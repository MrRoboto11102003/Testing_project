### Fast data preparation for the Python data stack.

<br>

**Arnio** is a compiled C++ data preparation engine for messy CSV and pandas workflows.<br>
It parses, infers types, strips whitespace, deduplicates, validates, and profiles data —<br>
then hands clean results back to the tools you already use.<br>
Use Arnio _before_ and _alongside_ pandas, NumPy, scikit-learn, DuckDB, and Arrow.

## ⚡ Quickstart

If you're new to Arnio, the example below demonstrates a simple first-run workflow for loading, cleaning, and preparing CSV data before converting it back into a pandas DataFrame.
The workflow starts by loading a CSV dataset into an Arnio frame for preprocessing and cleaning.

```python
import arnio as ar

# Load CSV directly through C++ — no Python parsing overhead
frame = ar.read_csv("messy_sales_data.csv")

# Strict mode (default) fails on inconsistent row widths
frame = ar.read_csv("messy_sales_data.csv", mode="strict")

# Permissive mode fills missing trailing values with nulls
frame = ar.read_csv("messy_sales_data.csv", mode="permissive")
```

Each pipeline step applies a specific transformation such as trimming whitespace, normalizing text formatting, handling missing values, and removing duplicate rows.


```python
# Declare what clean data looks like — arnio handles the rest
clean = ar.pipeline(frame, [
    ("strip_whitespace",),
    ("normalize_case", {"case_type": "lower"}),
    ("fill_nulls", {"value": 0.0, "subset": ["revenue"]}),
    ("drop_nulls",),
    ("drop_duplicates",),
])
```

After preprocessing is complete, the cleaned result can be converted back into a standard pandas DataFrame for further analysis or integration with existing workflows.

```python
# Out comes a standard pandas DataFrame — use it like you always have
df = ar.to_pandas(clean)

# Use copy=True when you need defensive pandas-owned buffers
safe_df = ar.to_pandas(clean, copy=True)
```
### Dry Run Validation

Use `dry_run=True` to validate pipeline configuration and
step execution without returning transformed output.

```python
ar.pipeline(
    frame,
    [
        ("drop_nulls",),
    ],
    dry_run=True,
)
```

Need step timings for debugging? Opt in without changing the default pipeline return type:

```python
clean, metadata = ar.pipeline(
    frame,
    [("strip_whitespace",), ("drop_duplicates",)],
    return_metadata=True,
)

print(metadata["step_timings"])
print(metadata["applied_steps"])
print(metadata["row_counts"])
print(metadata["execution_summary"])
```

## Quick Example

```python
import arnio

frame = arnio.read_csv("sample.csv")

# Preview first 5 rows
frame.preview(5)

# Generate and view scannable summary statistics
print(frame.describe())
```

### Pipeline validation behavior

Pipeline step specifications are validated before execution begins.

Malformed step tuples, invalid kwargs structures, or unknown step names fail early before any pipeline steps execute.

```python
ar.pipeline(
    frame,
    [
        ("strip_whitespace",),
        ("bad_step", "oops", "extra"),
    ],
)
```

This prevents partial pipeline execution when later pipeline steps are invalid.

### from_dict support

This adds support for creating an ArFrame from a Python dictionary.

You can build an `ArFrame` directly from a dictionary of equal-length columns, which is useful for small inline datasets that you want to pass into a pipeline.

```python
import arnio as ar

data = {"name": ["Alice", "Bob"], "age": [25, 30]}

frame = ar.from_dict(data)
# or
frame = ar.ArFrame.from_dict(data)
```

Already working with a pandas `DataFrame`? Arnio can also be integrated directly into an existing pandas workflow without changing your current data-processing approach:

```python
import pandas as pd
import arnio as ar

df = pd.read_csv("messy_sales_data.csv")

clean_df = df.arnio.clean([
    ("strip_whitespace",),
    ("normalize_case", {"case_type": "lower"}),
    ("drop_duplicates",),
])

report = clean_df.arnio.profile()

trimmed_df = (
    df.arnio.strip_whitespace(subset=["customer_name"])
      .arnio.clip_numeric(upper=100, subset=["loyalty_score"])
      .arnio.drop_nulls(subset=["customer_name"])
)
```

## Schema diff reports

Use `diff_schema()` to compare expected and observed data contracts across
datasets, releases, or generated schemas.

```python
import arnio as ar

expected = ar.Schema({
    "id": ar.Int64(nullable=False, unique=True),
    "email": ar.Email(nullable=False),
})

observed = ar.Schema({
    "id": ar.Int64(nullable=False),
    "created_at": ar.DateTime(format="%Y-%m-%d"),
})

diff = ar.diff_schema(expected, observed)
print(diff.summary())
print(diff.to_markdown())
```

### Select specific columns

Use `select_columns()` to create a new `ArFrame` with only the required columns before converting to pandas.

```python
selected = ar.select_columns(frame, ["name", "revenue"])

print(selected.columns)
# ['name', 'revenue']
```

- Preserves the requested column order.
- Returns a new `ArFrame`.
- Raises `ValueError` if any requested column does not exist.
- Raises `TypeError` if `columns` is not a sequence of strings.

### Handling missing values

Arnio supports configuring which strings are treated as null during CSV parsing using the `null_values` parameter in `read_csv` and `scan_csv`. By default, Arnio preserves its existing behavior and treats only empty cells as null. Custom matching is case-insensitive and applies to cell values only (not headers).

```python
# Default behavior: empty cells are null
frame = ar.read_csv("data.csv")

# Provide a custom list of sentinels (overrides the empty-cell default)
frame = ar.read_csv("data.csv", null_values=["", "MISSING", "UNKNOWN"])

# Disable null sentinel handling completely
frame = ar.read_csv("data.csv", null_values=[])
```

### Handling decimal separators

Use `decimal_separator` when numeric CSV data uses a separator other than
the default dot. This is explicit by design: Arnio does not auto-detect decimal
formats because a comma can also be the CSV delimiter.

```python
# Semicolon-delimited CSV with unquoted European decimals
frame = ar.read_csv("prices.csv", delimiter=";", decimal_separator=",")

# Comma-delimited CSV still needs quoted comma-decimal values
frame = ar.read_csv("prices.csv", decimal_separator=",")
```

The default remains `decimal_separator="."`, so existing dot-decimal files keep
their current behavior. If you also use `thousands_separator`, it must differ
from `decimal_separator`.

### Handling invalid UTF-8 bytes

Use `encoding_errors` to control how invalid UTF-8 bytes are handled during CSV parsing.

```python
# Raise an error on invalid UTF-8 bytes (default)
frame = ar.read_csv(
    "data.csv",
    encoding_errors="strict",
)

# Replace invalid bytes with the Unicode replacement character (�)
frame = ar.read_csv(
    "data.csv",
    encoding_errors="replace",
)

# Ignore invalid bytes completely
frame = ar.read_csv(
    "data.csv",
    encoding_errors="ignore",
)
```
Supported values:

- `"strict"` (default)
- `"replace"`
- `"ignore"`
> Every step above executes in C++. Your Python code is a _configuration_ — not the execution engine.

> Explore more in the **[examples/](./examples/)** folder — ready-to-run recipes for sales, customers, survey, logs, and finance datasets.

### Security note: CSV formula injection

Arnio preserves cell values by default when writing CSV files. It does not rewrite
strings that begin with spreadsheet formula prefixes such as `=`, `+`, `-`, or `@`
unless you opt in to formula escaping.

If you export Arnio-cleaned data back to CSV and expect users to open that file in
Excel, Google Sheets, LibreOffice, or another spreadsheet application, treat
untrusted text fields as potentially executable spreadsheet formulas. Use
`escape_formulas=True` when exporting user-controlled text to prefix formula-like
string cells with a single quote while leaving numeric columns unchanged:

```python
ar.write_csv(clean_frame, "safe_export.csv", escape_formulas=True)
```

This is especially important for customer names, notes, comments, imported form
fields, and any other free-text values that may come from outside your trust
boundary. Arnio keeps the export policy explicit, so existing CSV output remains
unchanged unless this option is enabled.

## Error Handling

### `read_csv` and `scan_csv`

| Input | Raises | Message |
|:---|:---|:---|
| File not found | `CsvReadError` | `Cannot open file: <path>` |
| Zero-byte file | `CsvReadError` | `CSV file is empty: '<path>'` |
| Blank header line | `CsvReadError` | `CSV header contains an empty column name` |
| Binary / NUL bytes | `CsvReadError` | `CSV input contains NUL bytes and appears to be binary or corrupted` |

### Schema Validation

`ar.validate()` returns a `ValidationResult`; it does not raise for validation failures. Check `result.passed` and `result.issues` for `dtype` or `required_column` rule violations.

`validate()` currently operates on a single in-memory `ArFrame`. Chunked validation via `read_csv_chunked()` iterators is not yet supported directly. Validate each chunk individually or materialize the data before validation when working with streamed/chunked inputs.

### Pipeline Step Errors

Unknown step names raise `UnknownStepError` before execution begins.

<summary><b>📸 Peek at a 100 GB file without loading it</b></summary>
<br>

`scan_csv` reads only the header + a sample to infer the schema. Zero data loaded.

```python
# Pass sample_size to control how many rows are evaluated for type inference
schema = ar.scan_csv("100GB_file.csv", sample_size=500)
# {'id': 'int64', 'name': 'string', 'is_active': 'bool', 'revenue': 'float64'}
```

Useful for exploring datasets before committing memory.
</details>

<details>
<summary><b>📄 Read JSON Lines (JSONL / NDJSON) files</b></summary>
<br>

`read_jsonl` parses one JSON object per line into an ArFrame. Blank lines are skipped, missing keys become nulls, and mixed-type columns are coerced to string — the same rules as `from_pandas`.

```python
# events.jsonl
# {"user": "alice", "score": 9.5, "active": true}
# {"user": "bob",   "score": 8.1, "active": false}

frame = ar.read_jsonl("events.jsonl")

# Limit rows
frame = ar.read_jsonl("large.jsonl", nrows=1000)

# Stream large JSONL/NDJSON files in bounded chunks
for chunk in ar.read_jsonl_chunked("large.jsonl", chunksize=50_000):
    process(chunk)

# Non-UTF-8 encoding
frame = ar.read_jsonl("data.ndjson", encoding="latin-1")

# Plug straight into the cleaning pipeline
clean = ar.pipeline(frame, [("strip_whitespace",), ("drop_nulls",)])
```

Raises `ar.JsonlReadError` with the 1-based line number if a line contains invalid JSON. The chunked reader uses the same validation and decoding rules as `read_jsonl`, but only materializes one chunk at a time.
</details>

<details>
<summary><b>📦 Parquet import and export for columnar analytics pipelines</b></summary>
<br>

`read_parquet` and `write_parquet` use pyarrow for Parquet I/O.  Install the optional extra first:

```bash
pip install arnio[parquet]
```

```python
# Import a Parquet file into an ArFrame (no pandas intermediate)
frame = ar.read_parquet("data.parquet")

# Read only selected columns
frame = ar.read_parquet("data.parquet", usecols=["name", "age"])

# Export an ArFrame to Parquet
ar.write_parquet(frame, "output.parquet")

# Choose compression codec: "snappy" (default), "gzip", "zstd", "brotli", "none"
ar.write_parquet(frame, "output.parquet", compression="zstd")

# Control row group size for large files
ar.write_parquet(frame, "output.parquet", row_group_size=50_000)

# .pq extension also accepted for both read and write
frame = ar.read_parquet("data.pq")
ar.write_parquet(frame, "output.pq")
```

Both functions raise `ImportError` with an install hint if pyarrow is not available.
</details>

<details>
<summary><b>👀 Preview rows without pandas conversion or full-column Python list materialization</b></summary>

`preview()` reads only the first `n` rows directly from the C++ frame — no pandas conversion triggered.

```python
frame = ar.read_csv("huge_file.csv")

```

<details>
<summary><b>💰 Financial Decimal Support</b></summary>
<br>

`arnio` provides support for converting Python `decimal.Decimal` objects.

* **Behavior**: Python `Decimal` objects are automatically preserved as high-precision strings during serialization/binding to prevent floating-point precision loss.
* **Caveat**: When reading back into Pandas, `to_pandas()` returns these as string (`object` dtype) columns. You will need to explicitly cast them back to `Decimal` objects on the resulting DataFrame if you want to resume exact math.

Example:

```python
from decimal import Decimal

import pandas as pd

import arnio as ar

df = pd.DataFrame({
    "price": [Decimal("19.99"), Decimal("29.95")]
})

frame = ar.from_pandas(df)  # Decimal values safely preserved as exact strings
result = ar.to_pandas(frame)
# result["price"] will be string objects ["19.99", "29.95"]
```

</details>

<details>
<summary><b>🧩 Add custom steps without touching C++</b></summary>
<br>

Register any Python function as a pipeline step. It receives a `DataFrame`, returns a `DataFrame`.

```python
def remove_outliers(df, column="revenue", threshold=100_000):
    return df[df[column] <= threshold]

ar.register_step("remove_outliers", remove_outliers)
ar.register_step("team:drop_nulls", remove_outliers)  # namespaced custom step

# Use builtin: for an explicit built-in step, and your own prefixes
# like team: or plugin_name: to avoid name collisions.

# Introspect built-in and custom step names without reaching into internals.
print(ar.list_steps())

# Opt in to a context object only when you need execution metadata.
def capture_context(df, context=None):
    print(context.step_name, context.step_index, context.total_steps)
    return df

# Now use it in any pipeline alongside native C++ steps
clean = ar.pipeline(frame, [
    ("builtin:strip_whitespace",),
    ("remove_outliers", {"column": "revenue", "threshold": 50000}),
    ("drop_duplicates",),
])
```

Need to inspect the built-in kwargs a step accepts before assembling a pipeline?

```python
signatures = ar.get_builtin_step_signatures()
print(list(signatures["drop_nulls"].parameters))  # ["subset"]
print(list(signatures["filter_rows"].parameters))  # ["column", "op", "value"]
```

Need to restore the registry back to built-in steps only during tests?

```python
ar.reset_steps()

print(ar.list_steps())
# Only built-in steps remain
```

Custom steps run through a pandas↔ArFrame conversion bridge. Prototype in Python, then optionally migrate hot paths to C++ for full speed.
</details>

<details>
<summary><b>🔄 Custom Step Overwrite Policy</b></summary>
<br>

By default, trying to register a custom step with a name that is already taken by another custom Python step will raise a `ValueError` to prevent silent overwriting.

To intentionally replace an existing custom **Python** step, pass `overwrite=True`:

```python
def custom_logging(df):
    print("Running step v1")
    return df

ar.register_step("log_data", custom_logging)

# This will succeed and safely overwrite the original logic
def custom_logging_v2(df):
    print("Running step v2")
    return df

ar.register_step("log_data", custom_logging_v2, overwrite=True)
```
> Note: Built-in C++ pipeline steps (like "drop_nulls") can never be overwritten, even if overwrite=True is explicitly supplied.
</details>

<details>
<summary><b>✂️ Slice rows with head() and tail()</b></summary>
<br>

`head()` and `tail()` return the first or last `n` rows as a new `ArFrame`.
```python
frame = ar.read_csv("data.csv")

frame.head()     # first 5 rows (default)
frame.head(10)   # first 10 rows
frame.tail(3)    # last 3 rows

# n larger than row count returns all rows safely
frame.head(1000)

# n=0 returns an empty ArFrame
frame.head(0)
```

Raises `ValueError` for negative or boolean `n`.
</details>

## 🔗 Integrations

Arnio is designed to make the rest of the Python data stack more productive,
not to replace it.

| Workflow | How Arnio helps |
|:---|:---|
| **pandas** | Clean, validate, and profile messy `DataFrame`s through `df.arnio`. |
| **NumPy** | Prepare typed numeric data before array/modeling workflows. |
| **scikit-learn** | Use Arnio cleaning as a preprocessing layer before model training. |
| **DuckDB / Arrow** | Validate and prepare data before analytics and columnar exchange. Export ArFrame to pyarrow.Table via ``ar.to_arrow(frame)``. |
| **notebooks** | Inspect quality issues and cleaning suggestions before analysis. |

### DuckDB registration

Use `ar.register_duckdb(frame, conn, "table_name")` to register an ArFrame directly as a DuckDB relation without writing pandas conversion glue yourself. DuckDB is an optional dependency — install it with `pip install "arnio[duckdb]"` when needed. You can also install DuckDB directly with `pip install duckdb`.

For development and CI, `pip install -e ".[dev]"` now includes DuckDB so the integration test module in `tests/test_integrations_duckdb.py` runs in the default test job.

```python
import duckdb
import arnio as ar

frame = ar.read_csv("data.csv")
conn = duckdb.connect()
ar.register_duckdb(frame, conn, "my_table")
result = conn.execute("SELECT * FROM my_table").fetchdf()
```

### Row-dropping and schema-change behavior

`ArnioCleaner` enforces a strict transformer contract by default:

- **Row-count-changing steps** (`drop_nulls`, `drop_duplicates`,
  `filter_rows`, `keep_rows_with_nulls`) are **rejected by default** with a
  clear `ValueError`. To allow row-count changes, pass `allow_row_count_change=True`.

- **Column schema-changing steps** (`rename_columns`, `drop_columns`,
  `drop_constant_columns`, `combine_columns`) are **rejected by default**
  and allowed only when `allow_schema_changes=True` is passed.

```python
# Schema-preserving (default strict mode)
cleaner = ArnioCleaner(
    steps=[
        ("strip_whitespace",),
        ("fill_nulls", {"value": 0}),
    ],
)

# Opt-in column schema changes
cleaner = ArnioCleaner(
    steps=[
        ("rename_columns", {"old_name": "new_name"}),
        ("drop_constant_columns",),
    ],
    allow_schema_changes=True,
)
```

### Pandas accessor

Arnio integrates directly with pandas through a registered DataFrame accessor. After importing Arnio, every pandas `DataFrame` gains an `.arnio` accessor that provides cleaning, profiling, validation, and pipeline utilities without requiring you to leave your existing pandas workflow.

The accessor is registered through pandas' DataFrame extension API, allowing Arnio methods to be accessed directly as `df.arnio`.

#### Cleaning data with `.clean()`

Use `.clean()` to apply common data-cleaning operations and return a cleaned pandas DataFrame.

```python
import pandas as pd
import arnio as ar

df = pd.read_csv("raw_customers.csv")

clean_df = df.arnio.clean(
    strip_whitespace=True,
    drop_duplicates=True,
)
```

Supported options include:

- `strip_whitespace` – remove leading and trailing whitespace from string values
- `drop_nulls` – remove rows containing null values
- `drop_duplicates` – remove duplicate rows
- `steps` – optional Arnio pipeline steps. When provided, `.clean()` executes the supplied pipeline and returns the resulting pandas DataFrame.

`.clean()` returns a pandas `DataFrame`, allowing you to continue using your existing pandas analysis workflow.

#### Profiling data with `.profile()`

Use `.profile()` to generate a data quality summary.

```python
quality = clean_df.arnio.profile()

print(quality)
```

`.profile()` returns a `DataQualityReport` containing dataset quality information and profiling insights that can help identify issues before downstream analysis.

#### Accessor vs `ar.pipeline()`

| Approach | Best for |
|-----------|-----------|
| `df.arnio.clean()` | Existing pandas workflows |
| `df.arnio.profile()` | Quick quality assessment |
| `df.arnio.pipeline(...)` | Custom pipeline execution from a DataFrame |
| `ar.pipeline(...)` | Direct Arnio/ArFrame workflows |

#### End-to-end example

```python
import pandas as pd
import arnio as ar

df = pd.read_csv("customers.csv")

clean_df = df.arnio.clean(
    strip_whitespace=True,
    drop_duplicates=True,
)

quality = clean_df.arnio.profile()

validation = clean_df.arnio.validate({
    "email": ar.Email(nullable=False),
    "user_code": ar.Regex(r"^USR-\d{4}$", nullable=False),
    "age": ar.Int64(nullable=True, min=0),
})

print(quality)
```

This approach keeps pandas as the analysis tool while Arnio handles data preparation, quality checks, and validation.

## 🧰 Cleaning primitives

Most operations below run natively in C++. Currently, `filter_rows`, `replace_values` and `standardize_missing_tokens` run via the Python (pandas) backend and may be optimized in C++ later.

| Primitive | What it does | Example |
|:---|:---|:---|
| `drop_nulls` | Remove rows with null/empty values | `ar.drop_nulls(frame, subset=["age"])` |
| `drop_columns` | Remove selected columns while preserving the remaining order | `frame = ar.drop_columns(frame, ["debug_col"])` |
| `drop_empty_columns` | Remove columns whose values are all null/empty | `frame = ar.drop_empty_columns(frame)` |
| `keep_rows_with_nulls` | Keep only rows that contain at least one null | `ar.keep_rows_with_nulls(frame, subset=["age"])` |
| `validate_columns_exist` | Fail early when required columns are missing | `ar.validate_columns_exist(frame, ["age"])` |
| `filter_rows` | Filter rows using comparison operators | `ar.filter_rows(frame, column="age", op=">", value=18)` |
| `fill_nulls` | Replace nulls with a scalar | `ar.fill_nulls(frame, 0, subset=["revenue"])` |
| `drop_duplicates` | Deduplicate rows (first/last/none) | `ar.drop_duplicates(frame, keep="first")` |
| `drop_constant_columns` | Remove columns with only one unique value | `ar.drop_constant_columns(frame)` |
| `clip_numeric` | Clip numeric values to lower and/or upper bounds | `ar.clip_numeric(frame, lower=0, upper=100)` |
| `coalesce_columns` | Select the first non-null value from a list of columns | `ar.coalesce_columns(frame, subset=["phone", "mobile"], output_column="contact")` |
| `combine_columns` | Combine multiple columns into a single output column | `ar.combine_columns(frame, subset=["first", "last"], separator=" ", output_column="name")` |
| `strip_whitespace` | Trim leading/trailing spaces from strings | `ar.strip_whitespace(frame)` |
| `standardize_missing_tokens` | Replace common missing-value strings with NaN | `ar.standardize_missing_tokens(frame)` |
| `normalize_case` | Force lower/upper/title case | `ar.normalize_case(frame, case_type="title")` |
| `rename_columns` | Rename columns via mapping | `ar.rename_columns(frame, {"old": "new"})` |
| `cast_types` | Cast column types with `errors="raise"`, `"coerce"`, or `"ignore"` | `ar.cast_types(frame, {"age": "int64"}, errors="raise")` |
| `round_numeric_columns` | Round numeric columns (non-numeric columns in subset ignored safely) | `ar.round_numeric_columns(frame, decimals=2)` |
| `replace_values` | Replace values using a mapping (column or whole-frame). Handles `None`/`NaN`. | `ar.replace_values(frame, {"active": "A", "inactive": "I"}, column="status")` |
| `clean` | Convenience shorthand supporting config dicts | `ar.clean(frame, strip_whitespace={"subset": ["name"]}, drop_nulls=True)` |
| `safe_divide_columns` | Divide one column by another, handling zero/null denominators | `ar.safe_divide_columns(frame, numerator="revenue", denominator="cost", output_column="ratio")` |
| `drop_columns_matching` | Drop columns whose names match a regex pattern | `ar.drop_columns_matching(frame, pattern="^temp_")` |
| `trim_column_names` | Strip leading/trailing whitespace from column names | `ar.trim_column_names(frame)` |
| `select_columns` | Return a new frame containing only selected columns | `ar.select_columns(frame, ["id", "name"])` |
| `slugify_column_names` | Normalise column names to snake_case | `ar.slugify_column_names(frame)` |

#### `ArFrame.select_dtypes` — type-based column selection

Returns a **new `ArFrame`** containing only the columns whose dtype matches the filter. Raises `ValueError` if no columns match.

```python
frame = ar.read_csv("data.csv")

# Keep only numeric columns
numeric = frame.select_dtypes(include=["int64", "float64"])

# Drop string columns
without_strings = frame.select_dtypes(exclude="string")
```

**Valid dtype strings:** `"int64"`, `"float64"`, `"string"`, `"bool"`, `"null"`

- At least one of `include` or `exclude` must be given — raises `ValueError` otherwise.
- `include` and `exclude` must not overlap — raises `ValueError` if they share a dtype.
- Unknown dtype strings raise `ValueError` with a list of valid options.
- Raises `ValueError` when no columns match (never returns an empty frame silently).
- Column order in the result always matches the original frame.

Or compose them all into a **pipeline**:

```python
clean = ar.pipeline(frame, [
    ("validate_columns_exist", {"columns": ["name", "city", "revenue"]}),
    ("drop_columns", {"columns": ["debug_notes"]}),
    ("strip_whitespace",),
    ("standardize_missing_tokens",),
    ("normalize_case", {"case_type": "lower"}),
    ("fill_nulls", {"value": "unknown", "subset": ["city"]}),
    ("drop_duplicates", {"keep": "first"}),
])
```

### Winsorize outliers

`winsorize_outliers()` clips extreme numeric values using lower and upper quantiles. Non-numeric columns are ignored unless explicitly selected in `subset`.

```python
frame = ar.read_csv("data.csv")

result = ar.winsorize_outliers(
    frame,
    lower=0.05,
    upper=0.95,
)
```

It can also be used inside `ar.pipeline()` as `("winsorize_outliers", {"lower": 0.05, "upper": 0.95})`.

### 🔁 Replace values

Use `replace_values` to substitute values using a mapping. It works as a pipeline step (Python backend) and can operate on a single column or the whole frame when `column` is omitted. It also understands null semantics: using `None` (or `np.nan`) as a mapping key targets existing nulls, and mapping a value to `None` creates real nulls.

Column-specific example:

```python
clean = ar.pipeline(frame, [
    ("replace_values", {"mapping": {"active": "A", "inactive": "I"}, "column": "status"}),
])
```

Whole-frame example (no `column`):

```python
clean = ar.pipeline(frame, [
    ("replace_values", {"mapping": {None: "MISSING", "active": "A", "inactive": "I"}}),
])
```

Direct API:

```python
frame2 = ar.replace_values(frame, {"active": "A", "inactive": "I"})
```

## 📊 Pandas Dtype Support Matrix

This table helps users understand which pandas dtypes and workflows are fully supported, partially supported, unsupported, or planned.

If a dtype is partially supported, users may need conversion before processing. Unsupported dtypes should raise clear errors where applicable.

| Pandas Dtype | Support Status | Notes / Fix Hints |
|---|---|---|
| `int64` / `Int64` | ✅ Supported | Fully supported with native C++ columnar storage. Nulls mapped to `pd.NA`. |
| `float64` / `Float64` | ✅ Supported | Fully supported with zero-copy conversion. Nulls mapped to `np.nan` or `pd.NA`. |
| `bool` / `boolean` | ✅ Supported | Native booleans supported with C++ backing. Nulls mapped to `pd.NA`. |
| `string` / `string[python]` | ✅ Supported | Native string extension type. Recommended for text. Nulls mapped to `pd.NA`. |
| `object` (strings / scalars) | ✅ Supported | Handled as text or coerced to common type if mixed. |
| `object` (nested / lists / dicts) | ❌ Unsupported | Nested structures not allowed in flat columnar storage. Raises `TypeError`. |
| `category` | ❌ Unsupported | Raises `TypeError` with fix hint. Convert to string: `df["col"].astype(str)` |
| `datetime64[ns]` / timezone-aware | ❌ Unsupported | Raises `TypeError` with fix hint. Use `df["col"].astype(str)` or string timestamps. |
| `timedelta64[ns]` | ❌ Unsupported | Raises `TypeError` with fix hint. Use `df["col"].dt.total_seconds()`. |
| `complex64` / `complex128` | ❌ Unsupported | Raises `TypeError` with fix hint. Split into real/imag columns or convert to strings. |

### Notes

- **Zero-copy Optimization**: Numeric columns (`int64`, `float64`) are optimized for fast zero-copy conversion between C++ and pandas where supported.
- **Defensive Buffers**: Pass `copy=True` to `to_pandas()` when downstream pandas code needs defensive pandas-owned column buffers.
- **Boolean Buffers**: Boolean conversion is copied because `std::vector<bool>` cannot be exposed as a zero-copy NumPy buffer.
- **Null Handling**: Columns with null masks are automatically converted to pandas nullable Extension dtypes (`Int64`, `BooleanDtype`, `StringDtype`).
- **Index Drop**: pandas DataFrame indexes are currently not preserved during `from_pandas()` conversion; converted frames receive a default `RangeIndex` when converted back via `to_pandas()`.
- **Validation**: Attempting to convert any unsupported type will raise a clear, user-friendly `TypeError` detailing the column name and how to fix/preprocess it.

```python
# Register a custom validator once, then reference it by name in any schema
ar.register_validator("positive", lambda v: v > 0)

schema = ar.Schema({
    "id": ar.Int64(nullable=False, unique=True),
    "email": ar.Email(nullable=False),
    "phone": ar.PhoneNumber(nullable=False),

    "user_type": ar.String(nullable=False),

    # country becomes required when user_type == "international"
    "country": ar.String(
        nullable=True,
        required_if=("user_type", "international"),
    ),

    # CurrencyCode validates 3-letter uppercase formats (e.g., USD, EUR, INR).
    "currency": ar.CurrencyCode(),

    # LanguageCode validates lowercase ISO 639-1 language codes (e.g., en, hi, fr).
    "language": ar.LanguageCode(),

    # TimeZone validates IANA timezone identifiers (e.g., Asia/Kolkata).
    "timezone": ar.TimeZone(),

    "username": ar.String(min_length=3, max_length=20),
    "user_code": ar.Regex(r"^USR-\d{4}$", nullable=False),
    "revenue": ar.Custom("positive", nullable=True, required_if=("user_type", "merchant")),
    "signup_date": ar.Date(nullable=False),
    "created_at": ar.DateTime(nullable=False, format="%Y-%m-%d"),

})

result = ar.validate(frame, schema)

if not result.passed:
    summary = result.summary()
    print(summary["issues_by_rule"])
    print(summary["issues_by_column"])
    print(summary["issues_by_column_and_rule"])
    print(result.to_pandas())
    print(result.to_markdown(max_issues=10))
```

### URL validation

`URL()` validates that values are well-formed URLs. By default, both `http` and `https` schemes are accepted.

```python

schema = ar.Schema({
```

Any URL with a scheme not in `allowed_schemes` will fail validation.

### Beginner-friendly auto-clean tutorial

Use this workflow when you receive a small messy dataset and want to inspect what Arnio will change before applying it.

```python
import arnio as ar
import pandas as pd

raw = pd.DataFrame(
    {
        "order_id": [1001, 1002, 1002, 1003, 1004],
        "customer": [" Ishan ", " Prasoon ", " Prasoon ", " Pranay ", " Dhruv "],
        "city": [" Paris ", "London", "London", " New York ", " Tokyo "],
    }
)

frame = ar.from_pandas(raw)

report = ar.profile(frame)
summary = report.summary()
print(summary)

suggestions = ar.suggest_cleaning(frame)
print(suggestions)
# [('strip_whitespace', {'subset': ['customer', 'city']}), ('drop_duplicates', {'keep': 'first'})]

safe = ar.auto_clean(frame)
strict = ar.auto_clean(frame, mode="strict")
```

Messy input:

| order_id | customer | city |
|:--|:--|:--|
| 1001 | ` Ishan ` | ` Paris ` |
| 1002 | ` Prasoon ` | `London` |
| 1002 | ` Prasoon ` | `London` |
| 1003 | ` Pranay ` | ` New York ` |
| 1004 | ` Dhruv ` | ` Tokyo ` |

Expected cleaned output with `mode="strict"`:

| order_id | customer | city |
|:--|:--|:--|
| 1001 | Ishan | Paris |
| 1002 | Prasoon | London |
| 1003 | Pranay | New York |
| 1004 | Dhruv | Tokyo |

`mode="safe"` only trims whitespace. Use `mode="strict"` when you also want deterministic built-in cleanup such as exact duplicate removal. If strict mode proposes type casts, run `dry_run=True` first and pass the exact proposed mapping as `confirmed_casts` with `allow_lossy_casts=True`.

See [examples/auto_clean_tutorial.py](examples/auto_clean_tutorial.py) for a runnable version of this walkthrough, and [examples/schema_validation.py](examples/schema_validation.py) for a focused validation tutorial.

### You don't need C++ to contribute

Most new features are pure Python pipeline steps:

```python
# 1. Write a function that takes a DataFrame and returns a DataFrame
def remove_special_chars(df, subset=None):
    cols = subset or df.select_dtypes("object").columns
    for col in cols:
        df[col] = df[col].str.replace(r"[^a-zA-Z0-9\s]", "", regex=True)
    return df

# 2. Register it
ar.register_step("remove_special_chars", remove_special_chars)

# 3. Write tests, open a PR. That's it.
```

If Arnio renames a built-in or registered pipeline step in a future release,
the old step name can stay temporarily available and will emit a
`DeprecationWarning` while routing execution to the new canonical step.

### If you do know C++

The biggest performance wins are in:
- **`drop_duplicates`** — replacing `std::ostringstream` row serialization with proper hash-based comparisons
- **`strip_whitespace`** — converting from copy-on-write to in-place mutation
- **Parallel column processing** — `std::thread` across independent columns

The primary function used to check an `ArFrame` against a `Schema`. It returns a `ValidationResult`.

#### <a name="validationresult"></a>ValidationResult / <a name="validationissue"></a>ValidationIssue

The objects returned after calling `validate()`.

**Row index convention:** `ValidationIssue.row_index` is **1-based** and refers to

## ===== docs/TROUBLESHOOTING.md =====

## Numeric columns inferred as strings

### Problem

Sometimes a numeric column gets detected as a string, even when you expect it to contain only numbers.

### Why it happens

This usually happens when the column contains mixed values, missing entries, or unexpected characters. The loader may then treat the entire column as text instead of numeric data.

### What to do about it

* Use `cast_types()` to apply explicit Arnio datatypes when needed
* Check columns for invalid values or unexpected symbols before validation

### Quick example

```python
import arnio as ar

frame = ar.read_csv("data.csv")

frame = ar.cast_types(
    frame,
    {"age": "int64"}
)
```

## Slow CSV parsing and performance issues

### Problem

Large CSV files may take a long time to load or process.

### Why it happens

Performance issues usually occur when unnecessary columns are loaded, datatype inference becomes expensive, or the entire dataset is processed at once.

### What to do about it

* Use `usecols` in `ar.read_csv(...)` to load only required columns
* Avoid unnecessary `cast_types()` operations unless they are needed
* Use `select_columns()` to reduce unnecessary data before processing
* Remove unused columns with `drop_columns()` when possible

### Quick example

```python
import arnio as ar

frame = ar.read_csv(
    "large.csv",
    usecols=["id", "name"]
)
```

## Supported pipeline steps for chunked mode

A **row-safe** step is one that operates on each row independently.  It never needs to see
adjacent rows or the full column to produce a correct result.  Row-safe steps can be applied
safely inside a chunked loop.

A **requires-global-view** step is one whose correctness depends on the full dataset being
present.  Applying it per chunk produces silently wrong results.

A **schema-changing** step alters column names or types.  It is safe per chunk but the same
mapping must be applied to every chunk consistently.

| Step | Category | Safe in chunked loop? | Notes |
|---|---|---|---|
| `strip_whitespace` | Row-safe | ✅ Yes | Operates on individual cell strings. |
| `normalize_case` | Row-safe | ✅ Yes | Operates on individual cell strings. |
| `fill_nulls` | Row-safe | ✅ Yes | Fills per-cell with a scalar value. |
| `cast_types` | Schema-changing | ✅ Yes | Apply the same mapping to every chunk. |
| `rename_columns` | Schema-changing | ✅ Yes | Apply the same mapping to every chunk. |
| `drop_nulls` | Row-safe | ✅ Yes | Drops rows whose specified columns are null. Cross-chunk row counts differ; this is expected and fine. |
| `drop_duplicates` | Requires global view | ❌ No | Can only detect duplicates within a single chunk. Rows that are duplicates of each other across chunk boundaries will not be removed. |
| `auto_clean(mode="safe")` | Row-safe | ✅ Yes | Only applies `strip_whitespace` internally. |
| `auto_clean(mode="strict")` | Requires global view | ❌ No | Includes `drop_duplicates` internally. |
| `suggest_cleaning` / `profile` | Requires global view | ⚠️ Partial | Profiling a single chunk gives locally-accurate statistics only. Aggregate manually if you need file-level metrics. See the note below. |

### `profile` and `suggest_cleaning` in chunked mode

`ar.profile()` returns accurate statistics for the frame it receives.  When you call it inside
a chunked loop each report reflects only that chunk.  File-level metrics such as
`duplicate_ratio` or `null_count` will be underestimates unless you aggregate them yourself.

For large-file quality monitoring the recommended pattern is to profile each chunk, collect the
per-chunk `DataQualityReport` objects, and combine the counts you care about:

```python
total_rows = 0
total_nulls = 0

for chunk in ar.read_csv_chunked("big.csv", chunksize=50_000):
    report = ar.profile(chunk)
    total_rows += report.row_count
    for col_profile in report.columns.values():
        total_nulls += col_profile.null_count
```

## Reconciling `row_index` values in CI and data-quality logs

When you log or store validation issues from a chunked run, always record both the `chunk_number`
and the `global_row` (computed as shown in Example A).  This makes issues traceable back to the
original file regardless of `chunksize`.

**Recommended log schema for CI:**

| Field | Type | Description |
|---|---|---|
| `run_id` | string | Unique identifier for this validation run (timestamp, git SHA, etc.). |
| `source_file` | string | Path or URI of the input CSV. |
| `chunksize` | int | `chunksize` used in this run. |
| `chunk_number` | int | 0-based chunk index. |
| `local_row` | int | `issue.row_index` — 1-based, local to the chunk. |
| `global_row` | int | `chunk_number * chunksize + local_row`. |
| `column` | string | Column name where the issue was detected. |
| `rule` | string | Rule name (e.g. `"email_format"`, `"max"`). |
| `message` | string | Human-readable description. |
| `value` | any | The offending cell value. |

Storing `chunksize` alongside `global_row` lets you re-derive `local_row` later
(`local_row = global_row - chunk_number * chunksize`) and also means the log remains
interpretable if `chunksize` changes between runs.

**Quick CI gate pattern:**

```python
import sys
import arnio as ar

schema = ar.Schema({ ... })
issue_count = 0

for chunk_number, chunk in enumerate(ar.read_csv_chunked("pipeline_input.csv")):
    result = ar.validate(chunk, schema)
    issue_count += result.issue_count

    if issue_count > 0:
        print(f"[FAIL] chunk {chunk_number}: {result.issue_count} issue(s)")
        for issue in result.issues[:5]:
            global_row = chunk_number * 10_000 + issue.row_index
            print(f"  row {global_row}: {issue.column} — {issue.message}")

if issue_count > 0:
    print(f"\nValidation failed: {issue_count} total issue(s).")
    sys.exit(1)

print("Validation passed.")
```

## 3. Unsafe Patterns

Do not do any of the following.

**Mutates input in place:**

```python
def unsafe_mutate(df, column):
    df[column] = df[column].str.lower()  # modifies the caller's DataFrame
    return df
```

**Forgets to return the DataFrame:**

```python
def unsafe_no_return(df, column):
    df = df.copy()
    df[column] = df[column].str.lower()
    # missing: return df — pipeline receives None and crashes
```

**Silently swallows errors:**

```python
def unsafe_silent(df, column):
    try:
        df = df.copy()
        df[column] = df[column].str.lower()
    except Exception:
        pass  # hides bugs, returns wrong data
    return df
```

**No column existence check:**

```python
def unsafe_no_check(df, column):
    df = df.copy()
    df[column] = df[column].str.lower()  # KeyError if column is missing
    return df
```

## 4. Full Example — `remove_outliers`

This is a complete, PR-ready custom step. Copy this pattern for any new step you contribute.

```python
import pandas as pd
import arnio as ar


def remove_outliers(
    df: pd.DataFrame,
    column: str,
    threshold: float,
    keep: str = "below",
) -> pd.DataFrame:
    """Remove rows where a numeric column exceeds (or falls below) a threshold.

    Parameters
    ----------
    df        : Input DataFrame. Not modified in place.
    column    : Name of the numeric column to filter on.
    threshold : The cutoff value.
    keep      : "below" keeps rows where column <= threshold (default).
                "above" keeps rows where column >= threshold.

    Returns
    -------
    pd.DataFrame
        A new DataFrame with outlier rows removed.

    Raises
    ------
    ValueError
        If column is not in the DataFrame, or keep is not a valid option.
    TypeError
        If column is not numeric.

    Examples
    --------
    >>> ar.register_step("remove_outliers", remove_outliers)
    >>> frame = ar.from_pandas(pd.DataFrame({"revenue": [100, 999, 50, 10_000]}))
    >>> clean = ar.pipeline(frame, [
    ...     ("remove_outliers", {"column": "revenue", "threshold": 500}),
    ... ])
    >>> ar.to_pandas(clean)["revenue"].tolist()
    [100, 50]
    """
    if column not in df.columns:
        raise ValueError(
            f"remove_outliers: column '{column}' not found. "
            f"Available columns: {list(df.columns)}"
        )
    if not pd.api.types.is_numeric_dtype(df[column]):
        raise TypeError(
            f"remove_outliers: column '{column}' must be numeric, "
            f"got dtype '{df[column].dtype}'."
        )
    if keep not in ("below", "above"):
        raise ValueError(
            f"remove_outliers: 'keep' must be 'below' or 'above', got '{keep}'."
        )
    df = df.copy()
    if keep == "below":
        return df[df[column] <= threshold]
    return df[df[column] >= threshold]


ar.register_step("remove_outliers", remove_outliers)
```

Use it in a pipeline:

```python
frame = ar.from_pandas(pd.DataFrame({"revenue": [100, 999, 50, 10_000]}))
clean = ar.pipeline(frame, [
    ("remove_outliers", {"column": "revenue", "threshold": 500}),
])
df = ar.to_pandas(clean)
# df["revenue"].tolist() -> [100, 50]
```

Input and output:

| revenue (before) | revenue (after) |
|---|---|
| 100 | 100 |
| 999 | removed |
| 50 | 50 |
| 10000 | removed |

## ===== docs/nullable_dtype_compat.md =====

## NA Handling

- `pd.NA` is preserved as `pd.NA` for `Int64`, `boolean`, and `string` columns.
- `pd.NA` in a `Float64` column becomes `float('nan')` / `pd.isna()` after
  round-trip because the output dtype is native `float64`.

## Unsupported Dtypes

The following dtypes raise `TypeError` with a fix hint:

| pandas dtype     | Error |
|-----------------|-------|
| `datetime64`    | Convert to string first: `.astype(str)` |
| `timedelta64`   | Convert to seconds: `.dt.total_seconds()` |
| `category`      | Convert to string first: `.astype(str)` |
| `complex128`    | Convert to string: `.apply(str)` |

## UInt64 Boundary

`UInt64` values must fit within the signed 64-bit integer range
(`0` to `9223372036854775807`). Values exceeding this raise `ValueError`.

## ===== docs/remote.md =====

# Remote CSV Input

`read_csv`, `scan_csv`, and `read_csv_chunked` accept HTTP and HTTPS URLs
in addition to local filesystem paths and file-like objects.  No extra
packages are required for HTTP/HTTPS — Arnio uses Python's built-in
`urllib` module.

## Supported input modes

| Input type | Example | Requires |
|---|---|---|
| Local path | `ar.read_csv("data.csv")` | nothing |
| `os.PathLike` | `ar.read_csv(Path("data.csv"))` | nothing |
| File-like object | `ar.read_csv(io.StringIO(...))` | nothing |
| HTTP / HTTPS URL | `ar.read_csv("https://example.com/data.csv")` | nothing (stdlib) |
| S3 URL | `ar.read_csv("s3://bucket/data.csv")` | `arnio[s3]` *(planned)* |
| GCS URL | `ar.read_csv("gs://bucket/data.csv")` | `arnio[gcs]` *(planned)* |
| Azure Blob URL | `ar.read_csv("az://container/data.csv")` | `arnio[azure]` *(planned)* |

## Error handling

```python
from arnio.exceptions import RemoteReadError

try:
    frame = ar.read_csv("https://example.com/data.csv")
except RemoteReadError as e:
    print(f"Fetch failed: {e}")
    print(f"URL: {e.url}")
    print(f"HTTP status: {e.status_code}")  # None for network-level failures
```

`RemoteReadError` is raised for:

- Non-2xx HTTP responses (e.g. 404 Not Found, 403 Forbidden)
- Network-level failures (DNS resolution failure, connection refused, timeout)
- Response body that cannot be decoded as UTF-8

The exception exposes two attributes:

| Attribute | Type | Description |
|---|---|---|
| `url` | `str` | The URL that failed |
| `status_code` | `int \| None` | HTTP status code, or `None` for network errors |

## Cloud provider schemes (planned)

Passing an `s3://`, `gs://`, `az://`, `abfs://`, or `abfss://` URL raises
a `ValueError` with an actionable install hint:

```
ValueError: Cloud scheme 's3' is not yet supported by arnio.
Install the optional extra when available: pip install "arnio[s3]"
```

This ensures that users get a clear message rather than a cryptic error
from the C++ backend when support arrives in a follow-up release.

## Security and credential notes

- **HTTP/HTTPS**: Arnio passes a `User-Agent: arnio/read_csv` header. No
  authentication is performed. If the server requires credentials, use a
  pre-signed URL or download the file manually.
- **Timeout**: Requests time out after 30 seconds. There is no retry logic;
  implement retries in your calling code if needed.
- **Content validation**: The response body is expected to be UTF-8 encoded
  CSV text. Non-UTF-8 responses raise `RemoteReadError` with a descriptive
  message.
- **Redirects**: `urllib` follows redirects by default (up to 10 hops).
- **TLS/SSL**: Standard Python SSL certificate verification applies. If you
  need to disable it (e.g. for internal CAs), pre-fetch the file manually
  and pass an `io.StringIO` instead.

def coalesce_columns(
    frame,
    *,
    subset: Sequence[str],
    output_column: str = "coalesced",
):
    """Select the first non-null value from a list of columns.

    Parameters
    ----------
    frame : ArFrame or pd.DataFrame
        Input data frame.
    subset : sequence of str
        Sequence of columns to check in order.
    output_column : str, default "coalesced"
        Name of the new column to store coalesced values.

    Returns
    -------
    ArFrame or pd.DataFrame
        New frame with coalesced column.

    Raises
    ------
    TypeError
        If subset is not a list, or frame is not an ArFrame or DataFrame.
    ValueError
        If subset is empty, output_column is empty, or output_column already
        exists in the frame.
    KeyError
        If any column in subset does not exist in the frame.

    Examples
    --------
    >>> frame = ar.read_csv("data.csv")
    >>> result = ar.coalesce_columns(frame, subset=["col_a", "col_b"],
    ...                              output_column="first_non_null")
    """
    from .convert import from_pandas, to_pandas

    frame, is_arframe = _validate_frame(frame, allow_pandas=True)

    if not isinstance(output_column, str) or not output_column.strip():
        raise ValueError("output_column must be a non-empty string")

    column_names = list(frame.columns)
    subset_columns = _validate_existing_column_sequence(
        subset,
        available_columns=column_names,
        argument_name="subset",
        reject_duplicates=True,
        missing_message=lambda missing, available: (
            f"Missing columns for coalesce_columns: {missing}. "
            f"Available columns: {available}"
        ),
    )

    if not subset_columns:
        raise ValueError("subset must contain at least one column")

    if output_column in column_names:
        raise ValueError(f"Output column '{output_column}' already exists.")

    df = to_pandas(frame) if is_arframe else frame.copy(deep=False)

    # Select the first non-null/non-NaN/non-None value per row
    df[output_column] = df[subset_columns].bfill(axis=1).iloc[:, 0]

    return from_pandas(df) if is_arframe else df

def combine_columns(
    frame,
    *,
    subset: list[str] | None = None,
    separator: str = " ",
    output_column: str = "combined",
):
    """Combine multiple columns into a single output column.

    Parameters
    ----------
    frame : ArFrame or pd.DataFrame
        Input data frame.
    subset : list[str], optional
        Columns to combine. If None, all columns are used.
    separator : str
        String used to separate values in the output column.
    output_column : str
        Name of the new column to store combined values.

    -------
    ArFrame or pd.DataFrame
        Frame with the combined output column appended.

    ------
    TypeError
        If separator is not a string, or frame is not an ArFrame or DataFrame.

        If output_column is empty, output_column already exists in the frame,

    >>> frame = ar.read_csv("data.csv")

    ...                             separator=" ", output_column="full_name")
    """

    if not isinstance(separator, str):
        raise TypeError("separator must be a string")
    if not isinstance(output_column, str) or not output_column.strip():

    if subset is None:
        subset_columns = list(column_names)
    else:

            missing_message=lambda missing, available: (
                f"Missing columns for combine_columns: {missing}. "
                f"Available columns: {available}"
            ),
        )

    if not subset_columns:
        raise ValueError("subset must contain at least one column")

    if output_column in column_names:
        raise ValueError(f"Output column '{output_column}' already exists.")

    if is_arframe:
        from ._arnio_cpp import combine_columns as _combine_columns

        result = _combine_columns(
            frame._frame, subset_columns, separator, output_column
        )
        return _wrap(result, frame)

    # Pandas fallback
    df = frame.copy(deep=False)
    combined = (
        df[subset_columns].astype("string").fillna("").agg(separator.join, axis=1)
    )
    null_mask = df[subset_columns].isna().all(axis=1)
    combined = combined.mask(null_mask, pd.NA)

    df[output_column] = combined

    return df

# arnio.cleaning.drop_columns_matching
def drop_columns_matching(frame, pattern):
    """Drop columns whose names match a given pattern.

    Parameters
    ----------
    frame : ArFrame or pd.DataFrame
        Input data frame.
    pattern : str
        Regex pattern to match column names against.

    Returns
    -------
    ArFrame or pd.DataFrame
        Data frame with matching columns removed.

    Raises
    ------
    TypeError
        If pattern is not a string.
    re.error
        If pattern is not a valid regex.
    ValueError
        If pattern matches all columns.

    Examples
    --------
    >>> frame = ar.read_csv("data.csv")
    >>> cleaned = drop_columns_matching(frame, "^temp_")
    """
    import re

    from .convert import from_pandas, to_pandas

    frame, is_arframe = _validate_frame(frame, allow_pandas=True)

    if not isinstance(pattern, str):
        raise TypeError(f"pattern must be a string, got {type(pattern).__name__}")

    try:
        re.compile(pattern)
    except re.error as e:
        raise re.error(f"Invalid regex pattern: {pattern!r}") from e

    df = to_pandas(frame) if is_arframe else frame

    cols_to_drop = [col for col in df.columns if re.search(pattern, str(col))]

    if len(df.columns) == 0:
        return frame if is_arframe else df

    if len(cols_to_drop) == len(df.columns):
        raise ValueError(
            "Pattern matches all columns. At least one column must remain."
        )

    result = df.drop(columns=cols_to_drop)

    return from_pandas(result) if is_arframe else result

# arnio.cleaning.drop_constant_columns
def drop_constant_columns(
    frame: ArFrame | pd.DataFrame,
) -> ArFrame | pd.DataFrame:
    """Remove columns with exactly one unique value.

    Nulls are counted as values when determining whether a column is constant.
    This means columns like ``[None, None]`` are dropped, while columns like
    ``[1, 1, None]`` are kept. Empty columns in zero-row frames are also kept,
    since they have zero unique values rather than one.

    If every column is dropped, the resulting zero-column frame preserves the
    original row count.

    Parameters
    ----------
    frame : ArFrame or pd.DataFrame
        Input data frame.

    Returns
    -------
    ArFrame or pd.DataFrame

    --------
    >>> frame = ar.read_csv("data.csv")
    >>> reduced = ar.drop_constant_columns(frame)
    """
    from .convert import from_pandas, to_pandas

    frame, is_arframe = _validate_frame(frame, allow_pandas=True)
    df = to_pandas(frame) if is_arframe else frame
    if len(df.index) == 0:
        result_df = df.copy(deep=True)

        if is_arframe:
            result = from_pandas(result_df)

            if getattr(frame, "_attrs", None) is not None:
                result._attrs = copy.deepcopy(frame._attrs)

            return result

        return result_df

    nunique_counts = df.nunique(dropna=False)
    constant_columns = nunique_counts[nunique_counts == 1].index.tolist()
    result_df = df.drop(columns=constant_columns)
    return from_pandas(result_df) if is_arframe else result_df

# arnio.cleaning.filter_rows
def filter_rows(
    frame: ArFrame | pd.DataFrame,
    column: str,
    op: str,
    value: object,
) -> ArFrame | pd.DataFrame:
    """Filter rows based on a column condition.

    Parameters
    ----------
    frame : ArFrame or pd.DataFrame
        Input data frame. When an ``ArFrame`` is supplied the return value
        is also an ``ArFrame``; when a ``pd.DataFrame`` is supplied the
        return value is a ``pd.DataFrame``.
    column : str
        Name of the column to filter on.
    op : str
        Comparison operator.  Supported values: ``">"``, ``"<"``,
        ``">="``, ``"<="``, ``"=="``, ``"!="``.
    value : object
        Scalar value to compare each cell against.

    Returns
    -------
    ArFrame or pd.DataFrame
        Filtered frame of the same type as the input.

    Examples
    --------
    >>> frame = ar.read_csv("data.csv")
    >>> filtered = ar.filter_rows(frame, column="age", op=">", value=18)
    """
    from pandas.api.types import is_scalar

    from .convert import from_pandas, to_pandas

    frame, is_arframe = _validate_frame(frame, allow_pandas=True)

    if not isinstance(column, str) or not column.strip():
        raise TypeError(
            f"filter_rows: column must be a non-empty string, got {type(column).__name__!r}"
        )

    if not isinstance(op, str):
        raise TypeError(f"filter_rows: op must be a string, got {type(op).__name__!r}")
    df = to_pandas(frame) if is_arframe else frame

    ops = {
        ">": "gt",
        "<": "lt",
        ">=": "ge",
        "<=": "le",
        "==": "eq",
        "!=": "ne",
    }

    if op not in ops:
        raise ValueError(f"Unsupported operator: {op}")

    if column not in df.columns:
        raise ValueError(f"Unknown column: {column}")

    if not is_scalar(value):
        raise TypeError("filter_rows value must be a scalar")

    try:
        mask = getattr(df[column], ops[op])(value)
    except TypeError as exc:
        raise TypeError(
            f"filter_rows: cannot compare column {column!r} with value "
            f"{value!r} using operator {op!r}: {exc}"
        ) from exc

    mask = mask.fillna(False).astype(bool)
    filtered = df[mask]
    if is_arframe:
        filtered = filtered.reset_index(drop=True)

    return from_pandas(filtered) if is_arframe else filtered

# arnio.cleaning.replace_values
def replace_values(
    frame: ArFrame | pd.DataFrame,
    mapping: dict,
    column: str | None = None,
) -> ArFrame | pd.DataFrame:
    """Replace values based on a mapping dict.

    If ``column`` is ``None``, the mapping is applied to every column.

    Handles ``None``/``NaN`` in mappings:

    - If the mapping has a null-like key (``None`` / ``NaN`` / ``pd.NA``),
      existing nulls in the frame are replaced via ``fillna``.
    - If the mapping maps a value *to* a null-like value, the result will
      contain real nulls (``NaN`` / ``NA``).

    Parameters
    ----------
    frame : ArFrame or pd.DataFrame
        Input data frame. When an ``ArFrame`` is supplied the return value
        is also an ``ArFrame``; when a ``pd.DataFrame`` is supplied the
        return value is a ``pd.DataFrame``.
    mapping : dict
        Mapping of ``{old_value: new_value}`` pairs.
    column : str, optional
        Specific column to apply replacements to.  When ``None`` (default)
        the mapping is applied across all columns.

    Returns
    -------
    ArFrame or pd.DataFrame
        New frame with values replaced, same type as the input.

    Examples
    --------
    >>> frame = ar.read_csv("data.csv")
    >>> replaced = ar.replace_values(frame, {"old_value": "new_value"}, column="name")
    """

    from .convert import from_pandas, to_pandas

    frame, is_arframe = _validate_frame(frame, allow_pandas=True)

    mapping = _validate_mapping(
        mapping,
        argument_name="mapping",
        allow_empty=False,
        non_mapping_message=(
            "mapping must be a dict-like mapping of {old_value: new_value}, "
            f"not {type(mapping).__name__}."
        ),
    )
    # Avoid mutating the caller's DataFrame in the direct pandas API path.
    df = to_pandas(frame) if is_arframe else frame.copy(deep=False)

    if column is not None:
        if not isinstance(column, str) or not column.strip():
            raise TypeError("column must be a non-empty string when provided")
        if column not in df.columns:
            available = ", ".join(map(str, df.columns)) or "<none>"
            raise KeyError(
                f"Column '{column}' not found. Available columns: {available}"
            )

    # Normalize mapping and separate null-key handling because NaN != NaN
    null_key_present = False
    null_replacement = None
    normalized_mapping = {}

    for k, v in mapping.items():
        # Handle scalar null-like keys safely without evaluating
        # tuple/list/array-like objects in boolean context.
        if _is_null_mapping_key(k):
            null_key_present = True
            null_replacement = v
        # Exclude tuple/list/ndarray/series/index keys which pandas.replace
        # does not support and can raise confusing errors (e.g. operand
        # length mismatch). Treat strings and true scalars as valid keys.
        elif is_scalar(k) and not isinstance(
            k, (tuple, list, np.ndarray, pd.Series, pd.Index)
        ):
            normalized_mapping[k] = v
        else:
            raise TypeError(
                f"replace_values() does not support non-scalar mapping keys. "
                f"Got key {k!r} of type '{type(k).__name__}'. "
                f"Only scalar values (str, int, float, bool) and null-like keys "
                f"(None, float('nan'), pd.NA, pd.NaT) are supported."
            )

    if column:
        s = df[column]
        original_null_mask = s.isna() if null_key_present else None
        if normalized_mapping:
            s = s.replace(normalized_mapping)
        if null_key_present:
            # Replace only values that were already null before replacement so
            # null-valued mapping results remain real nulls.
            s = s.where(~original_null_mask, null_replacement)
        df[column] = s
    else:
        original_null_mask = df.isna() if null_key_present else None
        if normalized_mapping:
            df = df.replace(normalized_mapping)
        if null_key_present:
            # Replace only values that were already null before replacement so
            # null-valued mapping results remain real nulls.
            df = df.where(~original_null_mask, null_replacement)

    return from_pandas(df) if is_arframe else df

# arnio.cleaning.safe_divide_columns
def safe_divide_columns(
    frame, numerator: str, denominator: str, output_column: str, fill_value: float = 0.0
):
    """Divide one column by another, handling division by zero and nulls explicitly.

    When the denominator is zero or null, the result is replaced with
    fill_value instead of raising an error or producing NaN/Inf.

    Parameters
    ----------
    frame : ArFrame
        Input data frame.
    numerator : str
        Column name to use as the numerator.
    denominator : str
        Column name to use as the denominator.
    output_column : str
        Name of the new column to store the division result. Must be a
        non-empty string. If the column already exists, a ``ValueError`` is raised.
    fill_value : float, optional
        Value to use when denominator is zero or null. Defaults to 0.0.

    Returns
    -------
    ArFrame

    Examples
    --------
    >>> frame = ar.read_csv("data.csv")
    >>> result = ar.safe_divide_columns(frame, numerator="revenue", denominator="cost", output_column="ratio")
    """
    from .convert import from_pandas, to_pandas

    frame, is_arframe = _validate_frame(frame, allow_pandas=True)
    columns = frame.columns

    if not isinstance(numerator, str):
        raise TypeError("numerator must be a string column name")

    if not isinstance(denominator, str):
        raise TypeError("denominator must be a string column name")

    if numerator not in columns:
        raise ValueError(f"Numerator column '{numerator}' not found in frame.")

    if denominator not in columns:
        raise ValueError(f"Denominator column '{denominator}' not found in frame.")

    if not isinstance(output_column, str) or not output_column.strip():
        raise ValueError("output_column must be a non-empty string.")

    if isinstance(fill_value, bool):
        raise TypeError("fill_value must be a finite float, not bool")

    if not isinstance(fill_value, (int, float)):
        raise TypeError(
            f"fill_value must be a finite float, got {type(fill_value).__name__!r}"
        )

    if not math.isfinite(fill_value):
        raise ValueError(f"fill_value must be finite, got {fill_value}")

    if output_column in columns:
        raise ValueError(f"Output column '{output_column}' already exists.")

    if is_arframe:
        numerator_dtype = frame.dtypes.get(numerator)
        denominator_dtype = frame.dtypes.get(denominator)

        numeric_types = {"int64", "float64"}

        if numerator_dtype in numeric_types and denominator_dtype in numeric_types:
            return ArFrame(
                _safe_divide_columns(
                    frame._frame,
                    numerator,
                    denominator,
                    output_column,
                    fill_value,
                )
            )

    df = to_pandas(frame) if is_arframe else frame

    numerator_series = df[numerator]
    denominator_series = df[denominator]

    numerator_values = pd.to_numeric(numerator_series, errors="coerce")
    denominator_values = pd.to_numeric(denominator_series, errors="coerce")

    bad_numerator = numerator_values.isna() & numerator_series.notna()
    bad_denominator = denominator_values.isna() & denominator_series.notna()

    if bad_numerator.any():
        bad_values = df.loc[bad_numerator, numerator].head(3).tolist()
        raise ValueError(
            f"Numerator column '{numerator}' contains non-numeric values: {bad_values}"
        )

    if bad_denominator.any():
        bad_values = df.loc[bad_denominator, denominator].head(3).tolist()
        raise ValueError(
            f"Denominator column '{denominator}' contains non-numeric values: {bad_values}"
        )

    is_zero_or_null = denominator_values.isna() | (denominator_values == 0)
    safe_denom = denominator_values.mask(is_zero_or_null)
    result = numerator_values / safe_denom

    df = df.copy(deep=False)
    df[output_column] = result.fillna(fill_value)

    return from_pandas(df) if is_arframe else df

# arnio.cleaning.standardize_missing_tokens
def standardize_missing_tokens(frame, tokens=None, subset=None):
    """Convert null-like string tokens in the frame to the standard NaN form.

    Parameters
    ----------
    frame : ArFrame
        Input data frame.
    tokens : list[str], optional
        List of strings to treat as missing. If None, then a built-in default tokens list is used
    subset : list[str], optional
        Column names to replace missing tokens in. If None, applies to all columns.

    Notes
    -----
    Matching is case-insensitive and trims surrounding whitespace before checking
    token membership. Values that do not match a missing token preserve their
    original whitespace.

    Returns
    -------
    ArFrame
        New frame with missing token values replaced by NaN.

    Examples
    --------
    >>> frame = ar.from_pandas(pd.DataFrame({"value": [1, 2, "N/A"]}))
    >>> result = ar.standardize_missing_tokens(frame)
    >>> frame = ar.from_pandas(pd.DataFrame({"value": [" NULL ", "\\tNaN\\t", "kept"]}))
    >>> result = ar.standardize_missing_tokens(frame)
    """

    from .convert import from_pandas, to_pandas

    frame, is_arframe = _validate_frame(frame, allow_pandas=True)
    df = to_pandas(frame) if is_arframe else frame

    df = df.copy(deep=False)
    if isinstance(subset, str):
        raise TypeError(
            f"subset must be a list of column names, not a string. "
            f"Did you mean subset=['{subset}']?"
        )
    if tokens is not None:
        if isinstance(tokens, str):
            raise TypeError(
                f"tokens must be a list of strings, not a bare string. "
                f"Did you mean tokens=['{tokens}']?"
            )
        if not isinstance(tokens, list):
            raise TypeError(
                f"tokens must be a list of strings, got {type(tokens).__name__!r}"
            )
        for item in tokens:
            if not isinstance(item, str):
                raise TypeError(
                    f"tokens must be a list of strings, got {type(item).__name__!r} item"
                )

    default_tokens = [
        "N/A",
        "NA",
        "n/a",
        "na",
        "nan",
        "-",
        "none",
        "nil",
        "null",
        "",
        "?",
    ]

    token_values = default_tokens if tokens is None else list(tokens)
    normalized_tokens = {
        token.strip().lower() for token in token_values if isinstance(token, str)
    }

    def _normalize_missing_value(value):
        if not isinstance(value, str):
            return value
        if value.strip().lower() in normalized_tokens:
            return float("nan")
        return value

    def _normalize_columns(columns):
        for column in columns:
            df[column] = df[column].map(_normalize_missing_value)

    if subset is None:
        _normalize_columns(df.columns)

    else:
        subset_columns = _validate_existing_column_sequence(
            subset,
            available_columns=df.columns,
            argument_name="subset",
            missing_error=ValueError,
            missing_message=lambda missing, _available: (
                f"Unknown columns in subset: {missing}"
            ),
        )
        _normalize_columns(subset_columns)

    return from_pandas(df) if is_arframe else df

### arnio.cleaning.coalesce_columns

# Notes: `arnio.cleaning.coalesce_columns(frame, *, subset, output_column="coalesced")`

## 1. Purpose
- Adds one new column, `output_column`, as the last column.
- Each row's value is the first non-null value across `subset`, scanned left to right in the order `subset` lists them.
- Implemented in pandas: `df[output_column] = df[subset_columns].bfill(axis=1).iloc[:, 0]`.

## 2. Inputs
- `frame`: an `ArFrame` or a `pd.DataFrame`. Anything else raises TypeError.
- `subset`: required, keyword-only, no default. Validated in this order:
  1. A `str` or `bytes` value raises TypeError.
  2. It must be a `collections.abc.Sequence` (list, tuple) or a `pd.Index`. A `set`, a generator or `None` raises TypeError.
  3. It is converted to a `list`, and every item must be a `str`.
  4. Duplicate names are rejected.
  5. Every name must exist in `frame.columns`.
- `subset` order matters. It sets the priority, not the frame's column order.
- `output_column`: a `str` with at least one non-whitespace character. It must not already be a column of the frame.

## 3. Raises (in check order)
1. Frame type: `TypeError("frame must be an ArFrame or a pandas DataFrame")`. Trigger: `coalesce_columns({"a": [1]}, subset=["a"])`.
2. Bad `output_column` (not a str, or blank/whitespace): `ValueError("output_column must be a non-empty string")`.
   - Triggers: `output_column=""`, `"  "`, or `5`.
   - This is checked before `subset`.
3. `subset` is a string: `TypeError("subset must be a sequence of column names, not a string")`. Trigger: `subset="a"`.
4. `subset` is not a sequence: `TypeError("subset must be a sequence of column names")`. Triggers: `subset={"a"}` or `subset=None`.
5. Non-string items: `TypeError("subset must contain only string column names")`. Trigger: `subset=["a", 1]`.
6. Duplicates: `ValueError(f"subset contains duplicate column names: {duplicates}")`.
   - Trigger: `subset=["a","a"]` gives `"subset contains duplicate column names: ['a']"`.
   - This is checked before missing columns, so `["a","a","zz"]` raises ValueError, not KeyError.
7. Missing columns: `KeyError(f"Missing columns for coalesce_columns: {missing}. Available columns: {available}")`.
   - `available` is `", ".join(columns)`, or `"<none>"` if the frame has no columns.
   - Trigger: frame with columns a, b and `subset=["a","zz"]` gives `"Missing columns for coalesce_columns: ['zz']. Available columns: a, b"`.
8. Empty subset: `ValueError("subset must contain at least one column")`. Triggers: `subset=[]` or `subset=()`.
9. Output already exists: `ValueError(f"Output column '{output_column}' already exists.")`.
   - Trigger: `subset=["a"], output_column="b"` when `b` exists.
   - The default name `"coalesced"` also triggers it if the frame has a column with that name.

## 4. Returns and guarantees
- The result has the same type as the input:
  - ArFrame in gives ArFrame out, built via `from_pandas(df)`.
  - DataFrame in gives DataFrame out.
- Columns are all the original columns in their original order, then `output_column` at the end.
- Original column values are unchanged.
- Row count is unchanged and no rows are dropped.
- Per row, the output is the first value in `subset` order that pandas considers non-null.
  - `None`, `NaN` and `pd.NA` are all treated as null.
  - If every subset value in a row is null, the output is null.
  - pandas does not treat `""` as null.
- Pandas input: the index is preserved. The result is a shallow copy of the input with the extra column.
- ArFrame input: attrs are not explicitly carried over (no `_wrap`).
  - Whether `from_pandas` keeps attrs depends on code in another module. Do not test attrs.
- Dtype of the output:
  - When all subset columns share a dtype (all float64, or all object strings), the result normally has that dtype.
  - For mixed dtypes (int and str), `bfill(axis=1)` may upcast to object or float. Assert values, not the dtype.

## 5. Side effects
- The input pandas DataFrame is not modified. A column is added only to `frame.copy(deep=False)`, so the original `df.columns` is unchanged.
- An input ArFrame is not modified.
- No global state is touched and no files are written.

## 6. Branches and edge cases
- First subset column non-null: its value wins even if later columns are also non-null.
  - `a=[1.0], b=[9.0]`, `subset=["a","b"]` gives `[1.0]`.
  - `subset=["b","a"]` gives `[9.0]`.
- Fallthrough to a later column:
  - `a=[1.0, nan, nan]`, `b=[10.0, 2.0, nan]`, `subset=["a","b"]` gives `[1.0, 2.0, NaN]`.
- Three columns:
  - `a=[nan]`, `b=[nan]`, `c=[7.0]` gives `[7.0]`.
- Single-column subset: the output equals that column's values.
- Strings (pandas object):
  - `a=["x", None]`, `b=["y","z"]` gives `["x","z"]`.
- Columns outside `subset` are ignored even when non-null.
- Zero-row frame with a valid subset returns 0 rows, with `output_column` added.
- ArFrame path: `to_pandas`, then pandas ops, then `from_pandas`. Null handling and dtypes depend on the `convert` module and the C++ core, which are not visible here.

## 7. Rules from docstring and comments
- "Select the first non-null value from a list of columns."
- Comment: "Select the first non-null/non-NaN/non-None value per row."
- Docstring Raises section:
  - TypeError for a bad subset or frame.
  - ValueError for an empty subset, an empty output_column, or an existing output_column.
  - KeyError for a missing subset column.

## 8. Testing hints
- The pandas path gives the most exact assertions:
  ```python
  df = pd.DataFrame({"a": [1.0, np.nan, np.nan], "b": [10.0, 2.0, np.nan]})
  out = ar.coalesce_columns(df, subset=["a", "b"], output_column="c")
  assert list(out.columns) == ["a", "b", "c"]
  assert out["c"].tolist()[:2] == [1.0, 2.0] and pd.isna(out["c"].iloc[2])
  assert list(df.columns) == ["a", "b"]  # input not mutated
  ```
- ArFrame path:
  - Build with `ar.from_pandas(...)` and read the result back with `ar.to_pandas(result)`.
  - Check `isinstance(result, ar.ArFrame)` and the `result.columns` order.
  - Compare nulls with `pd.isna`, never with `== None` or `== np.nan`.
  - Prefer float64 or string columns. Int columns with nulls may come back as a different dtype.
- Use `pytest.raises(..., match=re.escape(msg))`. For a KeyError, `str(exc)` adds quotes, but `match` uses a substring search, so it still works.
- Test priority by swapping the `subset` order. A bug that uses frame order, or picks the last value instead of the first, shows up there.
- Test the check order:
  - `output_column=""` combined with `subset="a"` raises ValueError, because `output_column` is checked first.
  - Duplicates combined with a missing column raise ValueError.
  - An existing output column combined with `subset=[]` raises the "at least one column" error first.

### arnio.cleaning.combine_columns

# Notes: `arnio.cleaning.combine_columns`

## 1. Purpose
- Joins the values of several columns, row by row, into one new string column. The new column is added as the last column.
- ArFrame input is handled by a C++ function. pandas input is handled by Python code whose logic is fully visible below.

## 2. Inputs
- `frame`: an `ArFrame` or a `pd.DataFrame`. Anything else raises `TypeError`.
- `subset` (keyword-only, default `None`):
  - `None` means every column, in frame order.
  - Otherwise it must be a list, tuple or `pd.Index` of `str`.
  - The output order follows `subset` order. `subset=["b","a"]` joins b first, then a.
- `separator` (default `" "`): must be a `str`. `""` is allowed.
- `output_column` (default `"combined"`): must be a `str` that is not empty after `.strip()`.

## 3. Raises (checks run in this order)
1. Bad frame: `TypeError("frame must be an ArFrame or a pandas DataFrame")`.
   - Trigger: `combine_columns({"a": [1]})`.
2. Non-str separator: `TypeError("separator must be a string")`.
   - Trigger: `separator=1`.
3. Bad output_column: `ValueError("output_column must be a non-empty string")`.
   - Triggers: `output_column=""`, `"   "`, or `5`.
4. Subset validation (only when `subset` is not None):
   - String or bytes subset: `TypeError("subset must be a sequence of column names, not a string")`. Trigger: `subset="a"`.
   - Not a Sequence or `pd.Index`: `TypeError("subset must be a sequence of column names")`. Trigger: `subset={"a"}` (a set).
   - Non-str items: `TypeError("subset must contain only string column names")`. Trigger: `subset=["a", 1]`.
   - Duplicates (checked before missing columns): `ValueError(f"subset contains duplicate column names: {duplicates}")`.
     - Trigger: `subset=["a","a"]` gives `"subset contains duplicate column names: ['a']"`.
   - Missing columns: `KeyError(f"Missing columns for combine_columns: {missing}. Available columns: {available}")`.
     - `available` is `", ".join(columns)`, or `"<none>"` when there are no columns.
     - Trigger: on columns a, b, `subset=["z"]` gives `"Missing columns for combine_columns: ['z']. Available columns: a, b"`.
   - An empty subset is not rejected by this step.
5. Empty selection: `ValueError("subset must contain at least one column")`.
   - Trigger: `subset=[]`.
   - Also triggered by `subset=None` on a zero-column frame.
6. Output name already exists: `ValueError(f"Output column '{output_column}' already exists.")`.
   - Trigger: columns `["a","combined"]` with default arguments gives `"Output column 'combined' already exists."`.
   - This check runs after the subset checks. For example, `subset=["z"]` plus an existing output name raises `KeyError`, not `ValueError`.
- All of these checks run before the C++ import or call, so they can be tested with ArFrame input too.

## 4. Returns and guarantees
### pandas input (fully visible code)
- Code:
  ```python
  df = frame.copy(deep=False)
  combined = df[subset].astype("string").fillna("").agg(separator.join, axis=1)
  combined = combined.mask(df[subset].isna().all(axis=1), pd.NA)
  df[output_column] = combined
  ```
- Returns a new `pd.DataFrame`. Columns are the originals in their original order, then `output_column` last.
- The index is kept as is (no reset).
- How values become strings (pandas `astype("string")`):
  - `1` becomes `"1"`.
  - `1.5` becomes `"1.5"`.
  - A float column such as `[1.0, 2.0]` gives `"1.0"`.
  - `True` becomes `"True"`.
- Null handling:
  - A null in a partly-null row becomes `""`, and the separator is kept.
  - `{"a": ["x", None], "b": [None, "y"]}` with `separator="-"` gives `["x-", "-y"]`.
- A row where every subset value is null gives `pd.NA` (check with `pd.isna`).
- Empty strings are not null:
  - `["", ""]` with `" "` gives `" "`, not NA.
- Single-column subset: the output is just the stringified value.

### ArFrame input
- Calls `arnio._arnio_cpp.combine_columns(frame._frame, subset_columns, separator, output_column)`.
- Wraps the result with `_wrap`, so the result is a new ArFrame and `_attrs` is a deep copy of the input's.
- **The formatting, null handling and output dtype are in C++ and cannot be seen.** Do not assume they match pandas exactly.
- Note this imports from `._arnio_cpp`, not `._core`.

## 5. Side effects
- pandas: works on a shallow copy, so the caller's DataFrame does not gain `output_column` and its values are unchanged.
- ArFrame: a new frame is returned; the input is untouched.
- No global state changes and no file I/O.

## 6. Branches / edge cases
- `subset=None`: all columns are joined.
  - pandas `{"a": ["x"], "b": ["y"]}` gives `"x y"`.
- `subset` given: only those columns are joined, in the given order.
- `separator=""`: `{"a": ["x"], "b": ["y"]}` gives `"xy"`.
- Non-default `output_column="full"`: a new last column named `"full"`.
- Zero-column pandas frame `pd.DataFrame(index=[0])` with `subset=None` raises the `"subset must contain at least one column"` ValueError.
- ArFrame vs pandas: the type check returns the same type as the input. Validation is shared; the combining logic differs.

## 7. Rules from the docstring
- `TypeError` if separator is not a str or frame has the wrong type.
- `ValueError` if output_column is empty or already exists, or the subset is empty.
- `KeyError` for missing subset columns.

## 8. Testing hints
- Pin exact values using the pandas path, e.g. `ar.combine_columns(pd.DataFrame(...), ...)`.
- Read results with `result["combined"].tolist()`, or `pd.isna(result.loc[1, "combined"])` for NA.
- Do not assert the output dtype. `agg(axis=1)` plus `mask` may give object or string dtype.
- Avoid zero-row pandas frames: `agg(..., axis=1)` on an empty frame behaves unclearly.
- Check that the input is not mutated: `assert "combined" not in df.columns` after the call.
- For ArFrames:
  - Build input with `ar.from_pandas(pd.DataFrame({...}))`.
  - Test mainly the validation errors.
  - Safe checks: `result.columns == [..., "combined"]` and `isinstance(result, ar.ArFrame)`.
  - For values, at most use simple non-null string columns (e.g. `"x y"`), knowing this relies on the C++ code.
- `KeyError`'s `str()` adds surrounding quotes, so match with `re.escape(...)` on a substring, or compare `exc.value.args[0]` exactly.
- Messages that are easy to get wrong:
  - `"Output column 'x' already exists."` ends with a period.
  - `"subset must contain at least one column"` has no period.

### arnio.cleaning.drop_columns_matching

# Notes: `arnio.cleaning.drop_columns_matching(frame, pattern)`

## 1. Purpose
- Drops every column whose name contains a match for the regex `pattern`, using `re.search`. It returns the same kind of object it was given: an `ArFrame` for an `ArFrame`, a `pd.DataFrame` for a `pd.DataFrame`.

## 2. Inputs
- `frame`: an `ArFrame` or a `pd.DataFrame`, checked by `_validate_frame(frame, allow_pandas=True)`.
  - Anything else raises `TypeError`.
  - No `pd.DataFrame` subclass special-casing beyond `isinstance`.
- `pattern`: must be a `str`. There is no default and no normalisation.
  - It is compiled once with `re.compile` purely to validate it.
  - Matching uses `re.search(pattern, str(col))`. This matches anywhere in the name, not anchored. It is case-sensitive because no flags are passed.
  - Non-string pandas column labels are converted with `str(col)` before matching. Example: label `0` is matched as `"0"`.

## 3. Raises (checks run in this order)
1. `TypeError("frame must be an ArFrame or a pandas DataFrame")`
   - Trigger: `drop_columns_matching([1, 2], "x")`.
   - The frame is checked before the pattern, so `drop_columns_matching(None, 5)` gives this message too.
2. `TypeError(f"pattern must be a string, got {type(pattern).__name__}")`
   - The type name is **not** quoted, so the message is exactly `pattern must be a string, got int`.
   - Trigger: `drop_columns_matching(frame, 5)`.
   - `re.compile` objects and `None` are also rejected: `got Pattern` / `got NoneType`.
3. `re.error(f"Invalid regex pattern: {pattern!r}")`, raised `from` the original `re.error`.
   - Trigger: `drop_columns_matching(frame, "[")`.
   - `str(exc)` is exactly `Invalid regex pattern: '['`.
   - `exc.__cause__` is an `re.error`.
4. Zero-column frame: this is an early return, not an error. It happens **before** the all-match check (see section 6).
5. `ValueError("Pattern matches all columns. At least one column must remain.")`
   - Trigger: frame with columns `["a", "b"]` and pattern `""` (empty matches everything), `"."` or `"a|b"`.

## 4. Returns and guarantees
- Result columns are the original columns minus the matched ones, in their **original relative order**.
- Rows, row count and cell values are unchanged.
- **`ArFrame` input:**
  - The result is `from_pandas(to_pandas(frame).drop(columns=...))`, which is a new `ArFrame`.
  - `_wrap` is not used, so `attrs` are **not** explicitly copied. Whether `from_pandas` keeps attrs depends on `convert.py` (not shown), so do not assert on attrs.
  - Dtypes go through a pandas round-trip. For plain int64 / float64 / string columns, `result.dtypes` should equal the input's dtypes for the surviving columns.
- **`pd.DataFrame` input:**
  - The result is `df.drop(columns=cols_to_drop)`, a new DataFrame. It is a distinct object even when nothing matched.
  - Index is preserved, with no reset.
- No match at all is not an error. You get a new frame with all columns: an `ArFrame` with the same columns, or a DataFrame `equal` to the input but `is not` the input.

## 5. Side effects
- None. The input DataFrame or `ArFrame` is not mutated, because `df.drop` returns a copy.
- No global state is touched and no files are written.

## 6. Branches and edge cases
- **Partial match.** `pd.DataFrame({"temp_a": [1, 2], "b": ["x", "y"], "temp_c": [1.5, 2.5]})` with `"^temp_"` gives columns `["b"]`.
- **Substring vs anchor.**
  - Columns `["my_temp", "temp_x", "keep"]` with `"temp"` gives `["keep"]`.
  - The same columns with `"^temp"` gives `["my_temp", "keep"]`.
- **Case-sensitive.** Columns `["TEMP_a", "temp_b", "c"]` with `"^temp"` gives `["TEMP_a", "c"]`.
- **No match.** `"zzz"` returns all columns unchanged (new object).
- **Zero columns.** If `len(df.columns) == 0`, the function returns the **input object itself**: `result is frame` for both `ArFrame` and DataFrame. This holds even for pattern `""`, so no ValueError is raised.
  - Use `pd.DataFrame(index=range(3))` to build this case.
  - Whether `ar.from_pandas` accepts a zero-column frame depends on the C++ core, so prefer the pandas path for this test.
- **Zero rows, some columns.** Behaves normally: the matched columns are dropped and the result has 0 rows.
- **Non-string labels (pandas).** `pd.DataFrame({0: [1], 1: [2], "x": [3]})` with `"^\d$"` gives columns `["x"]`.
- **All match.** Raises the ValueError from item 5 of section 3. Examples: a single-column frame `{"a": [1]}` with `"a"`, or any frame with `""`.

## 7. Rules from the docstring
- `pattern` is a regex matched against column names.
- A non-str `pattern` raises TypeError, an invalid regex raises `re.error`, and matching all columns raises ValueError.
- The return type matches the input type.

## 8. Testing hints
- Build inputs with `fr = ar.from_pandas(pd.DataFrame({...}))`.
- Observe results through:
  - `res.columns` (a list),
  - `res.shape`,
  - `ar.to_pandas(res)` together with `pd.testing.assert_frame_equal` against `df[["b"]]`, plus `check_dtype` where the dtypes are simple.
- Assert `isinstance(res, ar.ArFrame)` for `ArFrame` input and `isinstance(res, pd.DataFrame)` for DataFrame input.
- Check order: drop the middle column of `["a", "mid", "z"]` with `"^mid$"` and assert `["a", "z"]` exactly.
- Matching exception messages with `pytest.raises(..., match=...)`:
  - Wrap them in `re.escape`, because they contain `(`, `.` and `'`. Example: `match=re.escape("Invalid regex pattern: '['")`.
  - For the type error, `match="pattern must be a string, got int"` works; the type name is not quoted.
- Non-mutation check for the pandas path: keep `df_copy = df.copy()`, call the function, then `assert_frame_equal(df, df_copy)` and `list(df.columns)` unchanged.
- Pitfalls:
  - `""` and `"."` match every non-empty name, so they raise on non-empty frames.
  - Do not assert that `attrs` survive.
  - Do not assert `result is frame` except in the zero-column case.
  - For pandas input the index is **not** reset. After dropping columns the index is the same as the input's anyway.

### arnio.cleaning.drop_constant_columns

# Notes: `arnio.cleaning.drop_constant_columns(frame)`

## 1. Purpose
- Removes every column that has exactly one distinct value.
- Nulls count as a value (`nunique(dropna=False) == 1`).
- Accepts an `ArFrame` or a `pd.DataFrame` and returns the same kind of object.

## 2. Inputs
- `frame`: an `ArFrame` or a `pandas.DataFrame`. There are no other parameters.
- Validation is done by `_validate_frame(frame, allow_pandas=True)`:
  - `ArFrame` → ArFrame path.
  - `pd.DataFrame` → pandas path.
  - Anything else → `TypeError`.
- An `ArFrame` is converted with `ar.to_pandas(frame)`. A pandas input is used directly; it is not mutated, because `drop` and `copy` return new objects.

## 3. Raises
- `TypeError("frame must be an ArFrame or a pandas DataFrame")` for any other type.
  - Examples: `ar.drop_constant_columns({"a": [1]})`, `ar.drop_constant_columns(None)`, a list, a `pd.Series`.
- This is the only explicit raise. Pandas `nunique` may raise for unhashable cell values (e.g. lists in an object column). Do not test that.

## 4. Returns and guarantees
- **Return type:** an `ArFrame` for `ArFrame` input, a `pd.DataFrame` for DataFrame input. It is always a new object, never the input itself (`result is not frame`).
- **Column order:** the remaining columns keep their original relative order (`df.drop(columns=...)`).
- **Which columns are dropped:** `nunique_counts[nunique_counts == 1]`.
  - Columns with ≥2 distinct values (null counted as one distinct value) are kept.
- **Null handling:**
  - `[None, None]` / `[nan, nan]` → 1 unique → dropped.
  - `[1, 1, None]` → 2 unique (1 and NaN) → kept.
- **Rows:** never changed. Values and dtypes of the kept columns are unchanged in the pandas path.
- **Pandas path:** the index is preserved as-is (no `reset_index`).
- **attrs (ArFrame):**
  - Zero-row path: explicitly sets `result._attrs = copy.deepcopy(frame._attrs)`, when not None.
  - Non-empty path: returns `from_pandas(result_df)` with no explicit attrs copy. Whether attrs survive depends on `to_pandas`/`from_pandas` in `arnio.convert`, which is not visible here. Do not assert attrs in the non-empty path.

## 5. Side effects
- None. The input `ArFrame` or DataFrame is unchanged (columns and values identical afterwards).
- No global state is touched and no I/O is performed.

## 6. Branches and edge cases
- **Zero rows** (`len(df.index) == 0`): returns a deep copy with **all columns kept**, even though they have 0 unique values.
  - `pd.DataFrame({"a": [], "b": []})` → result has columns `["a", "b"]` and 0 rows, and is not the same object.
  - ArFrame: `from_pandas(copy)`, with attrs deep-copied (so mutating `result._attrs` does not affect `frame._attrs`).
- **Mixed columns:** `pd.DataFrame({"a": [1, 1, 1], "b": [1, 2, 3], "c": ["x", "x", "x"]})` → columns `["b"]`.
- **Nothing constant:** `{"a": [1, 2], "b": ["x", "y"]}` → both columns kept, values equal to the input.
- **Single row:** every column has nunique 1, so **all** columns are dropped.
  - Pandas: result has `columns == []` and `len(result) == 1` (row count preserved, per the docstring).
- **Every column constant:** `{"a": [5, 5], "b": ["z", "z"]}` → pandas result has 0 columns and `len == 2`.
  - The ArFrame row count for a 0-column result depends on `from_pandas` (not visible). Assert only `result.columns == []`.
- **Null-related columns:**
  - All-null column `{"a": [None, None, None], "b": [1, 2, 3]}` → `["b"]`.
  - Partly null `{"a": [1.0, 1.0, None], "b": [1, 2, 3]}` → both kept (`["a", "b"]`).
- **Bool column** `[True, True]` → dropped. `[True, False]` → kept.

## 7. Rules from the docstring
- "Nulls are counted as values"; `[None, None]` is dropped and `[1, 1, None]` is kept.
- "Empty columns in zero-row frames are also kept, since they have zero unique values rather than one."
- "If every column is dropped, the resulting zero-column frame preserves the original row count."

## 8. Testing hints
- **Build inputs:** `ar.from_pandas(pd.DataFrame({...}))`.
- **Observe results:**
  - `result.columns` (list of str, ordered), `result.shape`, and `ar.to_pandas(result)[col].tolist()`.
  - Check the return type with `isinstance(result, ar.ArFrame)` / `isinstance(result, pd.DataFrame)`.
- **Use the pandas-input path for exact assertions** (row count with 0 columns, index, dtypes). `pd.testing.assert_frame_equal(result, df[["b"]])` works for the pandas path.
- **Test the threshold exactly.** Best regression catchers:
  - A 2-value column is kept.
  - The null-vs-value distinction: `[1, 1, None]` kept, `[None, None]` dropped. This catches a `dropna=True` change.
  - The zero-row branch keeps columns.
  - Column order is preserved, e.g. `{"x": [1, 2], "c": [0, 0], "y": [3, 4]}` → `["x", "y"]`.
  - The input is not mutated: check `df.columns.tolist()` after the call.
- **Pitfalls:**
  - Don't mix `None` and `NaN` in one column, or mix `1` and `"1"`. Pandas/arnio coercion makes the unique count uncertain.
  - Don't assert attrs or the ArFrame row count for the all-dropped, non-empty case.
  - For zero-row ArFrames, build them via `ar.from_pandas(pd.DataFrame({"a": pd.Series([], dtype="int64")}))`. Assert only the columns and `shape[0] == 0`.
  - To set attrs, assign `frame._attrs = {"k": [1]}` (a private attribute). Use it only in the zero-row test.

### arnio.cleaning.drop_nulls

# Notes: `arnio.cleaning.drop_nulls(frame, *, subset=None)`

## 1. Purpose
- Removes every row that has a null in any checked column. With `subset=None` it checks all columns; otherwise it checks only the `subset` columns.
- The row filtering itself is done by the C++ core (`_drop_nulls`). Python only validates the arguments and wraps the result.

## 2. Inputs
- `frame`: must be an `ArFrame`.
  - It is checked by `_validate_arframe`, which lives in `arnio.frame` and is not shown here.
  - A non-ArFrame (for example a `pd.DataFrame`) presumably raises `TypeError`, but the exact message is not visible.
- `subset` (keyword-only), default `None`:
  - `None` means all columns are checked. It is passed to C++ as `subset=None`.
  - Otherwise it is normalised by `_validate_column_sequence(subset, argument_name="subset")`:
    - `str` or `bytes` is rejected.
    - The value must be a `collections.abc.Sequence` (list, tuple) or a `pd.Index`.
    - A `set`, `dict` or generator is rejected.
    - All items must be `str`.
    - It is converted with `list(subset)`.
  - Duplicate names in `subset` are **not** rejected.
  - Column-name matching is exact and case-sensitive. It uses `in frame.columns`.

## 3. Raises (checks happen in this order)
1. Frame check (non-ArFrame): exception type and message come from `arnio.frame`, so they are unverified. Use only `pytest.raises(TypeError)` if you test this at all.
2. `subset` is a string or bytes:
   - Raises `TypeError("subset must be a sequence of column names, not a string")`.
   - Trigger: `ar.drop_nulls(f, subset="a")`.
3. `subset` is not a Sequence or Index:
   - Raises `TypeError("subset must be a sequence of column names")`.
   - Trigger: `subset={"a"}`.
4. `subset` contains a non-str item:
   - Raises `TypeError("subset must contain only string column names")`.
   - Trigger: `subset=["a", 1]`.
   - This check runs before the missing-column check, so `subset=[1]` gives this TypeError, not a KeyError.
5. Empty `subset`:
   - Raises `ValueError("drop_nulls: subset cannot be empty; pass subset=None to check all columns")`.
   - Trigger: `subset=[]` or `subset=()`.
6. A column in `subset` does not exist:
   - Raises `KeyError(f"Missing columns for drop_nulls: {missing}. Available columns: {available}")`.
   - `missing` is a Python list repr of the missing names, in the order they appear in `subset`. Example: `['zz']`.
   - `available` is `", ".join(frame.columns)`, or `"<none>"` if the frame has no columns.
   - Example: for a frame with columns `a,b`, `subset=["zz"]` gives the message `Missing columns for drop_nulls: ['zz']. Available columns: a, b`.
   - Because `str(KeyError)` adds quotes, assert on `exc.value.args[0] == ...`, or use `match=re.escape("Missing columns for drop_nulls: ['zz']")`.
7. Errors raised inside the C++ `_drop_nulls` are unknown and not visible.

## 4. Returns and guarantees
- Always returns a **new** `ArFrame` built by `_wrap(result, frame)`. It is never the input object itself: `result is not frame`.
- Metadata: `result._attrs` is `copy.deepcopy(frame._attrs)`.
  - It is equal to the original but is not the same object. Nested objects are also not shared.
- Rows: kept rows are presumably in their original relative order. This is C++ behaviour, but it is the expected semantics.
- Columns and dtypes: the C++ layer is expected to keep the column set, column order and dtypes unchanged. This is not verifiable from the Python code. Asserting that `columns` is unchanged is reasonable.
- "null/empty": the docstring says empty values also count. Whether `""` counts as null is decided in C++ (and by how `from_pandas` stores `""`), so it is unverified. **Do not write tests that depend on `""` being dropped or being kept.**

## 5. Side effects
- No module or global state is touched and no files are written.
- The input frame should be unchanged. A test asserting that `frame.shape` and `to_pandas(frame)` are the same before and after the call is safe.

## 6. Branches and edge cases
- **`subset=None`.** Any null in any column drops the row.
  - Frame: `{"a": [1.0, None, 3.0], "b": ["x", "y", None]}`.
  - Result: 1 row, `a=1.0`, `b="x"`.
- **`subset=["a"]` on the same frame.** Only nulls in `a` count.
  - Rows 0 and 2 are kept: `a=[1.0, 3.0]`, `b=["x", None]`.
  - The null in `b` survives.
- **`subset=["b"]`.** Rows 0 and 1 are kept: `a=[1.0, nan]`, `b=["x", "y"]`.
- **Tuple subset** `("a",)`: gives the same result as `["a"]`.
- **Duplicate names** such as `["a", "a"]`: accepted; the result is presumably the same as `["a"]`.
- **No nulls at all:** the result has the same shape and values as the input, but it is a new object.
- **All rows contain a null:** the result has 0 rows and the same columns.
- **Zero-row input:** it goes straight to C++, and the result presumably has 0 rows with the same columns.

## 7. Rules from docstring and comments
- "A row is dropped if ANY column in the subset contains a null."
- `subset=None` means check all columns.
- An empty subset is an explicit error. Do not treat it as "check all columns".

## 8. Testing hints
- **Building a frame:**
  ```python
  f = ar.from_pandas(pd.DataFrame({"a": [1.0, None, 3.0], "b": ["x", "y", None]}))
  ```
  - Use `float` columns with `None`/NaN and object columns with `None` to create nulls.
  - Avoid nullable int columns and `""`, because how they map to nulls depends on `from_pandas` and the C++ core.
- **Observing the result:**
  - `r.shape`, `r.columns`, `r.to_dict()` (orient `"list"`), or `ar.to_pandas(r)`.
  - When comparing a pandas result, call `.reset_index(drop=True)` on it and check values with `pd.isna(...)` rather than `== None`.
  - A float `a` comes back as `1.0`, not `1`.
- **Checking attrs:**
  ```python
  f._attrs = {"src": {"k": [1]}}
  r = ar.drop_nulls(f)
  assert r._attrs == f._attrs and r._attrs is not f._attrs and r._attrs["src"] is not f._attrs["src"]
  ```
- **Precise assertions:**
  - The subset path is easy to pin down: `subset=["a"]` must keep the row that is null only in `b`. A regression that ignores `subset` would drop it.
  - Also check `subset=[]` → ValueError and `subset="a"` → TypeError, each with its exact message.
- **Pitfall:** a set subset raises TypeError (item 3 above); do not expect it to work.

### arnio.cleaning.filter_rows

# Notes: `arnio.cleaning.filter_rows(frame, column, op, value)`

## 1. Purpose
- Keeps only the rows where `frame[column] <op> value` is True, using a pandas comparison method.
- The result has the same type as the input: an `ArFrame` gives an `ArFrame`, a `pd.DataFrame` gives a `pd.DataFrame`.

## 2. Inputs
- **`frame`**: an `ArFrame` or a `pd.DataFrame`.
  - It is checked with `_validate_frame(frame, allow_pandas=True)`.
  - An `ArFrame` is converted with `to_pandas(frame)`.
  - A DataFrame is used directly and is not copied up front.
- **`column`**: must be a `str` that is not empty after `.strip()`.
  - It must exist in the pandas columns.
  - It is not stripped before the lookup, so `" a"` is not the same as `"a"`.
- **`op`**: must be a `str` and an exact key of this table (no stripping):
  ```
  ">"  -> gt
  "<"  -> lt
  ">=" -> ge
  "<=" -> le
  "==" -> eq
  "!=" -> ne
  ```
- **`value`**: anything where `pandas.api.types.is_scalar(value)` is True.
  - Accepted: int, float, str, bool, `None`, `np.int64`, `pd.Timestamp`.
  - Rejected: list, tuple, set, dict, ndarray.

## 3. Raises (in this exact order)
1. `TypeError("frame must be an ArFrame or a pandas DataFrame")`
   - Trigger: `filter_rows({"a": [1]}, "a", ">", 1)`
2. `TypeError(f"filter_rows: column must be a non-empty string, got {type(column).__name__!r}")`
   - `column=5` gives "...got 'int'".
   - `column=""` or `"   "` gives "...got 'str'".
3. `TypeError(f"filter_rows: op must be a string, got {type(op).__name__!r}")`
   - `op=None` gives "...got 'NoneType'".
4. `ValueError(f"Unsupported operator: {op}")`
   - `op="="` gives `"Unsupported operator: ="`.
   - `"=>"`, `" >"` and `"eq"` also raise this.
5. `ValueError(f"Unknown column: {column}")`
   - `column="zzz"` gives `"Unknown column: zzz"`.
6. `TypeError("filter_rows value must be a scalar")`
   - Trigger: `value=[1, 2]`.
7. Any `TypeError` raised by the pandas comparison is re-raised as:
   - `TypeError(f"filter_rows: cannot compare column {column!r} with value {value!r} using operator {op!r}: {exc}")`, with `__cause__` set to the original error.
   - Reliable trigger (pandas input, object column):
     ```python
     filter_rows(pd.DataFrame({"s": ["a", "b"]}), "s", ">", 1)
     ```
     The message starts with `"filter_rows: cannot compare column 's' with value 1 using operator '>': "`.
   - `"=="` and `"!="` between str and int do not raise; they just give all False / all True.

Ordering pitfalls:
- `op` is validated before `column`: `filter_rows(f, "missing", "=", 1)` raises "Unsupported operator: =".
- `column` is validated before `value`: `filter_rows(f, "missing", ">", [1])` raises "Unknown column: missing".

## 4. Returns and guarantees
- The mask is `getattr(series, op_name)(value).fillna(False).astype(bool)`.
  - Null comparison results (`pd.NA` from nullable dtypes) count as False and are dropped.
- **DataFrame input**:
  - Returns `df[mask]`, a new DataFrame.
  - The index is **not reset**; the original labels are kept, e.g. `[1, 2]`.
  - Columns and dtypes are unchanged.
- **ArFrame input**:
  - Returns `from_pandas(df[mask].reset_index(drop=True))`, a new `ArFrame`.
  - Columns keep their original order and row order is preserved.
  - `_attrs` are **not** deep-copied from the source; there is no `_wrap` call, unlike most other functions.
- Dtypes of the ArFrame result depend on `from_pandas` inference (in `convert`, not shown here).
- No rows matching gives 0 rows with the same columns.

## 5. Side effects
- The input frame or DataFrame is never mutated.
- No global state is touched and no files are written.

## 6. Branches and edge cases
Base frame for the examples: `pdf = pd.DataFrame({"a": [1, 2, 3], "b": ["x", "y", "z"]})`.

| Call | Result |
|---|---|
| `filter_rows(pdf, "a", ">", 1)` | rows `a=[2, 3]`, index `[1, 2]` |
| `filter_rows(ar.from_pandas(pdf), "a", ">", 1)` | `ArFrame`, `a=[2, 3]`, `b=["y", "z"]`, shape `(2, 2)` |
| `">="` 2 | `[2, 3]` |
| `"<"` 2 | `[1]` |
| `"<="` 2 | `[1, 2]` |
| `"=="` 2 | `[2]` |
| `"!="` 2 | `[1, 3]` |
| string column: `"b", "==", "y"` | 1 row |
| string column: `"b", ">=", "y"` | rows `y`, `z` (lexicographic) |
| no match: `"a", ">", 100` | 0 rows, columns `["a", "b"]` |

Float NaN with `"!="`:
- With pandas input `pd.DataFrame({"f": [1.0, float("nan"), 3.0]})`, `"!="` with `1.0` **keeps** the NaN row (index `[1, 2]`), because `NaN != 1.0` is True in numpy.
- `">"` with `0` drops the NaN row.

`value=None` or NaN:
- This follows pandas semantics: `"!="` keeps all rows and the other ops keep none.
- That behaviour is pandas' own, not arnio's; avoid relying on it heavily.

## 7. Rules from the docstring
- The output type matches the input type.
- Only the six listed operators are supported.
- `value` must be a scalar.

## 8. Testing hints
Build inputs and read results like this:
```python
fr = ar.from_pandas(pdf)
res = ar.filter_rows(fr, "a", ">", 1)
out = ar.to_pandas(res)
assert out["a"].tolist() == [2, 3]
assert res.columns == ["a", "b"]
```

What to assert on:
- **ArFrame result**: assert that the index is `RangeIndex` 0..n-1, e.g. `list(out.index) == [0, 1]`.
- **pandas result**: assert the original labels, e.g. `list(res.index) == [1, 2]`. This difference between the two paths is a key behaviour to pin.
- **Immutability**: assert `pdf` is unchanged afterwards (`pdf.equals(original_copy)`).
- **Error messages**: use `pytest.raises(..., match=re.escape(msg))`.
  - Operators like `>` and `?` are fine in regex, but strings containing `(`, `[` or `.` need escaping.
- **Comparison-wrap error**: use a **pandas** DataFrame with an object-dtype string column. The dtype that `to_pandas` gives ArFrame string columns is not visible here.

Pitfalls:
- Avoid asserting exact dtypes on zero-row ArFrame results, since `from_pandas` inference is not visible here.
- Do not assume attrs survive on the ArFrame path.
- Do not rely on how nulls in an ArFrame int column look after `to_pandas` (NaN vs `pd.NA`). The `"!="` + null behaviour differs between them, so test null handling only with pandas float64 input.

### arnio.cleaning.keep_rows_with_nulls

# Notes: `arnio.cleaning.keep_rows_with_nulls(frame, *, subset=None)`

## 1. Purpose
- Returns only the rows that have at least one null value. With `subset`, only those columns are checked.
- It is the complement of `drop_nulls`, but it is implemented entirely in pandas.
- It accepts an `ArFrame` or a `pd.DataFrame` and returns the same type it was given.

## 2. Inputs
- **`frame`**: an `ArFrame` or a `pd.DataFrame`. Anything else raises `TypeError`.
  - An `ArFrame` is converted with `to_pandas(frame)`.
  - A DataFrame is used as-is and is not copied up front.
- **`subset`** (keyword-only, default `None`):
  - `None` means every column is checked: `cols = df.columns.tolist()`.
  - Otherwise it must be a non-string `collections.abc.Sequence` (list or tuple) or a `pd.Index`.
  - Every item must be a `str` and must exist in `df.columns`.
  - Duplicate names are allowed (they are not rejected).
  - The order of names in `subset` has no effect on the result.

## 3. Raises (checks run in this order)
1. Bad frame type: `TypeError("frame must be an ArFrame or a pandas DataFrame")`.
   - Trigger: `keep_rows_with_nulls({"a": [1]})`.
2. `subset` is a `str`: `TypeError(f"keep_rows_with_nulls: 'subset' must be a list of column names, not a string. Did you mean subset=['{subset}']?")`.
   - Trigger: `subset="a"` gives `...Did you mean subset=['a']?`.
3. `subset` is `bytes`: `TypeError("subset must be a sequence of column names, not a string")`.
   - Trigger: `subset=b"a"`.
4. `subset` is not a Sequence or Index: `TypeError("subset must be a sequence of column names")`.
   - Trigger: `subset={"a"}` (a set) or `subset=5`.
5. `subset` contains a non-`str` item: `TypeError("subset must contain only string column names")`.
   - Trigger: `subset=["a", 1]`.
6. `subset` is empty: `ValueError("keep_rows_with_nulls: subset cannot be empty; pass subset=None to check all columns")`.
   - Trigger: `subset=[]` or `subset=()`.
7. Unknown column: `KeyError(f"Missing columns for keep_rows_with_nulls: {missing}. Available columns: {available}")`.
   - `missing` is the Python list repr of the missing names, in `subset` order.
   - `available` is `", ".join(columns)`, or `"<none>"` if the frame has no columns.
   - Example message: `Missing columns for keep_rows_with_nulls: ['z']. Available columns: a, b`.
   - Because it is a `KeyError`, `str(exc)` wraps the message in extra quotes. Match with `re.escape(...)` on a fragment.
- Note on ordering: the frame-type check runs before any check on `subset`.

## 4. Returns and guarantees
- **Return type**:
  - `ArFrame` input gives an `ArFrame` (`from_pandas(result)`).
  - `DataFrame` input gives a `pd.DataFrame`.
- **Null test**: `df[cols].isnull().any(axis=1)`. Only pandas nulls count: `None`, `NaN`, `pd.NA`, `NaT`.
  - Empty strings `""` and whitespace-only strings are **not** treated as null, even though the docstring says "null/empty".
- **Columns**: all columns are kept, in their original order, not just the `subset` columns.
- **Rows**:
  - Rows that match keep their original relative order.
  - The index is always reset to `0..n-1` via `reset_index(drop=True)`. This applies to pandas input too: if the input index is `[10, 20, 30]`, the output index is a `RangeIndex`.
- **Values**: unchanged, and nulls stay null.
- **Result object**: always a new object, never the input itself.
- **`ArFrame` attrs**: not explicitly copied. The function does not use `_wrap`. Whether attrs survive depends on `to_pandas`/`from_pandas` in `convert.py`, which is not shown here, so do not assert on attrs.

## 5. Side effects
- The input frame or DataFrame is not mutated, because boolean indexing creates a new frame.
- There is no global state, registry change, or file I/O.

## 6. Branches and edge cases
- **`subset=None`**: checks all columns.
  - Example: `{"a": [1.0, None, 3.0], "b": ["x", "y", None]}` keeps original rows 1 and 2 → a=[NaN, 3.0], b=["y", None].
- **With `subset`**: on the same data, `subset=["a"]` keeps only original row 1. `subset=["b"]` keeps only original row 2.
- **No nulls anywhere**: result has 0 rows and the same columns, e.g. `shape == (0, 2)`.
- **Every row has a null**: all rows are returned, in their original order.
- **Zero-row input**: returns zero rows with the same columns.
- **Zero-column pandas frame** (`pd.DataFrame(index=range(3))`):
  - `cols = []`, so `any(axis=1)` is all False.
  - The result is an empty frame with 0 rows.
- **Duplicate names in `subset`**: `subset=["a", "a"]` gives the same rows as `["a"]`.
- **Tuple or Index subset**: `subset=("a",)` and `subset=pd.Index(["a"])` both work.

## 7. Rules from the docstring
- A row is kept if **any** column in `subset` is null.
- A string `subset` raises `TypeError`, and a missing column raises `KeyError`. Both match the code.

## 8. Testing hints
- **Building input**:
  ```python
  df = pd.DataFrame({"a": [1.0, None, 3.0], "b": ["x", "y", None]})
  fr = ar.from_pandas(df)
  out = ar.keep_rows_with_nulls(fr)
  ```
- **Inspecting an `ArFrame` result**: use `ar.to_pandas(out)`, `out.shape`, and `out.columns`.
- **Comparing nulls**: compare with `pd.isna(...)`, not with `== None`.
  - After the ArFrame round trip, a null string may come back as `None` or `NaN`.
  - Int columns that contain nulls are float in pandas.
- **Testing the pandas path**:
  - Assert that `type(result) is pd.DataFrame`.
  - Assert `list(result.index) == list(range(len(result)))` when the input index was non-default.
  - Assert the original `df` is unchanged afterwards (`df.equals(copy)`).
- **Exact null criterion**: test it on the **pandas path**. A row whose only "missing" value is `""` must NOT be kept.
  - Avoid `""` on the ArFrame path: how the C++ conversion stores empty strings is not visible here.
- **Empty results**: assert `shape[0] == 0` and the column list. Do not assert dtypes of empty ArFrame results, since inference is done by C++/convert code that is not shown.
- **Error messages**: use `pytest.raises(..., match=re.escape("Missing columns for keep_rows_with_nulls: ['z']"))`.
  - Escape the brackets, and quotes too where they appear.
- **Not observable**: attrs propagation, and internal dtypes after `from_pandas`.

### arnio.cleaning.replace_values

# Notes: `arnio.cleaning.replace_values(frame, mapping, column=None)`

## 1. Purpose
- Replaces exact cell values using a `{old: new}` dict, either in one column or in every column.
- Null-like keys (`None`, `NaN`, `pd.NA`, `pd.NaT`) fill pre-existing nulls.
- The result has the same kind as the input: ArFrame in gives ArFrame out; `pd.DataFrame` in gives `pd.DataFrame` out.

## 2. Inputs
- `frame`: an `ArFrame` or a `pd.DataFrame`.
  - ArFrame input is converted with `to_pandas(frame)`.
  - DataFrame input is copied with `frame.copy(deep=False)`.
- `mapping`: any `collections.abc.Mapping`, converted with `dict(mapping)`. It must not be empty.
  - Each key is classified in insertion order:
    - **Null-like key**: `k is None`, or a scalar `k` where `pd.isna(k)` is true. Then `null_key_present = True` and `null_replacement = v`. If there are several null keys, the last one wins.
    - **Scalar key** (`pandas.api.types.is_scalar`, not tuple/list/ndarray/Series/Index): goes into the normal replace dict.
    - **Anything else** (for example a tuple `(1, 2)` or a `frozenset`): raises `TypeError` (see Raises).
- `column`: `None` (the default) means the mapping applies to all columns. Otherwise it must be a non-blank `str` that exists in the frame's columns.

## 3. Raises (in check order)
1. Frame of the wrong type: `TypeError("frame must be an ArFrame or a pandas DataFrame")`.
   - Example: `replace_values([1], {1: 2})`
2. Mapping that is not a Mapping: `TypeError(f"mapping must be a dict-like mapping of {{old_value: new_value}}, not {type(mapping).__name__}.")`.
   - Example: `replace_values(df, [("a", "b")])` gives `"... not list."`
3. Empty mapping: `ValueError("mapping must not be empty")`.
   - Example: `replace_values(df, {})`
4. Column that is not a string, or is blank: `TypeError("column must be a non-empty string when provided")`.
   - Examples: `column=5`, `column=""`, `column="  "`
5. Column not in the frame: `KeyError(f"Column '{column}' not found. Available columns: {available}")`.
   - `available` is `", ".join(map(str, df.columns))`, or `"<none>"` if there are no columns.
   - Example: columns `a`, `b` with `column="z"` gives `Column 'z' not found. Available columns: a, b`.
   - `str(KeyError)` adds quotes around the message, so `pytest.raises(KeyError, match="Column 'z' not found")` still works.
6. Non-scalar key: `TypeError(f"replace_values() does not support non-scalar mapping keys. Got key {k!r} of type '{type(k).__name__}'. Only scalar values (str, int, float, bool) and null-like keys (None, float('nan'), pd.NA, pd.NaT) are supported.")`.
   - Example: `{(1, 2): "x"}` gives `Got key (1, 2) of type 'tuple'`.
   - This check runs only after checks 1–5 pass. With a bad column and a tuple key, the column error is raised.

## 4. Returns and guarantees
- **Column path** (`column` given):
  - `s = df[column]` and `mask = s.isna()` (computed before any replacement).
  - Then `s.replace(normalized_mapping)`, if the dict is non-empty.
  - Then `s.where(~mask, null_replacement)`, if a null key is present.
  - The result is written back to `df[column]`. Other columns are untouched.
- **Whole-frame path**: the same steps, using `df.isna()`, `df.replace(...)` and `df.where(...)` over all columns.
- Matching is exact, whole-value matching (pandas `replace` with `regex=False`). There is no substring replacement: `{"a": "b"}` leaves `"abc"` unchanged.
- Nulls produced by the mapping stay null; only nulls that were null originally are filled. Example: `["a", None]` with `{"a": None, None: "z"}` gives `[None/NaN, "z"]`.
- Column order and row count are unchanged.
- **ArFrame input**: the result comes from `from_pandas(df)`, so it is a new ArFrame. It does not copy `frame._attrs` (unlike `_wrap`).
- **DataFrame input**: the result is a new DataFrame (`result is not df`).
- Output dtypes come from pandas `replace` and `where`. The ArFrame↔pandas dtype mapping lives in `arnio.convert`, which is not shown here.

## 5. Side effects
- The input is never mutated. The pandas path works on a shallow copy and assigns new columns or frames. ArFrame inputs are only read.
- There is no global state and no file I/O.

## 6. Branches and edge cases
- Column given, only scalar keys: `df = pd.DataFrame({"a": ["x", "y"], "b": ["x", "q"]})` with `{"x": "X"}` and `column="a"` gives `a == ["X", "y"]` and `b == ["x", "q"]`.
- No column: the same input with `{"x": "X"}` gives `a == ["X", "y"]` and `b == ["X", "q"]`.
- Only a null key in the column path: `{"a": ["x", None]}` with `{None: "missing"}` and `column="a"` gives `["x", "missing"]`.
- Null key in the whole-frame path fills nulls in every column. Example: `pd.DataFrame({"s": ["x", None], "n": [1.0, np.nan]})` with `{np.nan: 0}` gives `s == ["x", 0]` and `n == [1.0, 0.0]`. Prefer type-compatible fills.
- Keys that are never present: values are unchanged and there is no error.
- `pd.NA`, `float("nan")` and `pd.NaT` keys all behave like `None`.
- A mapping value that is itself a null creates real nulls. Example: `{"x": None}` with `column="a"` on `["x", "y"]` makes `pd.isna(result["a"][0])` true.

## 7. Rules from comments and docstring
- "Avoid mutating the caller's DataFrame in the direct pandas API path."
- The null-key path is kept separate "because NaN != NaN". Only values that were already null before replacement are filled, "so null-valued mapping results remain real nulls".
- Tuple/list/ndarray/Series/Index keys are rejected up front so that pandas does not raise confusing errors.

## 8. Testing hints
- To build inputs: `fr = ar.from_pandas(pd.DataFrame({...}))`.
- To observe results: `out = ar.to_pandas(ar.replace_values(fr, {...}, column="a"))` and compare `out["a"].tolist()`. Check nulls with `pd.isna(x)`, never with `== None` or `== np.nan`.
- Also test the pandas-in path:
  - `isinstance(res, pd.DataFrame)`
  - `res is not df`
  - `df` is unchanged afterwards (`pd.testing.assert_frame_equal` against a saved `.copy()`).
- Good regression targets:
  - Nulls created by the mapping are not overwritten by the null key.
  - `column=` limits changes to that column.
  - The exact error messages and the order of the checks.
  - The ArFrame type is preserved.
- Pitfalls to avoid:
  - Do not assert exact dtypes; ArFrame conversion is defined elsewhere.
  - Avoid mixing types inside one column (for example replacing a string with an int in a string column); how `from_pandas` handles that is not visible here.
  - Avoid `True`/`1`/`1.0` keys: they are the same dict key, and pandas may match bools to ints.
  - Avoid chained mappings like `{"a": "b", "b": "c"}`; the result depends on pandas.
  - Do not test `_attrs` preservation; attrs are not copied.
  - Hand-written integer columns with NaN become float in pandas, so `[1, None]` gives `[1.0, nan]`.

### arnio.cleaning.safe_divide_columns

# Notes: `arnio.cleaning.safe_divide_columns(frame, numerator, denominator, output_column, fill_value=0.0)`

## 1. Purpose
- Adds a new column `output_column` equal to `frame[numerator] / frame[denominator]`.
- Where the denominator is zero or null, the value is `fill_value` instead of NaN/inf.
- Accepts an ArFrame or a pandas DataFrame. The output type matches the input type.

## 2. Inputs
- `frame`: `ArFrame` or `pd.DataFrame`. Anything else raises TypeError.
- `numerator`, `denominator`: `str` column names, and both must exist. They may be the same column.
- `output_column`: a non-empty, non-whitespace `str` that must NOT already exist. A non-str value such as `5` raises **ValueError**, not TypeError.
- `fill_value`: `int` or `float`, and must be finite. `bool` is rejected.
  - `np.float64` is accepted because it subclasses float.
  - `np.int64` is rejected.

## 3. Raises (checks run in exactly this order)
1. `TypeError("frame must be an ArFrame or a pandas DataFrame")`, e.g. `safe_divide_columns({"a":[1]}, "a", "a", "r")`.
2. `TypeError("numerator must be a string column name")`, e.g. `numerator=1`.
3. `TypeError("denominator must be a string column name")`.
4. `ValueError(f"Numerator column '{numerator}' not found in frame.")`, e.g. `numerator="x"`.
5. `ValueError(f"Denominator column '{denominator}' not found in frame.")`.
6. `ValueError("output_column must be a non-empty string.")`. Note the trailing period. Triggered by `""`, `"  "` or `5`.
7. `TypeError("fill_value must be a finite float, not bool")`, e.g. `fill_value=True`.
8. `TypeError(f"fill_value must be a finite float, got {type(fill_value).__name__!r}")`:
   - `fill_value="0"` gives `got 'str'`.
   - `fill_value=None` gives `got 'NoneType'`.
9. `ValueError(f"fill_value must be finite, got {fill_value}")`:
   - `float("nan")` gives `got nan`.
   - `float("inf")` gives `got inf`.
10. `ValueError(f"Output column '{output_column}' already exists.")`, e.g. `output_column="n"`.
11. Pandas path only (see §6), non-numeric values:
    - `ValueError(f"Numerator column '{numerator}' contains non-numeric values: {bad_values}")`.
    - The denominator variant is the same text with `Denominator column '{denominator}'`.
    - `bad_values` lists the first 3 offending original values.
    - The numerator is checked first, so it is reported even when both columns are bad.
    - Example: `pd.DataFrame({"n":["a","b","c","d"],"d":[1,1,1,1]})` gives `Numerator column 'n' contains non-numeric values: ['a', 'b', 'c']`.

Order examples:
- A missing numerator plus `fill_value=True` raises the "not found" ValueError.
- An existing `output_column` plus `fill_value=nan` raises the "must be finite" ValueError.

## 4. Returns and guarantees
**Native path (C++):** used when the input is an ArFrame AND both `frame.dtypes` entries are in `{"int64","float64"}`.
- Returns `ArFrame(_safe_divide_columns(...))`.
- The `attrs` argument is NOT passed, so the source `_attrs` are not carried over.
- Exact values, null handling and output dtype are determined in C++ code I cannot see.
- The docstring says zero or null denominator gives `fill_value`.

**Pandas path:** used in every other case (any pd.DataFrame input, or an ArFrame with a non-numeric dtype such as `"string"`).
- `pd.to_numeric(errors="coerce")` is applied to both columns.
- Where the denominator is NaN or `== 0`, the denominator is masked to NaN.
- The result is `numerator / denominator` followed by `.fillna(fill_value)`.
- **A null numerator also yields `fill_value`**, because NaN/x is NaN and then gets filled.
- The output column is float64 and is appended as the last column. Existing columns are unchanged.
- ArFrame input returns `from_pandas(df)`, with attrs not preserved. DataFrame input returns a pd.DataFrame with the original index kept.

## 5. Side effects
- None.
- The pandas path assigns to `df.copy(deep=False)`, so the caller's DataFrame does not gain the new column.
- No global state is touched.

## 6. Branches and edge cases
- **pd input, numeric:**
  ```python
  pd.DataFrame({"n":[10.0,5.0,3.0,None],"d":[2.0,0.0,None,1.0]})
  ```
  `r` is `[5.0, 0.0, 0.0, 0.0]` with the default fill. With `fill_value=-1` it is `[5.0, -1.0, -1.0, -1.0]`.
- **pd input, int columns:** `{"n":[10,9],"d":[4,3]}` gives `[2.5, 3.0]`. The dtype is float64.
- **ArFrame with numeric strings (pandas path):** `ar.from_pandas(pd.DataFrame({"n":["10","20"],"d":[2,0]}))`.
  - This assumes the `"n"` dtype is `"string"`.
  - Result `r` is `[5.0, 0.0]`, and `n` stays a string column.
- **ArFrame with numeric columns (native path):** test only clear cases:
  - `{"n":[10.0,9.0],"d":[2.0,0.0]}` with `fill_value=-1.0` should give `[5.0,-1.0]`.
- **Same column twice:** `numerator == denominator` is allowed. `{"a":[2.0,0.0]}` gives `[1.0, 0.0]`.

## 7. Rules from docstring/comments
- Zero or null denominator is replaced with `fill_value`, never NaN or inf.
- An existing `output_column` raises ValueError.
- `fill_value` must be finite.

## 8. Testing hints
- **Prefer pd.DataFrame inputs** to pin exact pandas-path semantics, especially null numerator becoming `fill_value`.
  - Compare with `result["r"].tolist()`, or `pd.testing.assert_series_equal(..., check_names=False)`.
- **Use exactly representable values** such as 2.5 and 5.0. Use `pytest.approx` otherwise.
- **For ArFrame results**, use `ar.to_pandas(res)["r"].tolist()` and `res.columns[-1] == "r"`.
- **Check non-mutation:** after the call, assert `"r" not in original_df.columns`.
- **Check error messages** with `pytest.raises(X, match=re.escape(msg))`. Remember the trailing periods.
- **Pitfalls that would make a test wrong on the current code:**
  - Do not assert that attrs are preserved; they are not on either path.
  - Do not rely on C++-path behaviour for a null numerator, since it is unseen.
  - Avoid bool columns and empty strings: they go down the pandas path with unclear coercion.
  - Do not expect TypeError for a non-str `output_column`; it raises ValueError.

### arnio.cleaning.standardize_missing_tokens

# Notes: `arnio.cleaning.standardize_missing_tokens(frame, tokens=None, subset=None)`

## 1. Purpose
- Replaces string cells that look like missing-value tokens with `float("nan")`.
- Matching ignores case and surrounding whitespace.
- Accepts an ArFrame or a pandas DataFrame and returns the same kind of object.

## 2. Inputs
- **`frame`**: an `ArFrame` or a `pd.DataFrame`. Anything else raises TypeError.
  - An ArFrame is converted with `to_pandas(frame)`. A DataFrame is used directly.
  - In both cases the function works on `df.copy(deep=False)`.
- **`tokens`**: `None` or a `list` of `str`. A tuple or set is rejected.
  - `None` uses the defaults: `["N/A","NA","n/a","na","nan","-","none","nil","null","","?"]`.
  - A custom list replaces the defaults completely. It is not added to them.
  - Every token is normalised with `.strip().lower()`. The effective default set is `{"n/a","na","nan","-","none","nil","null","","?"}`.
  - `tokens=[]` means nothing is ever replaced.
- **`subset`**: `None` (all columns) or a sequence of column names.
  - A `list`, `tuple` or `pd.Index` is accepted.
  - An empty `[]` is allowed and replaces nothing.
  - Duplicate names are allowed.
  - Validation is done by `_validate_existing_column_sequence` with `missing_error=ValueError`.

## 3. Raises (checks run in this order)
1. Bad frame type: `TypeError("frame must be an ArFrame or a pandas DataFrame")`.
   - Trigger: `standardize_missing_tokens([1,2])`.
2. `subset` is a `str`:
   - Template: `TypeError(f"subset must be a list of column names, not a string. Did you mean subset=['{subset}']?")`.
   - `subset="a"` gives `"...Did you mean subset=['a']?"`.
3. `tokens` is a `str`:
   - Template: `TypeError(f"tokens must be a list of strings, not a bare string. Did you mean tokens=['{tokens}']?")`.
4. `tokens` is not a list:
   - Template: `TypeError(f"tokens must be a list of strings, got {type(tokens).__name__!r}")`.
   - `tokens=("x",)` gives `"tokens must be a list of strings, got 'tuple'"`.
5. A token item is not a `str`:
   - Template: `TypeError(f"tokens must be a list of strings, got {type(item).__name__!r} item")`.
   - `tokens=["x", 1]` gives `"... got 'int' item"`.
6. Only when `subset` is not None:
   - `subset` is bytes: `TypeError("subset must be a sequence of column names, not a string")`.
   - `subset` is a set or other non-Sequence: `TypeError("subset must be a sequence of column names")`.
   - A non-str name, e.g. `subset=[1]`: `TypeError("subset must contain only string column names")`.
   - A missing column: `ValueError(f"Unknown columns in subset: {missing}")`, where `missing` is a list repr.
   - `subset=["zz"]` gives `"Unknown columns in subset: ['zz']"`.
- Ordering pitfalls:
  - The `subset`-is-str check runs before any tokens check.
  - The column-existence check for `subset` runs last, after tokens validation.

## 4. Returns and guarantees
- **ArFrame in, ArFrame out.** The result is a new object built with `from_pandas(df)`.
  - Attrs are not explicitly copied, so do not assert on attrs.
- **DataFrame in, DataFrame out.** The result is the shallow copy, so it is not the input object (`result is not df`).
  - The index and column order are preserved.
- A cell is replaced only if `isinstance(value, str)` and `value.strip().lower()` is in the token set.
  - Replaced cells become `float("nan")`.
- All other cells are left unchanged, including ints, floats, bools, `None`, `pd.NA` and non-matching strings.
  - Non-matching strings keep their whitespace: `" kept "` stays `" kept "`.
- Whitespace-only strings (`"   "`, `"\t"`) normalise to `""`, which is a default token, so they become NaN.
- These values match by default:
  - `"NULL"`, `" None "`, `"\tNaN\t"`, `"N/A"`, `"NIL"`, `"-"`, `"?"`, `""`.
- These values do not match by default:
  - `"missing"`, `"#N/A"`, `"N.A."`, `"undefined"`, `"--"`, `"0"`.
- The dtype that ArFrame infers after the round-trip depends on `from_pandas` (convert module / C++), which this code does not show.

## 5. Side effects
- The input is not mutated.
  - For pandas input, `df[col] = ...map(...)` assigns a new Series on the shallow copy only.
  - The caller's DataFrame keeps its original values.
- There is no global state and no file I/O.

## 6. Branches and edge cases
- **`subset=None`**: every column is mapped, including numeric ones. Non-str values pass through.
- **`subset=["a"]`**: only column `a` changes. Tokens in other columns stay as strings.
  - Example: `{"a":["NA"],"b":["NA"]}` gives `a=[NaN]`, `b=["NA"]`.
- **`subset=[]`**: no columns are processed, so the output equals the input.
- **Custom tokens**: `tokens=["  MISSING "]` makes `"missing"` and `"Missing"` become NaN.
  - With custom tokens, `"N/A"` is no longer replaced.
- **`tokens=[]`**: nothing is replaced, not even `""`.
- **Zero rows**: works and returns an empty frame with the same columns.

## 7. Rules from the docstring
- "Matching is case-insensitive and trims surrounding whitespace before checking token membership."
- "Values that do not match a missing token preserve their original whitespace."
- The default token list is used when `tokens` is None.

## 8. Testing hints
- The pandas path is the most deterministic. Use object-dtype columns:
  ```python
  df = pd.DataFrame({"v": [" NULL ", "\tNaN\t", "kept ", "x"]})
  out = ar.standardize_missing_tokens(df)
  assert pd.isna(out["v"][0]) and pd.isna(out["v"][1])
  assert out["v"][2] == "kept " and out["v"][3] == "x"
  assert df["v"][0] == " NULL "   # input not mutated
  ```
- ArFrame path:
  - Build with `ar.from_pandas(pd.DataFrame({...}))`.
  - Check `isinstance(result, ar.ArFrame)`.
  - Inspect with `ar.to_pandas(result)` and use `pd.isna(...)`. Nulls may come back as `None` or `NaN`, so never compare with `==`.
  - Keep at least one real string in the column so it stays a string column.
- Pitfalls:
  - Do not assert the ArFrame dtype of mixed columns such as `[1, 2, "N/A"]`, or of columns that become all-null. That inference is in convert/C++ and is not shown here.
  - Avoid pandas `"string"` (StringDtype) inputs, because `.map` returning NaN has dtype-specific behaviour. Use object dtype instead.
  - For error messages, use `pytest.raises(..., match=re.escape(msg))`, since messages contain `[`, `'` and `?`.
