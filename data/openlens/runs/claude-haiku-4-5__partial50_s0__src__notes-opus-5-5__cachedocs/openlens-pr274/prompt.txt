## What is openlens?

openlens is a desktop application for designing and analyzing **glass optical
lenses and multi-element systems**. Whether you're a student learning optics, an
engineer designing optical systems, or a hobbyist exploring lens physics,
openlens provides an intuitive interface to:

- Design single lenses or assemblies with precise physical parameters
- Calculate first-order properties with thick-lens and paraxial models
- Experiment with different glass materials, surface profiles, and geometries
- Assign camera mounts and compute working flange distance
- Store and manage lenses, assemblies, and tolerance sets in SQLite
- Trace rays and inspect aberrations, spots, PSF/MTF, and wavefront error
- Export mechanical and manufacturing data as STL, STEP, or ISO 10110 drawings

## Installation

### Standalone executables (no Python required)

Every [release](https://github.com/pmaasz/openLens/releases/latest) includes
standalone builds for the desktop platforms:

| Platform | Download |
|----------|----------|
| Windows | `OpenLens-<version>-Windows.exe` |
| macOS (Apple silicon) | `OpenLens-<version>-macOS-arm64.zip` |
| macOS (Intel) | `OpenLens-<version>-macOS-x64.zip` |
| Linux | `OpenLens-<version>-Linux` |

Unzip a macOS download and drag `OpenLens.app` to Applications. The builds are
not code-signed, so the first launch needs **right-click -> Open** (or
**System Settings -> Privacy & Security -> Open Anyway**). On Linux, make the
downloaded file executable with `chmod +x`.

## Troubleshooting

### Issue: "No display name and no $DISPLAY environment variable" / Qt platform plugin errors

This occurs when running on a headless server or via SSH without X11 forwarding.

**Solutions:**
- **If using SSH**: Connect with X11 forwarding: `ssh -X user@host`
- **If running locally**: Ensure your display server is running (restart your desktop environment if needed)
- **For remote headless servers**: Use a virtual display:
  ```bash
  sudo apt-get install xvfb
  xvfb-run python3 -m openlens
  ```
  or force Qt's offscreen platform for testing:
  ```bash
  QT_QPA_PLATFORM=offscreen python3 -m openlens
  ```
- **WSL users**: Install an X server like VcXsrv or X410, then:
  ```bash
  export DISPLAY=:0
  python3 -m openlens
  ```

### Issue: PySide6 not found

**Error:** `ModuleNotFoundError: No module named 'PySide6'`

**Solution:**
```bash
pip install PySide6
# or
pip install -r requirements.txt
```

### Issue: Lenses not saving

**Solution:**
- Check write permissions in the directory
- Ensure `openlens.db` is not locked by another process
- Check disk space

### Issue: 3D visualization not working

**Solution:**
```bash
# Install required dependencies
pip install matplotlib numpy

# Or if using venv:
source venv/bin/activate
pip install matplotlib numpy
```

## First lens

```python
from openlens.lens import Lens

lens = Lens(
    name="Biconvex demo",
    radius_of_curvature_1=50.0,
    radius_of_curvature_2=-50.0,
    thickness=5.0,
    diameter=25.0,
    material="BK7",
)

print(lens.calculate_focal_length())
print(lens.calculate_back_focal_length())
print(lens.calculate_working_flange_distance())
```

## Trace rays

```python
from openlens.ray_tracer import LensRayTracer

tracer = LensRayTracer(lens)
rays = tracer.trace_parallel_rays(num_rays=11)
```

## Analyze image quality

```python
from openlens.aberrations import AberrationsCalculator
from openlens.performance_metrics import PerformanceMetrics

aberrations = AberrationsCalculator(lens).calculate_all_aberrations(field_angle_deg=5.0)
report = PerformanceMetrics(lens).format_metrics_report()
```

Failed traces and undefined quantities return `None`; check before formatting.
For multi-element systems, use `OpticalSystem` from
`openlens.optical_system`. For persistence, use `DatabaseManager` or the GUI
`LensStorage` facade; JSON is an interchange format, not primary state.

## 📊 Quality Assessment System

### Automatic Quality Scoring (0-100)
The system analyzes aberrations and assigns a quality score:

**Excellent (90-100):**
- Spherical aberration < 0.001 mm
- Chromatic aberration < 0.1 mm
- Distortion < 1%
- Astigmatism < 0.1 mm

**Good (75-89):**
- Moderate aberrations
- Suitable for general optical applications

**Fair (60-74):**
- Noticeable aberrations
- May be acceptable for specific uses

**Poor (40-59):**
- Significant aberrations
- Design optimization recommended

**Very Poor (<40):**
- Severe aberrations
- Redesign necessary

### Issue Detection
Automatically identifies and reports:
- High spherical aberration
- Excessive chromatic aberration
- Significant distortion
- Problematic astigmatism

## 📚 Mathematical Foundations

### Formulas Implemented

1. **Spherical Aberration:**
   Exact trace (fallback: third-order Seidel):
   ```
   LSA = marginal focus - paraxial focus   (paraxial ray at y = 0.001 mm)
   LSA_Seidel = -(y²/8f)·[(n/(n-1))² + (n+2)/(n(n-1)²)·(B + 2(n²-1)/(n+2)·C)²]
   B = (c1+c2)/(c1-c2)  [shape factor from curvatures; flat c = 0], C = -1
   ```

2. **Coma:**
   ```
   Coma = (err_top + err_bottom) / 2   (traced tangential fan, chief-referenced)
   ```

3. **Astigmatism:**
   ```
   AST = |tan_focus - sag_focus|   (traced best-focus split, longitudinal)
   ```

4. **Field Curvature:**
   ```
   R_petzval = n · f
   ```

5. **Distortion:**
   ```
   Dist = 0  (single lens, stop at lens: S5 = 0 exactly)
   General stops: traced distortion curve (chief-ray heights)
   ```

6. **Chromatic Aberration:**
   ```
   LCA = f / V_d            (single thin lens)
   LCA = BFL_C - BFL_F      (systems: traced back focal lengths)
   V_d = Abbe number
   ```

7. **Airy Disk:**
   ```
   d_airy = 2.44 · λ · (f/D)
   ```

## 📝 Notes

### Known Limitations
1. **Single Lens Only:** Aberrations calculated for individual lenses, not systems
2. **Paraxial Approximation:** Uses third-order (Seidel) aberrations
3. **Monochromatic:** LCA calculated, but not full spectral analysis
4. **Simplified Formulas:** Professional tools use more complex ray tracing

### Design Decisions
- Used Seidel aberrations (industry standard for first-order analysis)
- Included Abbe number database for common materials
- Provided quality scoring for quick assessment
- Formatted output for readability

Features
--------

* **Interactive lens design** with spherical, conic, parabolic, and Fresnel
  surfaces, clear apertures, bevels, and coatings.
* **Multi-element assemblies** with air gaps, an aperture stop, element
  alignment, nesting, and undo/redo.
* **Ray tracing** in 2-D and 3-D, including point sources, off-axis fields,
  multiple wavelengths, ghosts, and total internal reflection.
* **Image quality** through Seidel aberrations, spot diagrams, PSF, MTF,
  wavefront error, Strehl ratio, and encircled energy.
* **Design tools** for optimization, tolerancing, thermal/environmental
  perturbations, and desensitization.
* **Mechanical and manufacturing** output: camera mounts, working flange
  distance, lens cells, spacers, STL/STEP solids, and ISO 10110-style drawings.
* **SQLite library** for lenses, assemblies, and tolerance sets, with JSON
  interchange and image/report export.
* **Material catalog** with Sellmeier dispersion, thermal expansion, and
  Schott TIE-19 temperature coefficients where available.
* **Optional dependencies** are guarded: the core model and ray tracer start
  without numpy, matplotlib, scipy, or Pillow.

## ===== docs/sphinx/source/user_guide.rst =====

GUI Overview
------------

The main window keeps one active target: either a single lens or an optical
assembly. Selecting a library row loads that target into the editor tabs.

Selection Tab
^^^^^^^^^^^^^

The **Selection** tab is the library browser. It supports:

- browsing and filtering lenses and assemblies;
- loading a row into the active-target tabs;
- creating, duplicating, renaming, and deleting library records;
- saving to the SQLite library;
- importing/exporting JSON for interchange.

The default library is a per-user SQLite database. The status bar reports save
and load failures; a failed save is never presented as a success.

Lens Editor Tab
^^^^^^^^^^^^^^^

The **Lens Editor** edits a single element and shows calculated properties as
the prescription changes.

**Surface parameters**

- Radius of curvature for each surface, in millimetres.
- Optional conic constant for each surface.
- Legacy parabolic sag control where a measured sag is preferred.
- Clear aperture and bevel for each surface.

**Geometry and material**

- Centre thickness and mechanical diameter.
- Material from the catalog, or a model glass defined by ``nd``/``Vd``.
- Design wavelength and operating temperature.
- Refractive index, either resolved from the selected glass or entered for a
  model glass.

**Coatings**

Each surface can carry a thin-film stack. Coating presets can be loaded from
the coating tools; the stack modulates reflected/transmitted energy while the
geometric ray direction continues to follow Snell's law.

**Calculated properties**

The panel updates focal length, optical power, back and front focal lengths,
working flange distance, edge thickness, and feasibility warnings. Thin or
negative edge thickness warnings mean the surfaces intersect inside the clear
aperture and the shape is not manufacturable as drawn.

Camera Mounts
^^^^^^^^^^^^^

The **Mount** group assigns a camera mount to the lens. It reports the
**working flange distance**, measured from the rear lens vertex to the sensor
plane:

.. code-block:: text

   working flange distance = back focal length + mount flange distance

Built-in mounts are C, CS, M42, M39, T, Fujifilm X, Leica M, Canon EF, and
Nikon F. Use **Manage mounts…** to add a custom mount from its flange
distance. Custom mounts are shared by every lens and stored in ``mounts.json``
under the per-user OpenLens data directory; ``OPENLENS_MOUNTS_PATH`` overrides
the file location.

.. code-block:: python

   from openlens.lens import Lens

   lens = Lens(radius_of_curvature_1=50.0, radius_of_curvature_2=-50.0)
   lens.mount_type = "M42"
   print(lens.calculate_working_flange_distance())

If the lens is afocal or the mount is unknown, the distance is ``None``. The
mount is saved with the lens in the SQLite library.

Assembly Tab
^^^^^^^^^^^^

The **Assembly** tab edits a multi-element ``OpticalSystem``:

- add, remove, reorder, and nest lens elements;
- set the air gap before each element;
- place an aperture stop in a gap and set its diameter;
- apply decenter and tilt to individual elements;
- inspect the optical layout and element positions;
- edit tolerances and alignment values for the assembly.

Assembly edits are undoable. The window-level undo/redo controls follow the
active lens editor or assembly stack.

Simulation Tab
^^^^^^^^^^^^^^

The **Simulation** tab traces rays through a lens or assembly:

- choose a parallel fan or point source;
- set ray count, field angle, and ray height range;
- trace at one or more wavelengths;
- enable ghost reflections to inspect unwanted paths;
- place the detector at an absolute image plane, or leave it on **Auto** for
  the paraxial focus. The view marks a configured plane and reports the RMS
  spot measured there in either mode; the Performance spot metric and the
  optimizer's RMS-spot target use the same plane;
- switch between 2-D and 3-D views;
- clear the trace and reset the view without changing the optical model.

Vignetted rays are dropped at clear apertures or the system stop. The status
area reports the trace result; a failed trace is not replaced by an empty
“perfect” image.

Performance Tab
^^^^^^^^^^^^^^^

The **Performance** tab calculates the image-quality dashboard:

- first-order values (EFL, BFL, f-number, numerical aperture);
- Seidel spherical, coma, astigmatism, field curvature, and distortion;
- axial and lateral chromatic estimates;
- RMS spot size and AIRY disk diameter;
- Strehl ratio and RMS wavefront error;
- MTF cutoff;
- spot diagram, ray fan, field curves, PSF, MTF, wavefront, and ghost views.

Expensive calculations run in background workers. If a trace or wavefront
sample fails, the affected field is reported as unavailable or invalid instead
of zero. See :doc:`scientific/image_quality` for the definitions and limits of
each metric.

Optimization Tab
^^^^^^^^^^^^^^^^

The **Optimization** tab builds a merit function from variables and targets:

- choose radii, thicknesses, air gaps, and selected system parameters as
  variables;
- target focal length, back focal length, aberration values, or other metrics;
- run the default simplex optimizer, or choose another available algorithm;
- inspect the merit value and variable values after convergence.

The merit function penalizes invalid geometry such as negative edge thickness.
Optimization runs on a copy of the model until the result is applied, so a
cancelled run does not leave a half-mutated assembly behind.

Tolerancing Tab
^^^^^^^^^^^^^^^

The **Tolerancing** tab studies manufacturing and environmental variation:

- define tolerance sets for radii, thickness, gaps, decentre, tilt, and index;
- run sensitivity or Monte Carlo analysis;
- inspect the distribution of spot, MTF, or other image-quality metrics;
- save tolerance sets with the lens or assembly metadata.

A nominal design with a small spot but no tolerance margin is not yet a
manufacturable design. Compensators and focus adjustment should be included
explicitly.

Startup and Updates
-------------------

The welcome screen checks the latest GitHub release in the background while the
rest of the window stays responsive. Under the title it reports one of:

- the running version is up to date;
- a newer version is available;
- the newer release has no build for the current operating system and
  architecture;
- the check could not reach GitHub.

The check is advisory. A network failure never blocks startup and never opens
an error dialog; use **Retry** on the welcome screen to check again.

When a compatible newer release exists, the available action depends on how
OpenLens was installed:

Standalone Linux and Windows build
    **Download and install** fetches the release asset, waits for the current
    process to exit, replaces the executable, and starts the new version. If
    the replacement cannot be written, the old executable is started again and
    the reason is written to ``openlens-update-error.log`` beside the
    downloaded file.

Standalone macOS build
    **Download and install** fetches the matching ``macOS-arm64`` or
    ``macOS-x64`` archive, extracts it under ``~/Downloads``, and opens the new
    application bundle. Drag that bundle to **Applications** to keep it, then
    close the old copy.

Source checkout or pip install
    **Download from GitHub** opens the release page. OpenLens does not replace
    a Python-managed installation behind the package manager's back.

After a standalone update restarts, the new version opens the SQLite library
normally. Schema migrations run as part of database initialization, so an
update that changes the schema upgrades the existing library in place. Back up
the database before skipping several major versions.

.. note::

   The update check contacts the public GitHub Releases API at startup. It
   sends no library data, only a request for the latest release metadata. Set
   ``OPENLENS_NO_UPDATE_CHECK=1`` to skip the request; the welcome screen then
   shows only the running version.

Ray Tracing
-----------

The UI ray tracer and the Python tracers share the same surface intersection
and refraction code. A parallel fan is launched relative to the front vertex;
the default fills the full aperture so rim aberration is included. Point
sources use a position and an angular range. Off-axis analysis rotates or
displaces the bundle instead of changing the lens model.

For a first-order check, use the paraxial matrix results (EFL, BFL, FFL).
For a real design, inspect the ray fans and spot diagrams at the intended
field and wavelength.

Mounts and Mechanical Output
----------------------------

**File → Export** provides:

- **STL** for lens solids and printable models;
- **STEP** for lenses plus suggested cells, spacers, and a barrel;
- **ISO 10110** for a manufacturing-style drawing;
- **Report** for a text/plot summary.

The STEP housing is derived from the current assembly and mount. Threads are
specified in the part name but are not modeled as helical solids without a CAD
kernel. Treat the suggested housing as a mechanical starting point and verify
it in CAD before manufacture.

Persistence and Interchange
---------------------------

SQLite is the application's source of truth. **Save** updates the active
library record; **Save As...** writes a JSON copy. JSON is also used for
import/export and for user preferences such as custom mounts, but it is not the
primary library.

A lens stores its mount type, wavelength, temperature, conic/parabolic terms,
clear apertures, bevels, coatings, and metadata. An assembly stores its element
order, air gaps, stop, alignment, and tolerance metadata. Round-tripping through
SQLite or JSON preserves those fields.

## ===== docs/sphinx/source/scientific/optics.rst =====

Optical Model
=============

This page collects the conventions and equations that OpenLens uses for
first-order layout, surface shape, and ray refraction. It is deliberately
close to the implementation so a calculated number can be reproduced by hand.

.. contents:: Table of Contents
   :local:
   :depth: 2

Sign Convention
---------------

OpenLens uses the usual Cartesian optical convention:

- Light propagates from left to right along the positive *x* axis.
- Surface vertices are the reference points for surface coordinates.
- A radius is positive when the centre of curvature lies to the right of the
  surface vertex. For a biconvex lens in air, ``R1 > 0`` and ``R2 < 0``.
- Distances to the right of a reference are positive.
- A converging element has positive effective focal length (EFL).
- Angles are measured from the optical axis; the ray tracer stores them in
  radians internally.

The Lens model uses the helium d-line, 587.6 nm, as its default design
wavelength and for ``nd``/``Vd`` catalog data. Visualization, spot diagrams,
PSF/MTF, and resolution defaults use the photopic green line, 550 nm.

Surface Shape
-------------

Spherical sag
^^^^^^^^^^^^^

For a spherical surface of radius ``R``, the vertex-referenced sag at radial
height ``r`` is

.. math::

   z(r) = \operatorname{sgn}(R)\left(|R| - \sqrt{R^2 - r^2}\right).

Flat surfaces have ``z = 0``. OpenLens clamps ``|r|`` to the real domain so a
ray outside the sphere's cap does not produce a complex sag.

Conic sag
^^^^^^^^^

A conic surface is described by the vertex radius ``R`` and conic constant
``K``:

.. math::

   z(r) = \frac{c r^2}{1 + \sqrt{1 - (1+K)c^2 r^2}},
   \qquad c = \frac{1}{R}.

The common special cases are:

- ``K = 0``: sphere.
- ``K = -1``: paraboloid.
- ``-1 < K < 0``: prolate ellipsoid.
- ``K > 0``: oblate ellipsoid.
- ``K < -1``: hyperboloid.

OpenLens also supports the older parabolic control, which stores the sag at
the half-diameter and scales it as ``z(r) = z_{D/2}(r/(D/2))^2``. The conic
model is preferred when an exact conic constant is known.

Lensmaker's Equation
--------------------

For a thick lens in air with refractive index ``n``, centre thickness ``d``
and surface radii ``R1`` and ``R2``:

.. math::

   \frac{1}{f} = (n-1)\left(
   \frac{1}{R1} - \frac{1}{R2}
   + \frac{(n-1)d}{n R1 R2}
   \right).

A flat surface contributes ``1/R = 0``. A plane-parallel plate therefore has
zero power, as expected. For a thin lens (``d`` small compared with the
radii), the last term is omitted.

Back and Front Focal Lengths
^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The back focal length (BFL) is measured from the rear vertex to the rear
paraxial focus:

.. math::

   \mathrm{BFL} = f\left(1 - \frac{d P_1}{n}\right),
   \qquad P_1 = \frac{n-1}{R1}.

The front focal length (FFL) is a signed Cartesian coordinate measured from
the front vertex. For a converging lens the front focus lies to the left, so
the coordinate is negative:

.. math::

   \mathrm{FFL} = -f\left(1 - \frac{d P_2}{n}\right),
   \qquad P_2 = \frac{1-n}{R2}.

Both return ``None`` for an afocal element where the focal length is
undefined.

Camera Mounts and Working Flange
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

A camera mount fixes the sensor plane a specified flange distance behind the
mounting face. OpenLens models the mount as being at the lens rear vertex, so

.. math::

   \text{working flange distance} = \mathrm{BFL} + \text{mount flange distance}.

For example, a lens with a 27.93 mm BFL and an M42 mount (45.46 mm) has a
working flange distance of 73.39 mm. If the mount is unknown, or the lens is
afocal, the result is ``None`` rather than an assumed value.

Apertures, Bevels, and Stops
----------------------------

- The mechanical diameter is the outer lens diameter.
- A clear aperture, when set, is the polished optical aperture of that
  surface. Rays outside it are vignetted.
- Bevels model the protective chamfer at the rim and reduce the usable clear
  aperture near the edge.
- An optical system may define an aperture stop in an air gap. The stop has a
  diameter and is applied before the following element; rays outside it are
  blocked and reported as vignetted.
- Surface profiles are clamped to their real domain at the rim. A diameter
  larger than a spherical cap can support is therefore a validation issue, not
  a reason to invent a complex surface.

Ray Fans and Field Points
-------------------------

A parallel fan at angle ``θ`` is launched from a plane in front of the first
vertex. Its heights are chosen across a fraction of the semi-aperture; the
default is the full aperture so rim spherical aberration is included. Point
sources launch rays from a specified position with angles spanning a requested
range. Off-axis field analysis uses the same tracing machinery with a rotated
or displaced ray bundle.

## ===== docs/sphinx/source/scientific/image_quality.rst =====

Image Quality
=============

A lens prescription determines first-order properties, but two lenses with the
same focal length can form very different images. OpenLens reports both
geometric and diffraction-based measures. This page explains what each number
means and when it is trustworthy.

.. contents:: Table of Contents
   :local:
   :depth: 2

Seidel Aberrations
------------------

OpenLens reports the five primary (third-order) aberrations. Some are
calculator estimates from first-order parameters; field-dependent coma,
astigmatism, field curvature, and distortion use traced off-axis rays.

Spherical aberration
    Longitudinal shift between the paraxial focus and the marginal-ray focus.
    It is present on axis and grows rapidly with aperture. Stopping down
    reduces it.

Coma
    An off-axis aberration that makes a point source look like a comet.
    OpenLens estimates it from the asymmetry of the traced ray fan.

Astigmatism
    The tangential and sagittal ray fans focus at different distances. The
    reported value is the longitudinal separation of those foci.

Field curvature
    The image surface is curved rather than flat: best focus changes with
    field angle. A flat sensor therefore cannot be in focus everywhere.

Distortion
    The image height is not proportional to the ideal ``f tan θ`` mapping.
    Distortion moves points but does not by itself blur a point.

For a single spherical lens, third-order Seidel distortion is zero by
construction; the traced distortion curve is the useful measure.

Chromatic Aberration
--------------------

The refractive index depends on wavelength. OpenLens reports longitudinal
chromatic aberration as the focus shift between spectral lines. The Abbe
number is the usual first-order measure:

.. math::

   V_d = \frac{n_d - 1}{n_F - n_C}.

A low Abbe number means high dispersion and usually more chromatic
aberration. The calculation uses the material's catalog value where possible;
otherwise it falls back to a coarse estimate based on refractive index. Treat
that fallback as an estimate, not a measured glass property.

Achromatic Doublets
^^^^^^^^^^^^^^^^^^^

Combining a positive crown element with a negative flint element can bring two
wavelengths to a common focus. The cemented-doublet tools and optimizer in
OpenLens expose the element radii and glass choice as variables. A good
first-order achromat still needs a real ray check for spherical aberration and
manufacturing tolerances.

PSF
---

The point spread function is the image of an ideal point source. OpenLens can
compute it in two ways:

Geometric PSF
    Bin traced ray intersections on a detector grid. This is cheap and shows
    the geometric blur, but it ignores diffraction and can be noisy with few
    rays. The window grows to cover the traced spot; the result reports how
    much of the traced energy was captured. A low captured fraction means the
    PSF is clipped by the detector, not that the lens is perfect.

Diffraction PSF
    Take the complex pupil function from the traced wavefront and propagate it
    with an FFT. This includes diffraction and defocus, and is the appropriate
    model near the diffraction limit. It needs ``numpy`` and a sampled pupil.

The PSF is normalized so its integral represents the captured energy. When a
metric is computed from a clipped PSF, the report should be read together with
the captured fraction.

Strehl Ratio and Wavefront Error
--------------------------------

The Strehl ratio is the ratio of the aberrated peak irradiance to the ideal
peak. OpenLens obtains it from the traced pupil wavefront:

.. math::

   S = \left|\left\langle e^{i 2\pi W}\right\rangle\right|^2,

where ``W`` is the wavefront error in waves after piston and tilt are removed.
For small aberrations this is close to the Maréchal approximation

.. math::

   S \approx e^{-(2\pi\sigma)^2},

with ``σ`` the RMS wavefront error in waves. A Strehl ratio of 0.8 or above is
often treated as “diffraction limited”, but the threshold is a convention, not
a hard physical boundary.

Wavefront maps are sampled on a pupil grid. If too few rays reach the pupil,
the result is reported as unavailable rather than as a good wavefront.

Through-Focus and Tolerancing
-----------------------------

Image quality changes with focus. OpenLens can evaluate metrics at a requested
focus shift instead of assuming the paraxial image plane. A lens or assembly
can also pin an absolute detector plane with ``image_plane_x_mm``: spot-based
analyses, the RMS spot metric, and the optimizer's RMS-spot target then
measure at that plane. An unset plane keeps the paraxial focus as the default.
Tolerancing extends
this idea to manufacturing errors: element decentre, tilt, thickness, radius,
and index perturbations are sampled, and the resulting metric distribution is
reported. A nominal design with a good spot but no tolerance margin is not a
manufacturable design.

What the Numbers Do Not Cover
-----------------------------

- Geometric ray tracing ignores diffraction until the diffraction PSF/MTF
  branch is selected.
- Scalar diffraction does not model polarization or vector pupil effects;
  those need the coating/polarization models.
- A single-wavelength MTF does not describe a broadband image. Use the
  chromatic tools and multiple wavelengths.
- Ghost analysis follows unwanted reflections but does not predict sensor
  blooming or stray light outside the modeled aperture.
- Manufacturing tolerances are statistical inputs. The output is only as good
  as the distributions and compensators supplied.

Where to Look in the Code
-------------------------

- ``openlens/aberrations.py``: Seidel estimates, chromatic, Airy, Strehl.
- ``openlens/analysis/spot_diagram.py``: spot and encircled energy.
- ``openlens/analysis/geometric.py``: field curves and distortion.
- ``openlens/analysis/psf_mtf.py``: geometric and diffraction PSF/MTF.
- ``openlens/analysis/diffraction_psf.py``: pupil wavefront propagation.
- ``openlens/tolerancing.py``: Monte Carlo and sensitivity analysis.

## ===== docs/sphinx/source/scientific/thermal_mechanical.rst =====

Thermal Scaling
---------------

For a change in temperature ``ΔT`` from the 20 °C reference, a material with
linear coefficient of thermal expansion ``α`` changes its dimensions by

.. math::

   L(T) = L_0 \left(1 + \alpha \Delta T\right).

OpenLens applies this factor to the lens radii, centre thickness, diameter,
and - when a housing coefficient is supplied - to the air gaps. The radii and
thickness scaling preserves the shape of a homogeneous element to first order.
It is not a thermo-elastic finite-element model: it does not predict stress,
bending, or a cemented-interface failure.

The refractive index also changes. Catalog glasses can carry Schott TIE-19
coefficients ``D0``, ``D1``, ``D2``, ``E0``, ``E1`` and a thermal resonance
wavelength. When they are present, OpenLens evaluates

.. math::

   \Delta n = \frac{n^2-1}{2n}\left[
   D_0\Delta T + D_1\Delta T^2 + D_2\Delta T^3
   + \frac{E_0\Delta T + E_1\Delta T^2}{\lambda^2-\lambda_{tk}^2}
   \right],

with wavelength in micrometres. All-zero coefficients mean “no thermal data”,
and no correction is applied. A model glass defined only by ``nd``/``Vd`` has
no temperature coefficients either; its index is not invented.

Housing Expansion
-----------------

The air gaps are set by the mechanical housing, not by the glass. A first-order
estimate scales every gap by

.. math::

   g(T) = g_0 \left(1 + \alpha_\text{housing}\Delta T\right).

The default housing coefficient is aluminium, ``23.6 × 10⁻⁶ /K``. Steel is
roughly ``12 × 10⁻⁶ /K``, Invar ``1 × 10⁻⁶ /K``, and common plastics can be
tens to hundreds of ``10⁻⁶ /K``. Using the wrong housing coefficient can
change focus by more than the glass expansion does, especially in a long
assembly.

This is a uniform scaling model. A real barrel has a front and rear section,
retainers, and possibly different materials; those require a mechanical model
or a tolerance sensitivity study.

Where to Look in the Code
-------------------------

- ``openlens/analysis/environmental.py``: CTE, dn/dT, air index, conditioning.
- ``openlens/material_database.py``: thermal coefficients and glass data.
- ``openlens/mechanical_designer.py``: cells, spacers, barrel, mounts.
- ``openlens/mounts.py``: standard and custom flange distances.
- ``openlens/tolerancing.py``: perturbation, Monte Carlo, reports.
- ``openlens/io/step_export.py``: STEP solids for lenses and housings.

# openlens.aberrations.analyze_lens_quality
def analyze_lens_quality(lens: Any, field_angle: float = 5.0, **kwargs) -> Dict[str, Any]:
    """
    Convenience function to analyze lens quality.

    Args:
        lens: Lens object
        field_angle: Field angle for off-axis aberrations (degrees)
        wavelength_nm: Wavelength in nm evaluated throughout (kwarg)

    Returns:
        Dictionary with quality assessment
    """
    # Handle backward compatibility
    field_angle = kwargs.get("field_angle_deg", field_angle)
    wavelength_nm = kwargs.get("wavelength_nm", WAVELENGTH_GREEN)

    calc = AberrationsCalculator(lens)
    results = calc.calculate_all_aberrations(field_angle=field_angle, wavelength_nm=wavelength_nm)

    if results.get("error"):
        return {"quality_score": 0, "rating": "Error", "issues": [results["error"]]}

    issues = []
    score = 100

    # Evaluate spherical aberration
    sa = abs(results["spherical"])
    if sa > SPHERICAL_ABERRATION_EXCELLENT:
        issues.append(f"High spherical aberration ({sa:.4f} mm)")
        score -= 40  # Major SA penalty
    elif sa > (SPHERICAL_ABERRATION_EXCELLENT / 10):
        issues.append(f"Moderate spherical aberration ({sa:.4f} mm)")
        score -= 20  # Minor SA penalty

    # Evaluate chromatic aberration
    ca = results["chromatic"]
    if ca > 0.5:  # Significant chromatic aberration
        issues.append(f"High chromatic aberration ({ca:.4f} mm)")
        score -= 40  # Major SA penalty
    elif ca > 0.1:
        issues.append(f"Moderate chromatic aberration ({ca:.4f} mm)")
        score -= 20  # Minor SA penalty

    # Evaluate distortion
    dist = results["distortion"]
    dist_abs = abs(dist)
    if dist_abs > 5:
        issues.append(f"High distortion ({dist_abs:.2f}%)")
        score -= 15
    elif dist_abs > 1:
        issues.append(f"Moderate distortion ({dist_abs:.2f}%)")
        score -= 5

    # Evaluate astigmatism
    ast = results["astigmatism"]
    if ast > 1.0:  # Large astigmatism
        issues.append(f"High astigmatism ({ast:.4f} mm)")
        score -= 15  # Astigmatism penalty
    elif ast > 0.1:  # Moderate astigmatism
        issues.append(f"Moderate astigmatism ({ast:.4f} mm)")
        score -= 5

    # Determine rating
    if score >= (QUALITY_EXCELLENT_THRESHOLD + 5):  # 90
        rating = "Excellent"
    elif score >= (QUALITY_GOOD_THRESHOLD + 5):  # 75
        rating = "Good"
    elif score >= (QUALITY_FAIR_THRESHOLD + 10):  # 60
        rating = "Fair"
    elif score >= (QUALITY_FAIR_THRESHOLD - 10):  # 40
        rating = "Poor"
    else:
        rating = "Very Poor"

    return {
        "quality_score": score,
        "rating": rating,
        "issues": issues if issues else ["No significant aberrations detected"],
        "aberrations": results,
    }

# openlens.image_simulator.ImageSimulator.simulate_image
    def simulate_image(
        self,
        input_image: np.ndarray,
        object_distance: float,
        image_distance: Optional[float] = None,
        wavelength: float = WAVELENGTH_D_LINE,
        pixel_pitch_mm: float = 0.01,
    ) -> Dict[str, Any]:
        """
        Simulate image formation through the optical system.

        Args:
            input_image: Input image array (H, W, C) or (H, W)
            object_distance: Distance from lens to object
            image_distance: Distance from lens to image (None for auto)
            wavelength: Wavelength in nm
            pixel_pitch_mm: Sensor pixel pitch in mm (for vignetting scale)

        Returns:
            Dictionary with simulated image and metrics
        """
        # Calculate image distance if not provided
        if image_distance is None:
            image_distance = self._calculate_image_distance(object_distance, wavelength)

        # Apply aberrations
        aberrated_image = self._apply_aberrations(
            input_image,
            object_distance,
            image_distance,
            wavelength,
            pixel_pitch_mm=pixel_pitch_mm,
        )

        # Apply diffraction
        diffracted_image = self._apply_diffraction(
            aberrated_image, wavelength, pixel_pitch_mm=pixel_pitch_mm
        )

        # Apply chromatic aberration if color image
        if len(diffracted_image.shape) == 3:
            final_image = self._apply_chromatic_aberration(
                diffracted_image, object_distance, image_distance
            )
        else:
            final_image = diffracted_image

        # Apply vignetting
        final_image = self._apply_vignetting(
            final_image,
            image_distance_mm=image_distance,
            pixel_pitch_mm=pixel_pitch_mm,
        )

        # Calculate metrics
        metrics = self._calculate_image_metrics(input_image, final_image)

        return {
            "output_image": final_image,
            "magnification": -image_distance / object_distance,
            "image_distance": image_distance,
            "metrics": metrics,
        }

# openlens.optical_system.OpticalSystem.calculate_chromatic_aberration
    def calculate_chromatic_aberration(self) -> Dict[str, Any]:
        """Calculate system longitudinal chromatic aberration using standard F, d, C lines.

        For each line the system matrix is rebuilt with wavelength-correct
        indices, giving both the back focal length (BFL = -A/C, the
        observable focus position) and the effective focal length
        (EFL = -1/C). The ``f_*`` keys are true EFLs, not copies of BFL.
        """
        # Standard Fraunhofer lines in nm
        lines = {
            "F": WAVELENGTH_F_LINE,  # Blue
            "d": WAVELENGTH_D_LINE,  # Yellow (Reference)
            "C": WAVELENGTH_C_LINE,  # Red
        }

        bfls: Dict[str, Optional[float]] = {}
        efls: Dict[str, Optional[float]] = {}
        for line, wl in lines.items():
            n_map = {i: el.lens.refractive_index_at(wl) for i, el in enumerate(self.elements)}
            matrix = self._calculate_system_matrix(n_overrides=n_map)
            if matrix and abs(matrix[2]) > 1e-10:
                A, B, C, D = matrix
                bfls[line] = -A / C
                efls[line] = -1.0 / C
            else:
                bfls[line] = None
                efls[line] = None

        if bfls["F"] is not None and bfls["C"] is not None:
            longitudinal = bfls["C"] - bfls["F"]
            return {
                "longitudinal": longitudinal,
                "bfl_F": bfls["F"],
                "bfl_d": bfls["d"],
                "bfl_C": bfls["C"],
                "f_F": efls["F"],
                "f_d": efls["d"],
                "f_C": efls["C"],
                "corrected": abs(longitudinal) < 0.1,
            }
        return {"longitudinal": 0.0, "corrected": False}

# openlens.optical_system.OpticalSystem.load
    @staticmethod
    def load(filename: str) -> Optional["OpticalSystem"]:
        """Load optical system from JSON file.

        The file is size-capped and every number is checked for NaN/Infinity:
        ``json.load`` accepts the non-standard bare literals, and a NaN that
        reaches the model compares false against every sanity threshold and
        silently disables downstream checks.

        A file written by an older version spells a flat surface as the bare
        ``Infinity`` literal. Those radii are converted to the JSON spelling
        (null) before the check, so such a file still loads while every other
        non-finite value is still rejected.
        """
        try:
            reject_oversized_file(filename)
            with open(filename, "r") as f:
                data = json.load(f)
            data = json_safe_radii(data)
            reject_non_finite_numbers(data, "optical system")
            return OpticalSystem.from_dict(data)
        except Exception as e:
            logger.error("Error loading optical system: %s", e)
            return None

# openlens.tracer_3d.LensRayTracer3D.trace_surface
    def trace_surface(
        self, ray: Ray3D, surface_type: str, interaction: str = "refract"
    ) -> RefractionResult:
        """Trace ray interaction with a specific surface."""
        if surface_type == "front":
            center = self.front_center
            is_flat = self.front_is_flat
            is_parabolic = self.front_is_parabolic
            is_conic = self.front_is_conic
            conic_constant = self.conic_constant_1
            vertex = self.front_vertex
            R = self.R1
            default_n1 = REFRACTIVE_INDEX_AIR
            default_n2 = self.n
        elif surface_type == "back":
            center = self.back_center
            is_flat = self.back_is_flat
            is_parabolic = self.back_is_parabolic
            is_conic = self.back_is_conic
            conic_constant = self.conic_constant_2
            vertex = self.back_vertex
            R = self.R2
            default_n1 = self.n
            default_n2 = REFRACTIVE_INDEX_AIR
        else:
            return RefractionResult.MISSED

        fresnel_facets = self.fresnel_facets_1 if surface_type == "front" else self.fresnel_facets_2
        fresnel_hit = None
        if fresnel_facets:
            fresnel_hit = self._intersect_fresnel_surface(ray, surface_type)
            if fresnel_hit is None:
                return RefractionResult.MISSED
            intersection, normal = fresnel_hit
            is_flat = False
            is_parabolic = False
            is_conic = False
        elif is_parabolic:
            # R is the effective vertex radius (may be negative).
            if abs(R) < EPSILON or abs(R) > 1e10:
                normal = -self.optical_axis if surface_type == "front" else self.optical_axis
                intersection = self._intersect_plane(ray, vertex, self.optical_axis)
            else:
                normal = None  # gradient-based: oriented outward below
                intersection = self._intersect_paraboloid(ray, vertex, R, surface_type)
        elif is_conic:
            normal = None  # gradient-based: oriented outward below
            intersection = self._intersect_conic(ray, vertex, R, conic_constant, surface_type)
        elif is_flat:
            normal = self.optical_axis
            intersection = self._intersect_plane(ray, vertex, normal)
        else:
            intersection = self._intersect_sphere(ray, center, abs(R), (R > 0))

        if intersection is None:
            # No forward intersection with this surface (the ray line misses
            # the sphere/paraboloid/plane entirely). This is a miss however
            # the ray got here: report MISSED with state unchanged so the
            # caller terminates the ray, exactly like the 2D tracer. (A ray
            # that has somehow crossed the surface already must NOT be
            # fabricated into a transmitted ray: returning REFRACTED here
            # would leave origin/direction stale while flipping n to air.)
            return RefractionResult.MISSED

        v_to_i = intersection - vertex
        proj = v_to_i.dot(self.optical_axis)
        dist_sq = v_to_i.magnitude_sq() - proj**2

        aperture_sq = self._aperture_sq_front if surface_type == "front" else self._aperture_sq_back
        if dist_sq > aperture_sq:
            return RefractionResult.MISSED

        # Accumulate optical path for the segment just travelled in the
        # current medium (air gap before the front surface, glass between
        # the surfaces). Without this, Ray3D.optical_path_length would only
        # contain the exit-propagation leg and every OPL difference (hence
        # every wavefront map) would be wrong by ~millimetres of glass path.
        segment = intersection - ray.origin
        ray.optical_path_length += segment.magnitude() * ray.n

        # A zero-length hit (t ~ 0) is legitimate and must still refract: in a
        # cemented doublet the two surfaces share a vertex, so the ray has to
        # change index at the point it is already standing on. This is why
        # _intersect_sphere passes min_t=-EPSILON here while the 2D tracer
        # rejects such hits outright.
        #
        # What must not happen is *recording* it. Appending unconditionally
        # left consecutive identical path points separated by zero length, so
        # anything deriving a direction or a segment length from consecutive
        # path points divides by zero. A cemented doublet produced three such
        # repeats. The refraction below is unaffected.
        previous_origin = ray.origin
        ray.origin = intersection
        if not ray.path or (intersection - previous_origin).magnitude() > EPSILON:
            ray.path.append(intersection)

        if fresnel_hit is None and is_parabolic and normal is None:
            # Paraboloid normal: gradient of F = x - (y²+z²)/(2R) - vx = 0,
            # i.e. (1, -y/R, -z/R) in the local frame, oriented outward.
            # (Planar fallback keeps the ∓axis normal assigned above.)
            try:
                local_hit = self._to_local_point(intersection, vertex)
                ly, lz = local_hit.y, local_hit.z
                if abs(R) < EPSILON:
                    normal_local = vec3(1, 0, 0)
                else:
                    normal_local = vec3(1, -ly / R, -lz / R).normalize()
                geometric = self.transform.multiply_vector(normal_local)
            except Exception:
                geometric = None
            if geometric is None:
                normal = -self.optical_axis if surface_type == "front" else self.optical_axis
            else:
                normal = self._outward_normal(geometric, surface_type)
        elif fresnel_hit is None and is_conic and normal is None:
            # Conic gradient in the vertex-local frame:
            # ((1+K)x - R, y, z).
            try:
                local_hit = self._to_local_point(intersection, vertex)
                local_hit = local_hit - self._to_local_point(vertex, vertex)
                normal_local = vec3(
                    (1.0 + conic_constant) * local_hit.x - R,
                    local_hit.y,
                    local_hit.z,
                ).normalize()
                geometric = self.transform.multiply_vector(normal_local)
            except Exception:
                geometric = None
            if geometric is None:
                normal = -self.optical_axis if surface_type == "front" else self.optical_axis
            else:
                normal = self._outward_normal(geometric, surface_type)
        elif fresnel_hit is None and is_flat:
            if surface_type == "front":
                normal = -self.optical_axis
            else:
                normal = self.optical_axis
        elif fresnel_hit is None:
            normal = self._outward_normal(intersection - center, surface_type)

        current_n = ray.n

        if abs(current_n - default_n1) < 1e-3:
            n1, n2 = default_n1, default_n2
        elif abs(current_n - default_n2) < 1e-3:
            n1, n2 = default_n2, default_n1
        else:
            n1, n2 = current_n, default_n2

        if interaction == "reflect":
            ray.reflect(normal, n1, n2)
            return RefractionResult.REFLECTED
        elif interaction == "refract":
            return ray.refract_or_reflect(n1, n2, normal)

        return RefractionResult.MISSED

### openlens.aberrations.analyze_lens_quality

# Notes: `openlens.aberrations.analyze_lens_quality(lens, field_angle=5.0, **kwargs)`

## 1. Purpose
- Runs `AberrationsCalculator(lens).calculate_all_aberrations(...)`.
- Turns the result into a 0–100-style quality score, a rating string and a list of issue strings.

## 2. Inputs
- `lens`: a `Lens`.
  - `AberrationsCalculator.__init__` reads `refractive_index`, `radius_of_curvature_1/2`, `thickness` and `diameter`.
  - The object must NOT have an `elements` attribute, or it is treated as a system.
  - No `entrance_pupil_mm` is passed, so the pupil is `lens.diameter`.
- `field_angle` (float, default `5.0`, degrees).
  - It is overridden by `kwargs["field_angle_deg"]` if present: `field_angle = kwargs.get("field_angle_deg", field_angle)`.
- `kwargs["wavelength_nm"]`: defaults to `constants.WAVELENGTH_GREEN`. That value is not visible here; import it rather than hardcoding.
- Other kwargs are ignored. There is no validation of any input.
- The exact call made is: `calc.calculate_all_aberrations(field_angle=<angle>, wavelength_nm=<wl>)`.
  - Both are keyword arguments; `object_distance_mm` keeps its default `None`.

## 3. Raises
- The function itself has no explicit `raise`.
- `ValueError` cannot come from the object-distance check, because the distance is always `None`.
- `TypeError` is possible if a traced metric comes back `None` (trace failed), because of `abs(None)` or `None > 1.0`:
  - `results["distortion"]` is `None` → `abs(dist)` fails.
  - `results["astigmatism"]` is `None` → `ast > 1.0` fails.
- Don't rely on this in tests; it only happens for geometries whose trace fails.
- Spherical and chromatic are never `None` for a singlet:
  - Spherical falls back to Seidel.
  - Chromatic is `|f|/abbe`.

## 4. Returns
**Error branch:** taken if `results.get("error")` is truthy (focal length is `None`). The result is exactly:
```python
{"quality_score": 0, "rating": "Error",
 "issues": ["Cannot calculate focal length (zero optical power)"]}
```
- There is no `"aberrations"` key in this branch.
- When `Lens.calculate_focal_length()` returns `None` is defined in `openlens.lens`, which is not visible here (presumably zero optical power).

**Normal branch:** `{"quality_score": int, "rating": str, "issues": list[str], "aberrations": results}`.
- `"aberrations"` is the very dict returned by `calculate_all_aberrations` (same object, unchanged).
- `"issues"` is `["No significant aberrations detected"]` when no penalty applies.

**Scoring:** start at 100 and apply the checks in this order (all comparisons strict `>`). Issues are appended in the same order.

| Check | Penalty and issue text |
|---|---|
| `sa = abs(results["spherical"])`; `sa > SPHERICAL_ABERRATION_EXCELLENT` | −40, `f"High spherical aberration ({sa:.4f} mm)"` |
| elif `sa > SPHERICAL_ABERRATION_EXCELLENT/10` | −20, `f"Moderate spherical aberration ({sa:.4f} mm)"` |
| `ca = results["chromatic"]` (no abs); `ca > 0.5` | −40, `f"High chromatic aberration ({ca:.4f} mm)"` |
| elif `ca > 0.1` | −20, `"Moderate chromatic aberration (...)"` |
| `d = abs(results["distortion"])`; `d > 5` | −15, `f"High distortion ({d:.2f}%)"` |
| elif `d > 1` | −5, `f"Moderate distortion ({d:.2f}%)"` |
| `ast = results["astigmatism"]` (no abs); `ast > 1.0` | −15, `f"High astigmatism ({ast:.4f} mm)"` |
| elif `ast > 0.1` | −5, `f"Moderate astigmatism ({ast:.4f} mm)"` |

**Rating:** checked top-down with `>=`. The constants are in `openlens.constants` (not shown); the numbers in the comments imply EXCELLENT=85, GOOD=70, FAIR=50.

| Condition | Comment value | Rating |
|---|---|---|
| `score >= QUALITY_EXCELLENT_THRESHOLD+5` | 90 | `"Excellent"` |
| `score >= QUALITY_GOOD_THRESHOLD+5` | 75 | `"Good"` |
| `score >= QUALITY_FAIR_THRESHOLD+10` | 60 | `"Fair"` |
| `score >= QUALITY_FAIR_THRESHOLD-10` | 40 | `"Poor"` |
| otherwise | — | `"Very Poor"` |

- The minimum possible score is 100−40−40−15−15 = −10. The score is not clamped.

## 5. Side effects
- `calculate_all_aberrations` temporarily calls `lens.update_refractive_index(wavelength_nm=...)`.
- In `finally` it restores `lens.wavelength` and `lens.refractive_index`, so the lens is unchanged afterwards.
- A fresh calculator is used, so no cache persists between calls.

## 6. Branches / real-lens facts
**Chromatic for a singlet** is `abs(f)/V`.
- `V` is looked up by `lens.material`: BK7 64.17, "Fused Silica" 67.8, "Crown Glass" 60.0, "Flint Glass" 36.0, SF11 25.76, Sapphire 72.0.
- If the material is not in that table, `V` is estimated from the index: n<1.5→65, n<1.6→55, n<1.7→40, else 30.
- That index is `lens.refractive_index` read at calculator construction, i.e. before the wavelength update.
- `f` is computed at the requested wavelength.
- Consequence for BK7: |f| > ~32.1 mm gives "High chromatic"; 6.4 < |f| < 32.1 gives "Moderate".

**Field angle:**
- With `field_angle=0`, coma and astigmatism are exactly `0.0`, so there is no astigmatism issue.
- Distortion and field curvature still come from a ray trace.
- The exact traced values are not predictable from this module.

## 7. Comment-stated intent
- The comments give the rating cut-offs 90/75/60/40.
- Penalties are "major" (−40) and "minor" (−20) for spherical aberration, and the same pattern is reused for chromatic aberration.

## 8. Testing hints
**Best approach: monkeypatch the aberration call** for deterministic scoring.
```python
import openlens.aberrations as ab

fake = {"spherical": 0.0, "chromatic": 0.0, "distortion": 0.0, "astigmatism": 0.0}
monkeypatch.setattr(ab.AberrationsCalculator, "calculate_all_aberrations",
                    lambda self, **kw: (seen.update(kw), fake)[1])
r = ab.analyze_lens_quality(Lens())
```
- With all four metrics at 0 the result is: score 100, `"Excellent"`, `["No significant aberrations detected"]`, and `r["aberrations"] is fake`.
- The fake must accept keyword args; capture `kw` to assert `field_angle` and `wavelength_nm`.
  - Default call: `field_angle=5.0`.
  - `field_angle_deg=7` overrides `field_angle=3`.
- Import `SPHERICAL_ABERRATION_EXCELLENT` and the `QUALITY_*` constants from `openlens.constants`; don't hardcode them. Use spherical values like `1.5*E` and `0.5*E`.

**Boundaries:**
- Values exactly at a threshold do not penalize (strict `>`):
  - chromatic 0.5 → only −20 (because 0.5 > 0.1);
  - chromatic 0.1 → no penalty;
  - distortion 5 → −5; distortion 1 → none.
- Negative values:
  - Distortion −6 → "High distortion (6.00%)", because abs is applied.
  - Chromatic −1 → no penalty (no abs).
  - Spherical −x → penalized via abs, and the message shows the positive value.

**Error path:** return `{"error": "boom"}` from the fake. Expect `{"quality_score": 0, "rating": "Error", "issues": ["boom"]}` and no `"aberrations"` key.
- An empty-string `error` is falsy, so the normal path runs (and needs the four metric keys present).

**Exact strings to check:**
- Issue order: spherical, chromatic, distortion, astigmatism.
- Formatting: `.4f mm` for spherical/chromatic/astigmatism, `.2f%` for distortion (no space before `%`).
- Example: score 100−40−20−5−5 = 30 → `"Very Poor"`; score 60 → `"Fair"`; score 75 → `"Good"`.

**Real (un-mocked) runs:**
- Only assert structure, the restored lens index, and chromatic = `abs(r["aberrations"]["focal_length"])/64.17` for BK7.
- Don't assert traced values or the exact score.

### openlens.analysis.geometric.GeometricTraceAnalysis.calculate_field_curvature_distortion

# Notes: `GeometricTraceAnalysis.calculate_field_curvature_distortion`

## 1. Purpose
- Samples field angles from 0 to `max_field_angle_deg` and real-ray-traces each one through `self.system`.
- For each angle it reports:
  - tangential focus shift relative to the image plane,
  - sagittal focus shift relative to the image plane,
  - percent distortion against `efl * tan(angle)`.

## 2. Inputs
- **`max_field_angle_deg`** (float, default `20.0`).
  - The kwarg `max_field_angle=` is accepted as an alias. It is popped from kwargs and **overrides** the positional or default value.
- **`num_points`** (int, default `11`). Angles come from the private `_linspace(0, max, num)`:
  - If `num <= 1` (this includes `0` and negative values), the result is `[0]`. That is the int `0`, not `0.0`.
  - Otherwise `step = max/(num-1)` and each angle is `0 + i*step`. The last value is `(num-1)*step`, which may differ from `max` by float rounding; use `pytest.approx`.
- **`wavelength_nm`** (float, default `WAVELENGTH_GREEN`).
  - Every element's lens gets `lens.update_refractive_index(wavelength_nm=...)` before tracing.
  - The value is also passed to `resolve_image_plane_x`.
- **`**kwargs`**: any key other than `max_field_angle` is rejected.
- **`self.system`**: an `OpticalSystem`. The tracer (`SystemRayTracer3D`) is created in `__init__`.

## 3. Raises
- **`TypeError(f"Unexpected kwargs: {list(kwargs.keys())}")`**
  - Example: `ga.calculate_field_curvature_distortion(foo=1)` gives the message `"Unexpected kwargs: ['foo']"`.
  - With `max_field_angle=5, foo=1`, the message is still `"Unexpected kwargs: ['foo']"`, because the alias is popped first.
  - Use `pytest.raises(TypeError, match=r"Unexpected kwargs: \['foo'\]")`.
  - Order: the wavelength is applied first, then the kwargs check runs. Both happen inside `try`, so lens state is still restored when this error is raised.
- **Empty system** (`OpticalSystem()` with no lenses):
  - `self.system.elements[0].position` raises `IndexError`. This line runs before the loop.
  - `resolve_image_plane_x` (another module, not visible) runs first and might raise something else.
  - Only assert `pytest.raises(Exception)` here, if you test it at all.
- Errors from `Lens.update_refractive_index` for bad wavelengths come from another module and are unknown; do not test them.

## 4. Returns
Returns a new dict with exactly these 7 keys:
```
"field_angles_deg"   -> the angles list
"tan_focus_shift_mm" -> list[float]
"sag_focus_shift_mm" -> list[float]
"tan_focus_shift"    -> SAME list object as tan_focus_shift_mm (alias, `is`)
"sag_focus_shift"    -> SAME list object as sag_focus_shift_mm
"distortion_pct"     -> list[float]
"image_plane_x_mm"   -> float
```
- All five lists have length `len(angles)`. When `num_points >= 2`, that equals `num_points`; otherwise it is 1.
- **Image plane**: `image_plane_x = resolve_image_plane_x(system, wavelength_nm, tracer=self.tracer)`.
  - This returns the configured detector plane if there is one, otherwise the paraxial focus.
  - If it returns `None`, the value is `system.get_total_length() + 10.0`.
- **Per angle `a`**:
  - `tan_theta = tan(radians(a))`.
  - The chief ray starts 50 mm before `elements[0].position` and aims through the point `(elements[0].position, 0, 0)` with direction `(1, tan_theta, 0)` normalised.
  - **Distortion**:
    - `efl = system.get_system_focal_length() or 100.0`, so `None` or `0` both become `100.0`.
    - `paraxial = efl * tan_theta`.
    - If `|paraxial| > 1e-6`: `100*(real_y_at_image_plane - paraxial)/paraxial`.
    - Otherwise: exactly `0.0`.
  - **Tangential focus**:
    - A parallel ray is launched offset by `delta = 0.01 * elements[0].lens.diameter` in y at the first-lens plane.
    - The x-intersection of its 2D (x, y) line with the chief ray's line is computed, and the result is `x_focus - image_plane_x`.
    - If the slopes differ by `<= 1e-9`, the result is `0.0`, not NaN.
    - If the ray terminated, the result is NaN.
  - **Sagittal focus**:
    - The ray is offset by `delta` in z.
    - The result is the x of the chief-ray point at closest approach to the sagittal ray, minus `image_plane_x`.
    - It is NaN if the rays are near-parallel (`|1 - b²| < 1e-12`) or if the ray terminated.

## 5. Side effects
- Each lens's `wavelength` and `refractive_index` are snapshotted before tracing and restored in `finally`, even if an exception is raised.
- After the call, `lens.refractive_index` and `lens.wavelength` equal their pre-call values, including when a non-default `wavelength_nm` was used.
- No files are written. Lens geometry and positions are not mutated.

## 6. Branches and edge cases
- **Chief ray terminated at an angle**: NaN is appended to all three lists for that angle, then the loop continues. Lengths stay equal.
- **`num_points=1`**: `field_angles_deg == [0]`, and `distortion_pct == [0.0]`.
- **`max_field_angle_deg=0, num_points=3`**: angles `[0.0, 0.0, 0.0]`, `distortion_pct == [0.0, 0.0, 0.0]`.
- **Negative max** (e.g. `-10, 3`): angles `[0.0, -5.0, -10.0]`, i.e. descending.
- **Alias**: `calculate_field_curvature_distortion(max_field_angle=10, num_points=3)` gives angles `[0.0, 5.0, 10.0]`.
- **Defaults**: angles are approximately `[0, 2, 4, ..., 20]` (11 values).
- **Angle 0**: distortion is always exactly `0.0`.

## 7. Docstring and comment rules
- "Trace at the requested wavelength (indices restored on exit)."
- `max_field_angle` is a backward-compatibility alias.
- The sagittal focus is measured on the chief ray, not on the z=0 plane.

## 8. Testing hints
Build a system like this:
```python
from openlens.lens import Lens
from openlens.optical_system import OpticalSystem
from openlens.analysis.geometric import GeometricTraceAnalysis
lens = Lens(radius_of_curvature_1=50.0, radius_of_curvature_2=-50.0,
            thickness=5.0, diameter=25.0, material="BK7")
sysm = OpticalSystem(); sysm.add_lens(lens)
ga = GeometricTraceAnalysis(sysm)
```
- The sign convention and the exact focus value come from other modules. **Do not hard-code** focus shifts or `image_plane_x_mm` values.
- Assertions that are safe to make:
  - the key set,
  - list lengths,
  - aliases are identical objects (`res["tan_focus_shift"] is res["tan_focus_shift_mm"]`),
  - the angle values,
  - `distortion_pct[0] == 0.0`,
  - `isinstance(res["image_plane_x_mm"], float)`,
  - index and wavelength are restored after a call with `wavelength_nm=486.1`,
  - index is still restored after the `TypeError`.
- **Image-plane consistency**: for a `Lens` + `OpticalSystem`, call `resolve_image_plane_x(sysm, wl)` yourself and compare with `pytest.approx`. Use the same `wl`, since the default wavelengths match.
- **On-axis symmetry**: the angle-0 tangential and sagittal shifts should agree closely, e.g. `pytest.approx(abs=1e-6)`. This is a reasonable check, but it relies on the rotational symmetry of the tracer.
- Use `math.isnan` for NaN checks, not `==`.
- Avoid huge angles (≥ 90°): `tan` blows up and the outcome is unpredictable.

### openlens.analysis.geometric.GeometricTraceAnalysis.calculate_ray_fan

# Notes: `GeometricTraceAnalysis.calculate_ray_fan`

## 1. Purpose
- Computes a transverse ray-aberration fan by real 3D ray tracing through the whole `OpticalSystem` at one wavelength.
- Each error is the ray's image-plane intercept minus the chief ray's intercept, in mm, as a function of normalized pupil coordinate.

## 2. Inputs
- **Constructor:** `GeometricTraceAnalysis(system)` stores `self.system` and builds `self.tracer = SystemRayTracer3D(system)` once, at construction. Configure the system fully before constructing the analyzer.
- **`field_angle_deg`** (float, default `0.0`)
  - Ray direction is `vec3(1, tan(radians(angle)), 0).normalize()`, i.e. the field tilts in the X-Y (tangential) plane.
  - All fan rays share this direction. There is no validation.
- **`wavelength_nm`** (float, default `WAVELENGTH_GREEN`)
  - Each element's lens gets `update_refractive_index(wavelength_nm=...)` before tracing.
  - The trace uses `wavelength_nm * NM_TO_MM`.
  - Validation, if any, happens inside `Lens.update_refractive_index`, which is not visible here.
- **`num_points`** (int, default `21`). Pupil samples come from `_linspace(-1.0, 1.0, num_points)`:
  - If `num <= 1` (including 0 or negative values), the result is `[-1.0]`, a single point.
  - Otherwise `step = 2/(num-1)` and the values are `[-1.0 + i*step for i in range(num)]`.
  - `num_points=3` gives exactly `[-1.0, 0.0, 1.0]`. `num_points=2` gives `[-1.0, 1.0]`.
  - With 21 points, index 10 is exactly `0.0`, but other values such as `-0.9` carry float error. Use `pytest.approx` for them.
- **`pupil_axis`** (str, default `'y'`)
  - `'y'` gives a tangential fan: offsets go along Y and the error is in Y.
  - **Any other value** (`'z'`, `'x'`, `'foo'`) gives a sagittal fan: offsets go along Z and the error is in Z.
  - The value is echoed unchanged in the result.

## 3. Raises
- There is no explicit validation and no `raise` in this module's path.
- **Empty system** (`OpticalSystem()` with no lenses) raises an exception:
  - `elements[0]` would raise `IndexError`.
  - `resolve_image_plane_x` (from another module) runs first and might raise something else.
  - In a test, assert only `pytest.raises(Exception)`.
- **Float `num_points > 1`** (e.g. `2.5`) raises `TypeError` from `range()` in `_linspace`.
- Lens state is restored in a `finally` block, so it is restored even when an exception is raised.

## 4. Returns and guarantees
The result is a new `dict` on every call, with exactly these keys:
- `"pupil_coords"`: the list of pupil coordinates whose ray gave a non-NaN error, in ascending order. It is a subset of the `_linspace` values.
- `"ray_errors_mm"`: list of float errors, the same length as and aligned with `pupil_coords`.
- `"ray_errors"` and `"transverse_aberration"`: the **same list object** as `ray_errors_mm` (`is`-identical).
- `"axis"`: the `pupil_axis` argument as given.
- `"field_angle_deg"`: the argument as given.
- `"wavelength_nm"`: the argument as given, in nm and not converted.

How the geometry is set up:
- `max_r = elements[0].lens.diameter / 2`.
- Each ray passes through `(elements[0].position, p*max_r, 0)` for the y fan, or `(elements[0].position, 0, p*max_r)` for the z fan.
- Rays start at x = `elements[0].position - 50` and are back-propagated along the direction.

How the reference (chief ray) is set up:
- The chief ray passes through `(elements[0].position, 0, 0)`.
- If it is not terminated and `|dir.x| > 1e-6`, its intercept at `image_plane_x` gives `ref_y`/`ref_z`. Otherwise both stay `0.0`.

How `image_plane_x` is chosen:
- `resolve_image_plane_x(system, wavelength_nm, tracer=self.tracer)` returns a configured detector plane if set, else the paraxial focus. That function is in another module.
- If it returns `None`, the fallback is `system.get_total_length() + 10.0`.

Which rays are kept:
- A ray is kept only if it is not terminated and `|ray.direction.x| > 1e-6`.
- Otherwise its error is NaN and the point is **dropped**, not stored as NaN. The result lists therefore never contain NaN.

## 5. Side effects
- The call snapshots `(lens, lens.wavelength, lens.refractive_index)` for every element.
- It then sets the indices for `wavelength_nm`, traces, and in `finally` restores `lens.wavelength` and `lens.refractive_index` to the snapshot values.
- After the call, each lens's `refractive_index` and `wavelength` equal their pre-call values, even when `wavelength_nm` differs from the lens wavelength.
- Ray tracing goes through `self.tracer`, whose internal caching is not visible here. No files or globals are touched.

## 6. Branches and edge cases
- **p = 0 ray equals the chief ray.** It has an identical origin and direction, computed the same way. If it is not terminated, its error is **exactly `0.0`** for any field angle and either axis.
- **Edge rays (p = ±1)** hit exactly the rim (`diameter/2`). Whether the tracer clips them is unseen behaviour. Do not assert `len(pupil_coords) == num_points`; assert `<=`.
- **`num_points=1` or `0`** yields at most one point, `-1.0`.
- **Chief ray terminated** (e.g. a huge field angle): the reference is 0 and errors become absolute intercepts.
- **Any non-`'y'` axis** behaves as the sagittal fan. For example, `pupil_axis='x'` gives the same errors as `'z'`, with `axis == 'x'`.

## 7. Rules from comments/docstrings
- The wavelength argument "controls the physics, not just labels", and the indices are restored on exit.
- `'y'` means tangential (meridional) and `'z'` means sagittal. Pupil coords are normalized to the range −1 to 1.
- The entrance pupil is approximated as the first lens diameter, and the chief ray goes through the first surface centre.

## 8. Testing hints
Build a system like this:
```python
from openlens.lens import Lens
from openlens.optical_system import OpticalSystem
from openlens.analysis.geometric import GeometricTraceAnalysis
sys_ = OpticalSystem(); sys_.add_lens(Lens())   # or create_doublet()
g = GeometricTraceAnalysis(sys_)
r = g.calculate_ray_fan(num_points=11)
```

Robust assertions on current code:
- **Keys and aliases:** the key set is as listed above, and `r["ray_errors"] is r["ray_errors_mm"] is r["transverse_aberration"]`.
- **Echoed metadata:** `r["axis"] == "y"`. `field_angle_deg` and `wavelength_nm` are echoed. Passing `wavelength_nm=486.1` gives back `486.1`.
- **Lengths and order:** `len(pupil_coords) == len(ray_errors_mm) <= num_points`. The coords are a sorted subset of the linspace values. None of the values is NaN.
- **Centre point:** `0.0` is in `pupil_coords` when `num_points` is odd, and its error `== 0.0` exactly. This holds both on-axis and at, e.g., 5°.
- **On-axis symmetry** (rotationally symmetric single lens):
  - `error(p) ≈ -error(-p)`; use `pytest.approx(abs=1e-9)` for any pair that both survive.
  - The y fan equals the z fan elementwise (approx).
- **Off-axis sagittal fan:** it is still odd, `error(p) ≈ -error(-p)`, by mirror symmetry in Z.
- **Different wavelengths:** errors at 486.1 and 656.3 nm differ (not approx-equal) for a singlet. The lens `refractive_index` is unchanged after each call.
- **Inputs not mutated:** lens wavelength and refractive index are unchanged after the call (see section 5).

Pitfalls:
- Do not assert the sign or magnitude of aberrations. They depend on the unseen tracer, sign conventions and focus search.
- Do not rely on edge rays surviving.
- Do not pass `num_points` as a float.
- Do not expect NaN entries in the result.

### openlens.image_simulator.ImageSimulator.simulate_image

# Notes: `ImageSimulator.simulate_image(input_image, object_distance, image_distance=None, wavelength=WAVELENGTH_D_LINE, pixel_pitch_mm=0.01)`

## 1. Purpose
Runs an image through the simulated optics in this order:
1. image distance (lens equation)
2. aberration blur
3. diffraction blur
4. per-channel chromatic zoom (RGB only)
5. cos⁴ vignetting
6. quality metrics

It returns a dict.

## 2. Inputs
- `input_image`: numpy array, `(H, W)` or `(H, W, C)`. Use **float** arrays with values in [0, 1].
  - `gaussian_filter` keeps the input dtype, so integer input stays integer until the vignetting multiply.
- `object_distance`: float in mm. Not validated.
- `image_distance`: `None` means it is computed. Any value given is used as-is and returned unchanged (no `float()` conversion).
- `wavelength`: nm. Forwarded to `refractive_index_at`, `get_aberrations` and the Airy radius.
- `pixel_pitch_mm`: mm per pixel.
  - `<= 0` disables aberration blur.
  - It also gives diffraction sigma 0, which is floored to 0.1 px.
  - It also skips vignetting.
- `self.optical_system` (set in the constructor) is duck-typed. Attributes it uses:
  - `.elements[i].lens.refractive_index` (read and written)
  - `.lens.refractive_index_at(wl)`
  - `.elements[0].lens.diameter`
  - `get_system_focal_length()`
  - optionally `get_aberrations(wl)`

## 3. Raises
Checks run in this order:
1. **When `image_distance is None`:** `optical_system.elements` is accessed directly. A target without `.elements` raises `AttributeError`.
2. **Focal length.** `get_system_focal_length()` is callable and returns falsy (`None` or `0`):
   - `ValueError("OpticalSystem reports no focal length; cannot simulate an image through it.")`
   - Raised from the image-distance step, or later from the diffraction step if `image_distance` was given.
3. **No focal-length method.** None of `get_system_focal_length`, `calculate_focal_length` or `effective_focal_length` exists, or the last two return falsy:
   - `TypeError(f"{type(system).__name__} is not a supported optical target for ImageSimulator.")`
4. **No aperture** (scipy only, in diffraction). The pupil diameter check runs **before** the focal length is read there. It fails when there is no element with diameter > 0 and no positive `aperture_diameter` or `diameter` attribute:
   - `ValueError("Optical target has no usable aperture; cannot size the diffraction spot.")`
   - Trigger: `elements=[]` with `get_system_focal_length` returning 100 and `image_distance=50`.
5. **`object_distance == 0`:** `ZeroDivisionError`. It comes from `1.0/object_distance`, or from the magnification `-image_distance/object_distance` even when `image_distance` is given.
6. **No `get_aberrations` on the target:** `AberrationsCalculator` from `openlens.aberrations` is used. Its behaviour and errors are not visible here, so avoid it in tests.

## 4. Returns
A new dict with exactly 4 keys:

- `"output_image"`: new ndarray with the same shape as the input.
- `"magnification"`: `-image_distance / object_distance`.
- `"image_distance"`:
  - When computed: `abs(1/(1/f - 1/object_distance))`.
  - If `abs(object_distance - f) < 0.001`: `float("inf")`, so magnification is `-inf`.
- `"metrics"`: dict with keys `psnr`, `global_ssim`, `nyquist_spectral_ratio`, `sharpness`.
  - `psnr = 10*log10(1/mse)`, or `inf` when `mse == 0`.
  - `global_ssim`: global SSIM formula with `c1=1e-4`, `c2=9e-4`.
  - `nyquist_spectral_ratio`:
    - Mean FFT magnitude over the ring `|r - min(h,w)//4| <= 2`, divided by DC.
    - Returns 0.0 if DC <= 0.
    - On tiny images the ring includes DC, so use ≥ 16×16 images.
  - `sharpness`: mean Sobel gradient magnitude of the grayscale (channel-mean) image.

The focal length `f` is measured after every lens's `refractive_index` is set to `refractive_index_at(wavelength)`.

## 5. Side effects
- Each `lens.refractive_index` is temporarily overwritten and **restored in a `finally` block**. After the call the values equal their originals, even if the call raised.
- `input_image` is not mutated: aberrations operate on `.copy()`, and the filters return new arrays.

## 6. Branches and edge cases
**Image distance (f = 100):**

| `object_distance` | `image_distance` | `magnification` |
|---|---|---|
| 200 | 200.0 | -1.0 |
| 50 | 100.0 (abs of -100) | -2.0 |
| 100 | inf | -inf |

- **Given distance:** `image_distance=50`, `object_distance=100` gives `image_distance == 50` and magnification -0.5. `refractive_index_at` is not called for a grayscale image.

**Aberrations** (skipped entirely without scipy). Values are read from `get_aberrations(wl)`.
- Each sigma is `abs(value)/pitch` in pixels. None or non-numeric values are skipped.
- `spherical_aberration` or `spherical`: blurs both spatial axes.
- `coma`: blurs both spatial axes.
- `astigmatism` gives a half-width h:
  - axis 0 (rows) is blurred with `h*√2`;
  - axis 1 (columns) is blurred with `h/√2`.
- On RGB images the colour axis is never blurred (sigma `(s, s, 0)`).
- `{}` means no aberration blur.

**Diffraction:**
- `airy = 1.22*wavelength*1e-6*f/D` (mm).
- `sigma = max(0.1, airy*0.844/2.355/pitch)`.
- Example: f=100, D=25, λ=550, pitch=0.01 gives about 0.096 px, so sigma 0.1.
- That leaves an effectively identity kernel (kernel radius 0), but do not rely on exact equality for non-constant images.

**Chromatic step** (only when `ndim == 3` and `shape[2] >= 3`):
- `f_base = get_system_focal_length()` at the current index.
- For channels R, G, B at wavelengths 650, 550, 450: `scale = f_base / f_at(wl)`.
- If `|scale - 1| > 1e-4`, the channel is zoomed with order 1, then centre-cropped or edge-padded back to the original size.
- If the index does not vary with wavelength, nothing changes.
- `(H, W, 1)` images skip this step.

**Vignetting:**
- If `image_distance` is inf, the fallback is `abs(get_system_focal_length())`. `effective_focal_length(WAVELENGTH_GREEN)` is tried first if present.
- If L ≤ 0 or `pitch <= 0`, the image is unchanged.
- Otherwise the factor is `(L/sqrt(L² + r²))⁴`, where:
  - `r = hypot(x - w/2, y - h/2) * pitch`;
  - the centre is the **float** point `(w/2, h/2)`, so pixel `(h/2, w/2)` has factor 1 when h and w are even.
  - RGB images are broadcast over channels.

## 7. Rules from comments and docstrings
- Asking a question must never leave the system changed (index restore).
- The wavelength must be forwarded to the aberration lookup, not dropped.
- Blur sigma is in pixels: millimetres divided by `pixel_pitch_mm`.
- Astigmatism blurs both meridians by different amounts.
- RGB blur must not mix channels.
- Vignetting never forces the corners to zero.

## 8. Testing hints

### openlens.optical_system.OpticalSystem.calculate_chromatic_aberration

# Notes: `OpticalSystem.calculate_chromatic_aberration(self) -> Dict[str, Any]`

## 1. Purpose
- Computes longitudinal (axial) chromatic aberration of the whole system.
- It rebuilds the paraxial ABCD matrix at the F, d and C Fraunhofer lines, then reports back focal lengths (BFL), effective focal lengths (EFL), their difference, and a "corrected" flag.

## 2. Inputs
- No parameters. It reads the following:
  - `self.elements`, in order.
  - Each `el.lens.refractive_index_at(wl)`. This is defined in `openlens.lens`, which is not shown here; it probably uses the material DB or model glass.
  - `lens.get_effective_radius_1()` / `get_effective_radius_2()`.
  - `lens.thickness`.
  - `self.air_gaps[i].thickness`.
- Wavelengths come from `openlens.constants`: `WAVELENGTH_F_LINE`, `WAVELENGTH_D_LINE`, `WAVELENGTH_C_LINE`. The exact values are not shown, so import them instead of hard-coding them.
- Loop order is F, then d, then C. For each line, `refractive_index_at` is called once per element, in element order.
- `lens.refractive_index` is **ignored** whenever the system has at least one element. In that case the override map is non-empty, and the override index is always used.

## 3. Raises
- The method itself raises nothing explicitly.
- Exceptions from `refractive_index_at` or the radius getters would propagate. That code lives in `lens.py` and is not visible here.

## 4. Returns and guarantees
For each line, the private helper `_calculate_system_matrix(n_overrides)` builds the matrix:
- It starts from the identity matrix.
- Per element, in order:
  - **Surface 1:** if R1 is finite and non-zero, `P1 = (n - 1)/R1`, then `C -= P1*A` and `D -= P1*B`.
  - **Glass:** propagate the reduced thickness `d = t/n` (use plain `t` if n is 0): `A += d*C`, `B += d*D`.
  - **Surface 2:** if R2 is finite and non-zero, `P2 = (1 - n)/R2`, applied the same way.
  - **Air gap:** for every element except the last, propagate `air_gaps[i].thickness`.
- If `abs(C) > 1e-10`: `bfl = -A/C` and `efl = -1/C`. Otherwise both are `None`.

**Full result** (when `bfl_F` and `bfl_C` are both not None) is a new dict with exactly these 8 keys:
```
{"longitudinal": bfl_C - bfl_F, "bfl_F", "bfl_d", "bfl_C",
 "f_F", "f_d", "f_C", "corrected": abs(longitudinal) < 0.1}
```
- `corrected` uses a strict `<`, and its value is a Python `bool`.
- `bfl_d` and `f_d` can be `None` independently, but only if the d-line matrix alone is afocal.

**Fallback result** (otherwise): exactly `{"longitudinal": 0.0, "corrected": False}`, with no other keys.

Closed form for a single lens with spherical surfaces (n is the index at that line):
- `1/f = (n-1)(1/R1 - 1/R2) + (n-1)**2 * t / (n*R1*R2)`
- `bfl = f * (1 - (t/n)*(n-1)/R1)`

## 5. Side effects
- None.
- No mutation of lenses or elements, `modified_at` is not touched, and nothing is cached.
- A fresh dict is returned on every call.

## 6. Branches and edge cases
- **Empty system:** `OpticalSystem().calculate_chromatic_aberration() == {"longitudinal": 0.0, "corrected": False}`.
- **Afocal at F and C** (e.g. all surfaces flat): the fallback dict is returned.
- **Same index at all three lines** (index patched to a constant): F and C are computed identically, so `longitudinal == 0.0` exactly and `corrected is True`.
- **Positive BK7-like singlet with normal dispersion** (n_F > n_d > n_C):
  - `f_F < f_d < f_C`, and the same order holds for the BFLs.
  - So `longitudinal > 0`.
  - For f ≈ 100 mm BK7, it is about 1.5 mm, so `corrected is False`.
- **Negative lens:** the sign of `longitudinal` flips (it becomes negative).
- **Gaps:** the last element's following gap is never applied. Only `air_gaps[0 .. len-2]` are used.

## 7. Rules from docstrings/comments
- The `f_*` keys are true EFLs (`-1/C`). They are not copies of the BFL.
- BFL is `-A/C`, the observable focus position.
- The reduced thickness `d/n` is intentional (ray vector `(y, n·θ)`). Cemented zero-gap pairs are treated exactly.
- `is_achromatic()` returns `bool(result.get("corrected", False))`.

## 8. Testing hints
Pin indices exactly by overriding the bound method on the instance. This assumes `Lens` has no `__slots__`, which is likely; it is a normal class.

```python
from openlens.constants import WAVELENGTH_F_LINE as F, WAVELENGTH_D_LINE as D, WAVELENGTH_C_LINE as C
lens = Lens(radius_of_curvature_1=50.0, radius_of_curvature_2=-50.0, thickness=5.0, diameter=25.0)
idx = {F: 1.522, D: 1.5168, C: 1.514}
lens.refractive_index_at = lambda wl: idx[wl]
s = OpticalSystem(); s.add_lens(lens)
r = s.calculate_chromatic_aberration()
```

What to check:
- Compare `r["f_F"]`, `r["bfl_C"]` and so on with the closed form above, using `pytest.approx(rel=1e-9)`.
- Check `r["longitudinal"] == approx(r["bfl_C"] - r["bfl_F"])`.
- Check that `set(r)` equals the 8 keys.
- Verify `lens.refractive_index` is ignored: set it to something absurd (e.g. 3.0) and confirm the result does not change.
- Two-element test: add a second patched lens with `air_gap_before=10.0`. Compute the expected value by multiplying 2x2 matrices by hand. Changing the gap should change the BFL.
- Threshold test: choose indices so that |longitudinal| is about 0.05 (expect `corrected` True) versus about 0.2 (expect False). Avoid values near exactly 0.1.
- Verify ordering: record the wavelengths passed to `refractive_index_at`. For one element it should be `[F, D, C]`.

Pitfalls:
- Do not hard-code wavelength numbers or catalog indices. Without patching, `refractive_index_at` depends on code you cannot see, so only assert qualitative relations (signs and ordering).
- Use `approx` for floats. The one exception is the constant-index case, where exact `0.0` is safe.
- Avoid parabolic or conic lenses; their effective radius comes from `lens.py`, which is not shown.
- Flat surfaces (`float('inf')`) are skipped as having no power. Whether `Lens` accepts them is decided in `lens.py`.

### openlens.optical_system.OpticalSystem.load

# Notes: `OpticalSystem.load(filename)` (staticmethod, `openlens/optical_system.py`)

## 1. Purpose
- Reads an optical system from a JSON file and returns a new `OpticalSystem` built by `OpticalSystem.from_dict`.
- It **never raises** an `Exception` subclass. Any failure is logged and the function returns `None`.

## 2. Inputs
- `filename: str` is a path (a `pathlib.Path` from `tmp_path` also works with `open`).
- Processing steps, in order, all inside one `try`:
  1. `reject_oversized_file(filename)` checks a size cap. It lives in `openlens.validation`, which is not shown; its exact limit is unknown.
  2. `open(filename, "r")` then `json.load(f)`. `json.load` accepts the bare `NaN`, `Infinity` and `-Infinity` literals.
  3. `data = json_safe_radii(data)` comes from `openlens.lens`, not shown. Per the docstring, it converts infinite *radii* (the legacy flat-surface spelling) to `null`.
  4. `reject_non_finite_numbers(data, "optical system")` rejects any remaining NaN or Infinity anywhere. Its implementation is not shown.
  5. `return OpticalSystem.from_dict(data)`. No `lens_lookup` is passed, so every lens is deserialized fresh.

## 3. Raises
- **Nothing.** The code is `except Exception as e: logger.error("Error loading optical system: %s", e); return None`.
- The logger name is `"openlens.optical_system"` and the level is ERROR.
- Inputs that return `None`:
  - Missing file: `OpticalSystem.load(str(tmp_path/"nope.json"))` returns `None`.
  - Invalid JSON text `"not json"` returns `None`.
  - Top-level JSON list `[]` returns `None`, because `data.get` raises AttributeError.
  - Non-finite value outside a radius, e.g. `{"name":"x","aperture_stop_diameter": NaN}`, returns `None`.
  - Legacy flat element (no `node_tree`) whose dict lacks the `"lens"` key returns `None` (KeyError in `elem_data["lens"]`).
    - This also happens when `node_tree` is present, because the elements are parsed first.
  - An invalid `image_plane_x_mm` makes `validate_image_plane_x` (in `openlens.lens`, not shown) raise, and the result is `None`.

## 4. Returns and guarantees (what `from_dict` restores)
- Each call returns a **new** `OpticalSystem`.
- Values copied straight from the file, when present:
  - `id`
  - `created_at`
  - `modified_at`: it is not touched afterwards, since `add_lens` and the rebuild steps do not update it.
  - `name`: default `"Optical System"`.
  - `aperture_stop_gap` and `aperture_stop_diameter`: raw values, default `None`.
  - `thermal_state_temperature`: default `DEFAULT_TEMPERATURE`, a constant whose value is not shown.
- `image_plane_x_mm = validate_image_plane_x(data.get("image_plane_x_mm"))`. `None` stays `None`.
- `casing = Casing.from_dict(...)` only if the value is a dict, else `None`. It is **not** validated against the lenses.
- `metadata` is `data["metadata"]` with every key in this set removed:
  - `{"id","name","type","created_at","modified_at","aperture_stop_gap","aperture_stop_diameter","elements","air_gaps","metadata","node_tree","thermal_state_temperature","image_plane_x_mm","casing"}`
  - Example: saving with metadata `{"tol": 1, "name": "zzz"}` loads back as `{"tol": 1}`.
- Elements are first added via `add_lens(lens, air_gap_before=gaps[i-1]["thickness"])` with decenter and tilt values converted by `float(x or 0.0)`.
- If `node_tree` is present (always true for files written by `save`), the tree is rebuilt from it:
  - The element lenses then come from `node_tree[...]["element_model"]`.
  - Node positions and rotations come from the tree.
  - Modifiers are restored, and nesting is preserved.
- Without `node_tree` (legacy file):
  - Each saved `"position"` that is not `None` overrides the root child's x.
  - Then the flat lists are rebuilt.
  - With no positions at all, the layout runs from x=0 using the gaps.
- Air gaps are recomputed from positions: `next.x - (x + thickness)`, clamped to ≥0.

## 5. Side effects
- The function only reads the file. It does not modify or create files.
- On failure it logs one ERROR record.

## 6. Branches / edge cases
- `{}` in the file gives a system with name `"Optical System"`, `elements == []`, `air_gaps == []`, `metadata == {}` and `aperture_stop_gap is None`. A fresh `id` is generated.
- A file containing a bare `Infinity` radius (legacy plano) still loads, because `json_safe_radii` converts it before the finite check. This relies on unseen helpers, so assert only `is not None`.
- A legacy dict with elements at saved positions 15 and 30 (thickness 5) loads with element positions 15 and 30 and gap thickness 10 at gap position 20.
- An empty or `null` `node_tree` takes the legacy path.

## 7. Rules from docstrings/comments
- The file is size-capped, and NaN/Infinity anywhere is rejected because NaN would silently defeat sanity checks.
- Legacy `Infinity` radii are the one accepted exception.
- `save` writes `json_safe_radii(to_dict())` with `indent=2` and `allow_nan=False`, so `save` followed by `load` must round-trip.

## 8. Testing hints
- Round trip:
  ```python
  s = OpticalSystem(name="T", metadata={"tol": 1, "name": "zzz"})
  s.add_lens(Lens(name="A", radius_of_curvature_1=50.0, radius_of_curvature_2=-50.0, thickness=5.0, diameter=25.0))
  s.add_lens(Lens(name="B", radius_of_curvature_1=50.0, radius_of_curvature_2=-50.0, thickness=5.0, diameter=25.0), air_gap_before=10.0)
  s.set_aperture_stop(0, 8.0)
  p = tmp_path/"s.json"; assert s.save(str(p))
  r = OpticalSystem.load(str(p))
  ```
- Assertions that hold for this round trip:
  - `r is not s`.
  - `r.id == s.id`, `r.name == "T"`, and `r.created_at`/`r.modified_at` equal the originals.
  - `[e.position for e in r.elements] == approx([0.0, 15.0])`.
  - `r.air_gaps[0].thickness == approx(10.0)` and `r.air_gaps[0].position == approx(5.0)`.
  - `r.get_aperture_stop() == {"gap_index": 0, "position": approx(5.0), "diameter": 8.0}`.
  - `r.metadata == {"tol": 1}`.
  - `[e.lens.name for e in r.elements] == ["A", "B"]`.
  - `r.get_system_focal_length() == approx(s.get_system_focal_length())`.
- Also check that `r.image_plane_x_mm` round-trips (set it to `None` or e.g. `120.0` before saving).
- Legacy files: build them by hand with `json.dump` from `Lens(...).to_dict()` dicts and finite radii, leaving out `node_tree`.
- Failure cases:
  - Use `caplog` (level ERROR) and assert `"Error loading optical system"` appears in `caplog.text`.
  - Use `assert result is None`, **not** `pytest.raises`.
- Pitfalls:
  - Write NaN by hand as text (`'{"aperture_stop_diameter": NaN}'`); `json.dump` with defaults does emit it.
  - Do not assume `DEFAULT_TEMPERATURE`'s value; compare against `s.thermal_state_temperature`.
  - Use `pytest.approx` for positions.

### openlens.tracer_3d.LensRayTracer3D.trace_surface

# Notes: `LensRayTracer3D.trace_surface(ray, surface_type, interaction="refract")`

## 1. Purpose
- Finds where a `Ray3D` meets one surface ("front" or "back") of a lens.
- Moves the ray to that point and adds the optical path length for the segment.
- Then refracts or reflects the ray in place.
- Returns a `RefractionResult` (`openlens.ray`).

## 2. Inputs
- `self`: a `LensRayTracer3D(lens, transform=None, x_offset=0.0)`.
  - Lens values are **snapshotted at construction**: R1/R2 (`get_effective_radius_*`), thickness `d`, diameter `D`, `n=lens.refractive_index`, parabolic/conic flags, clear apertures, Fresnel facets.
  - Editing the lens afterwards does not affect `trace_surface`.
  - With no transform, the front vertex is at world `(x_offset,0,0)` and the back vertex at `(x_offset+d,0,0)`. The optical axis is +x.
- `ray`: a `Ray3D(origin: Vector3, direction: Vector3, ..., n=REFRACTIVE_INDEX_AIR)`. It is mutated.
- `surface_type`: only `"front"` or `"back"`. Any other string returns `MISSED` immediately.
- `interaction`:
  - `"refract"` (default) or `"reflect"`.
  - Any other value is accepted but returns `MISSED` *after* the ray has already been moved (see §6).

**How the surface kind is chosen** (in `_calculate_geometry`; the order matters):
1. Parabolic: `is_parabolic_k` and `|parabolic_sag_k| > EPSILON`.
2. Flat: `_is_flat(R)` (defined in `openlens.lens`, not shown; presumably an infinite or huge radius).
3. Conic: `|conic_constant_k| > EPSILON`.
4. Otherwise a sphere.
   - Front centre is at local `x=R1`; back centre is at local `x=d+R2`.
   - The cap nearest the vertex is used (`abs(R)`, convex flag `R>0`).

## 3. Raises
- No explicit `raise`.
- Errors could only come from helpers in other modules (`Ray3D.reflect`, `refract_or_reflect`, `OpticalIntersector`). Do not test for exceptions.

## 4. Returns and guarantees
- `RefractionResult.MISSED` in the following cases. In all of them the ray is **unchanged** (origin, direction, n, OPL, path):
  - bad `surface_type`;
  - no intersection;
  - the hit lies outside the aperture;
  - the Fresnel facet intersection is None.
- Aperture test:
  - The radial distance squared, measured perpendicular to the axis from the vertex, must be `<= (CA/2 + 1e-9)**2`.
  - `CA` is `lens.get_clear_aperture_k()`, falling back to `D` when it returns falsy.
  - Hit exactly at `CA/2` passes. A hit at radius `> CA/2` is a miss.
- On a hit, in this order:
  1. `ray.optical_path_length += |hit - old_origin| * ray.n`, using the `n` from *before* refraction.
  2. `ray.origin = hit`.
  3. `hit` is appended to `ray.path` only if the path is empty or the ray moved by more than `EPSILON`. A zero-length hit is not recorded again, but it is still refracted.
- Choice of `(n1, n2)`. Defaults: front is `(air, lens.n)`, back is `(lens.n, air)`.
  - If `|ray.n - default_n1| < 1e-3`, use the defaults.
  - Else if `|ray.n - default_n2| < 1e-3`, swap them: `(default_n2, default_n1)`.
  - Otherwise use `(ray.n, default_n2)`.
- `"reflect"`: calls `ray.reflect(normal, n1, n2)` and always returns `REFLECTED`.
- `"refract"`: returns whatever `ray.refract_or_reflect(n1, n2, normal)` returns. That is in `openlens.ray`; expect `REFRACTED`, or `REFLECTED` on total internal reflection.
- Normals are always oriented outward: the front normal is about `-axis`, the back normal about `+axis`.
- Never sets `ray.terminated`.

## 5. Side effects
- Mutates `ray`: origin, OPL, path, and direction/n through the refraction or reflection call.
- The tracer and the lens are not changed.

## 6. Branches and edge cases
Shared test lens:
`lens = Lens(radius_of_curvature_1=50, radius_of_curvature_2=-50, thickness=5, diameter=25, refractive_index=1.5)`
`t = LensRayTracer3D(lens)`

- **On-axis front hit.**
  - Call: `ray = Ray3D(vec3(-10,0,0), vec3(1,0,0))`, then `t.trace_surface(ray,"front")`.
  - Returns `REFRACTED`; origin is `(0,0,0)`; OPL increases by `10.0` (n=1).
  - Direction stays about `(1,0,0)` (normal incidence).
- **Back hit after that.**
  - Origin `(0,0,0)` going +x hits `(5,0,0)` (back sphere centre `-45`, radius `50`).
  - OPL increases by `5*ray.n`. If `refract_or_reflect` set `n=1.5`, that is `+7.5`.
  - Since `ray.n≈1.5`, `(n1,n2)=(1.5,1.0)`.
- **Off-axis sphere hit.**
  - Ray from `(-10,5,0)` going +x hits the front at `x = 50 - sqrt(2475) ≈ 0.2506281`, `y=5`.
  - OPL increases by about `10.2506281`.
- **Aperture miss.**
  - Ray from `(-10,13,0)` going +x: the sphere is hit (|y|<50), but `169 > 12.5²`, so `MISSED`.
  - Origin stays `(-10,13,0)` and OPL is unchanged.
- **Sphere missed entirely.**
  - Ray at `y=60` going +x returns `MISSED`.
- **Invalid surface type.**
  - `t.trace_surface(ray, "middle")` returns `MISSED` with nothing changed.
- **Unknown interaction.**
  - `t.trace_surface(ray, "front", "absorb")` returns `MISSED`.
  - However, origin is now `(0,0,0)` and OPL has increased by 10. This is a deliberate observable quirk.
- **Reflect.**
  - On-axis front hit with `"reflect"` returns `REFLECTED`.
  - Direction should become about `(-1,0,0)`; this relies on `Ray3D.reflect` being standard mirror reflection.
- **Zero-length hit.**
  - A ray whose origin is already at the vertex, with a non-empty path: the path length does not grow and OPL increases by 0.
  - The ray is still refracted.
- **x_offset.**
  - `LensRayTracer3D(lens, x_offset=100)` puts the front hit at `(100,0,0)`.
- **Flat surface.**
  - The surface is a plane through the vertex.
  - A ray parallel to it, e.g. direction `(0,1,0)` (|denom|<EPSILON), returns `MISSED`.
  - A plane hit behind the ray (`t < -EPSILON`) returns `MISSED`.
- **Parabolic surface with effective R that is ~0 or > 1e10.**
  - Treated as a plane.
- **Fresnel lens (facets non-empty).**
  - Only facet hits count. If no facet is hit, the result is `MISSED`.
  - Facet construction is in `openlens.geometry` (not shown), so avoid exact values.

## 7. Rules from comments
- "A zero-length hit (t ~ 0) is legitimate and must still refract" (cemented doublets), but the point must not be recorded twice in `path`.
- A no-intersection result must be `MISSED` with the state unchanged. The ray must never be faked into a transmitted ray.
- OPL is accumulated per segment using the current medium's `n`.
- Normal convention: the front normal points to −axis and the back normal to +axis, whatever the sign of the curvature.
