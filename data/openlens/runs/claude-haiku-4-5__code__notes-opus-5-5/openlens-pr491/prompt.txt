# openlens.lens_editor.LensManager.delete_lens
    def delete_lens(self) -> None:
        """
        Interactive CLI method to delete a lens from the collection.

        Prompts user to select a lens and confirm deletion.
        Updates storage after deletion.
        """
        if not self.lenses:
            print("\nNo lenses to delete.")
            return

        self.list_lenses()
        try:
            idx = int(input("\nSelect lens number to delete: "))
            lens = self.get_lens_by_index(idx)

            if not lens:
                print("Invalid selection.")
                return

            confirm = input(f"Delete '{lens.name}'? (yes/no): ").strip().lower()
            if confirm == "yes":
                # Delete the row explicitly. Popping the in-memory list and
                # re-saving does NOT delete anything: save_lenses defaults to
                # reconcile=False and only inserts or replaces rows, so the
                # lens came straight back on the next start while the CLI
                # cheerfully reported success.
                #
                # Only drop it from memory once the row is really gone, and
                # never print success when the database refused.
                if not self._delete_row(lens):
                    print("Lens kept in the library.")
                    return

                self.lenses.pop(idx - 1)
                self.save_lenses()
                print("✓ Lens deleted successfully!")
            else:
                print("Deletion cancelled.")

        except (ValueError, IndexError):
            print("Invalid input.")

# openlens.lens_editor.main
def main() -> None:
    """Main entry point for the interactive CLI lens editor.

    Passing ``mcp`` as the first argument starts the MCP stdio server instead
    of the interactive menu, so an AI client can launch ``openlens-cli mcp``.
    """
    if len(sys.argv) > 1 and sys.argv[1] == "mcp":
        from .mcp_server import main as mcp_main

        raise SystemExit(mcp_main())

    setup_logging(verbose=verbose_requested())
    manager = LensManager()

    print("=" * 60)
    print("   openlens - Optical Lens Creation & Modification Tool")
    print("=" * 60)

    while True:
        print("\n--- Menu ---")
        print("1. Create new lens")
        print("2. List all lenses")
        print("3. View lens details")
        print("4. Modify lens")
        print("5. Delete lens")
        print("6. Exit")

        choice = input("\nSelect option: ").strip()

        if choice == "1":
            manager.create_lens()
        elif choice == "2":
            manager.list_lenses()
        elif choice == "3":
            manager.view_lens()
        elif choice == "4":
            manager.modify_lens()
        elif choice == "5":
            manager.delete_lens()
        elif choice == "6":
            print("\nGoodbye!")
            break
        else:
            print("Invalid option. Please try again.")

### openlens.lens_editor.LensManager.delete_lens

# Notes: `openlens.lens_editor.LensManager.delete_lens(self) -> None`

## 1. Purpose
- Interactive CLI step. It lists the lenses, asks for a 1-based number, and asks for confirmation.
- It deletes the database row first, through `_delete_row`. Only if that succeeds does it remove the lens from `self.lenses` and call `save_lenses()`.
- It returns `None` on every path. All outcomes show up only as printed text and state changes.

## 2. Inputs
- No parameters apart from `self`. It uses `self.lenses` (a list of `Lens`) and `self.storage_file`, which `_delete_row` uses.
- It reads `builtins.input` up to twice:
  1. `input("\nSelect lens number to delete: ")` is passed to `int(...)`.
     - `int` itself accepts surrounding whitespace, so `" 2 "` works.
     - `"2.0"`, `"abc"` and `""` raise `ValueError`.
  2. `input(f"Delete '{lens.name}'? (yes/no): ")` is passed through `.strip().lower()`.
     - Only the exact result `"yes"` confirms. `"YES"` and `"  Yes "` confirm.
     - `"y"`, `"no"` and `""` cancel.
- Index check (`get_lens_by_index`): valid only when `1 <= idx <= len(self.lenses)`. Otherwise it returns `None`. Values `0` and negatives are invalid, so there is no Python negative indexing.

## 3. Raises
- In practice nothing escapes for normal string input:
  - `ValueError` and `IndexError` inside the `try` are caught and print `Invalid input.`.
  - `_delete_row` catches every `Exception`.
  - `save_lenses` catches every `Exception`.
- `EOFError` and `KeyboardInterrupt` from `input` are **not** caught and propagate. For example, a mocked input that raises `StopIteration` will propagate.
- `list_lenses()` runs before the `try`. An error from `lens.calculate_focal_length()` would propagate.

## 4. Returns / state
- Always returns `None`.
- On success:
  - `self.lenses.pop(idx - 1)` removes that exact object; the remaining order is preserved.
  - `self.save_lenses()` is called once, after the pop.
- On every other path, `self.lenses` is unchanged and `save_lenses` is **not** called.

## 5. Side effects
- Prints to stdout.
- Database deletion: `_delete_row` imports `LensStorage` from `openlens.gui.storage` at call time and calls `LensStorage(self.storage_file).delete_item(lens.id)`. That code is in another module and its behaviour is not visible here.
- Unexpected errors are logged with `logger.error` (logger `openlens.lens_editor`).

## 6. Branches (stdout lines, in order; prompts are not printed when `input` is mocked)
| Case | Inputs | Output after the listing | State |
|---|---|---|---|
| Empty list | (no input called) | `"\nNo lenses to delete."` only; no listing at all | unchanged |
| Non-integer | `"abc"` | `Invalid input.` | unchanged |
| Out of range | `"0"`, `"-1"`, `"3"` with 2 lenses | `Invalid selection.` (confirmation prompt never asked) | unchanged |
| Cancelled | `"1"`, `"no"` | `Deletion cancelled.` (`_delete_row` not called) | unchanged |
| `_delete_row` returns False | `"1"`, `"yes"` | (any message from `_delete_row`), then `Lens kept in the library.` | unchanged, no save |
| Success | `"1"`, `"yes"` | `✓ Lens deleted successfully!` | lens removed, saved once |

How `_delete_row` returns False:
- **`STORAGE_AVAILABLE` is False:** it prints nothing extra.
- **`LensInUseError` is raised:** it prints `f"Cannot delete '{lens.name}': {e}"`. The text of `e` comes from `openlens.database` and is not shown here.
- **Any other exception `e`:** it prints `f"Could not delete '{lens.name}' from the database: {e}"`. Example: `RuntimeError("boom")` prints `Could not delete 'A' from the database: boom`.

Listing printed first (from `list_lenses`, for a non-empty list):
- Header: `f"\n=== All Optical Lenses ({n}) ==="`
- One line per lens: `f"{i}. {name} - {material} ({lens_type}) - f={focal:.2f}mm or Undefined"`

## 7. Rules from comments
- Popping the list and re-saving does NOT delete anything. `save_lenses` defaults to `reconcile=False` and only inserts or replaces rows. That is why the explicit row delete happens first.
- The lens is dropped from memory only once the row is really gone.
- Success is never printed when the database refused the deletion.

### openlens.lens_editor.main

# Notes: `openlens.lens_editor.main()`

## 1. Purpose
- Entry point for the interactive CLI lens editor.
- With `mcp` as the first CLI argument, it hands off to the MCP stdio server.
- Otherwise it runs a text menu loop that dispatches to `LensManager` methods until the user picks "6".

## 2. Inputs
- No parameters. It reads three things:
  - `sys.argv`: only `sys.argv[1]` is inspected, and only when `len(sys.argv) > 1`. The match is exact (`== "mcp"`, case-sensitive, not stripped).
  - `builtins.input`: called with the prompt `"\nSelect option: "`. The result is `.strip()`-ed.
  - `verbose_requested()`, called with no args. It is defined in `openlens.logging_setup` (not shown here); it reads `sys.argv[1:]`.
- Module-level names it looks up at call time, all patchable on `openlens.lens_editor`:
  - `setup_logging`
  - `verbose_requested`
  - `LensManager`
  - `sys`

## 3. Raises
- **`SystemExit(mcp_main())`** when `sys.argv[1] == "mcp"`.
  - `.code` is whatever `openlens.mcp_server.main()` returns.
  - `mcp_server` is imported lazily, inside this branch only.
  - Example: `sys.argv = ["openlens-cli", "mcp"]` with a fake `mcp_server.main` returning `3` gives `SystemExit` with `.code == 3`.
- **No try/except in `main`.** Any exception from these propagates unchanged:
  - `input()`: e.g. `EOFError`, or `StopIteration` from a fake input iterator that runs out.
  - `LensManager()`.
  - Any manager method.
  - `setup_logging`.

## 4. Returns and guarantees
- Returns `None`, only after choice `"6"` (it `break`s the loop).
- Creates exactly one `LensManager()` with no arguments, so it uses the default DB path. The real class may seed example data into the user's app DB, so always patch it.
- Stdout for an immediate `"6"` (with `input` patched, so no prompt text is printed):

```
============================================================
   openlens - Optical Lens Creation & Modification Tool
============================================================

--- Menu ---
1. Create new lens
2. List all lenses
3. View lens details
4. Modify lens
5. Delete lens
6. Exit

Goodbye!
```

- Formatting details:
  - Banner lines are `"=" * 60`, i.e. 60 `=` characters.
  - The title line starts with 3 spaces.
  - `"\n--- Menu ---"` and `"\nGoodbye!"` each produce a blank line first.

## 5. Side effects
- Calls `setup_logging(verbose=verbose_requested())` once. This happens only on the menu path, never on the mcp path.
- Prints to stdout.
- Any persistence happens inside `LensManager` methods, not in `main` itself.

## 6. Branches and edge cases
- **mcp path:** `argv[1] == "mcp"`. Extra args are allowed (`["x", "mcp", "--foo"]` still takes this path).
  - Raises `SystemExit` before `setup_logging` and before `LensManager` is constructed.
  - `"MCP"`, `" mcp"` and `"mcp2"` do NOT match; they run the menu.
- **`argv` length ≤ 1** (e.g. `["prog"]`): menu path.
- **Menu choices** (after strip):

  | Choice | Action |
  |---|---|
  | `"1"` | `manager.create_lens()` |
  | `"2"` | `manager.list_lenses()` |
  | `"3"` | `manager.view_lens()` |
  | `"4"` | `manager.modify_lens()` |
  | `"5"` | `manager.delete_lens()` |
  | `"6"` | prints `"\nGoodbye!"`, then returns |
  | anything else | prints `Invalid option. Please try again.` and loops |

  - Each method is called with no args, and its return value is ignored.
  - "Anything else" includes `""`, `"7"`, `"01"`, `"1.0"`, `"exit"`.
- **Whitespace is stripped:** `"  2  "` calls `list_lenses`, and `" 6\n"` exits.
- **The menu reprints before every prompt.** Inputs `["9", "6"]` print the menu block twice, `Invalid option. Please try again.` once, then `Goodbye!`.
- **One call per choice:** inputs `["1", "1", "6"]` call `create_lens` twice and nothing else.

## 7. Rules stated in comments or docstrings
- The docstring states that `mcp` as the first argument starts the MCP stdio server instead of the menu (`openlens-cli mcp`).
