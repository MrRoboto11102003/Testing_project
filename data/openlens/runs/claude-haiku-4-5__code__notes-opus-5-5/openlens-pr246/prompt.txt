# openlens.tracer_2d.LensRayTracer.trace_parallel_rays
    def trace_parallel_rays(
        self,
        num_rays: int = DEFAULT_NUM_RAYS,
        ray_height_range: Optional[Tuple[float, float]] = None,
        wavelength_mm: float = WAVELENGTH_GREEN * NM_TO_MM,
        angle_deg: float = 0.0,
        fill: float = 1.0,
    ) -> List[Ray]:
        """Trace parallel rays (collimated beam) through the lens.

        Args:
            fill: Fraction of the semi-aperture spanned by the fan when
                ``ray_height_range`` is omitted. Defaults to the full
                aperture so rim spherical aberration is traced; pass the
                legacy viz-style ``APERTURE_FILL_FACTOR`` (0.95) explicitly
                for display fans.
        """
        if ray_height_range is None:
            max_height = self.D / 2 * fill
            ray_height_range = (-max_height, max_height)

        rays = []
        min_h, max_h = ray_height_range
        angle_rad = math.radians(angle_deg)
        # The bundle is referenced to the front vertex, not to the origin. With
        # lens_x hard-coded to 0.0 a lens placed anywhere else had its
        # back-projection computed against the wrong plane, so it received the
        # fan at the wrong heights: a 0-height 5 deg ray for a lens at
        # x_offset=50 arrived at y=4.3744 mm instead of on axis. The start
        # plane moves with the vertex so the ray still begins in front of it.
        lens_x = self.front_vertex_x
        start_x = lens_x - RAY_START_OFFSET_MM

        for i in range(num_rays):
            if num_rays == 1:
                height = 0
            else:
                height = min_h + (max_h - min_h) * i / (num_rays - 1)

            y_start = height - (lens_x - start_x) * math.tan(angle_rad)
            ray = Ray(start_x, y_start, angle_rad, wavelength_mm=wavelength_mm)
            self.trace_ray(ray)
            rays.append(ray)

        return rays

# openlens.tracer_2d.SystemRayTracer.trace_parallel_rays
    def trace_parallel_rays(
        self,
        num_rays: int = DEFAULT_NUM_RAYS,
        angle_deg: float = 0.0,
        wavelength_mm: float = WAVELENGTH_GREEN * NM_TO_MM,
        fill: float = 1.0,
    ) -> List[Ray]:
        """Trace parallel rays through the entire optical system.

        Args:
            fill: Fraction of the entrance-pupil semi-aperture spanned by
                the fan. Defaults to the full aperture; pass the legacy
                viz-style ``APERTURE_FILL_FACTOR`` (0.95) explicitly for
                display fans.
        """
        if not self.system.elements:
            return []

        self._sync_tracers()

        first_lens = self.system.elements[0].lens
        max_height = first_lens.diameter / 2 * fill
        min_h, max_h = -max_height, max_height

        rays = []
        angle_rad = math.radians(angle_deg)
        first_pos = self.system.elements[0].position
        start_x = first_pos - RAY_START_OFFSET_MM

        for i in range(num_rays):
            if num_rays == 1:
                height = 0
            else:
                height = min_h + (max_h - min_h) * i / (num_rays - 1)

            y_start = height - (first_pos - start_x) * math.tan(angle_rad)
            ray = Ray(start_x, y_start, angle_rad, wavelength_mm=wavelength_mm)
            self._trace_ray_through_system(ray)
            rays.append(ray)

        return rays

### openlens.tracer_2d.LensRayTracer.trace_parallel_rays

# Notes: `LensRayTracer.trace_parallel_rays`

## 1. Purpose
- Builds a fan of `num_rays` parallel (collimated) `Ray`s, all at the same tilt `angle_deg`.
- Traces each ray through the single lens with `self.trace_ray(ray)` and returns the traced rays in fan order.

## 2. Inputs
- `num_rays: int = DEFAULT_NUM_RAYS`
  - The value of `DEFAULT_NUM_RAYS` lives in `openlens.constants`, which is not shown. Always pass `num_rays` explicitly.
  - Used as `range(num_rays)`, so `0` or a negative value gives no rays.
- `ray_height_range: Optional[(min_h, max_h)] = None`
  - `None`: uses `(-D/2*fill, +D/2*fill)`.
  - `D` is `self.D`, the lens's **mechanical** `lens.diameter`. It is *not* the clear aperture.
  - A tuple is unpacked as `min_h, max_h` and is not validated. A reversed range such as `(5, -5)` is allowed and produces a descending fan.
- `wavelength_mm: float = WAVELENGTH_GREEN * NM_TO_MM`
  - Only stored on each `Ray` (`wavelength_mm=` argument).
  - It does **not** change refraction. The tracer always uses `self.n`, fixed in `__init__` from the `wavelength_nm` argument or from `lens.refractive_index`.
- `angle_deg: float = 0.0`
  - Converted with `math.radians`. Every ray starts with `angle = radians(angle_deg)`.
- `fill: float = 1.0`
  - Used **only** when `ray_height_range is None`. It is ignored when a range is given.

## 3. Raises
- The method raises nothing explicitly.
- Unpacking a `ray_height_range` that is not a 2-sequence raises `ValueError`/`TypeError` (Python unpacking error).
- Errors coming from `Ray(...)` or `trace_ray` are defined in other modules, so they are not known here.

## 4. Returns and guarantees
- Returns a new `list` of new `Ray` objects, `len == max(num_rays, 0)`, in index order `i = 0 .. num_rays-1`.
- Height of ray `i`:
  - If `num_rays == 1`: `height = 0`. This holds **even if a custom range is given**: `(2, 4)` gives height 0, not 3.
  - Otherwise: `height = min_h + (max_h - min_h) * i / (num_rays - 1)`. This is linspace including both endpoints.
- Start point of each ray:
  - `start_x = front_vertex_x - RAY_START_OFFSET_MM`, where `front_vertex_x == x_offset`. The constant's value is not shown.
  - `y_start = height - RAY_START_OFFSET_MM * tan(angle_rad)`.
  - So the unrefracted straight line reaches the plane `x = x_offset` at exactly `y = height`. The fan is referenced to the front vertex, not to x = 0. The code comment calls this a bug fix.
- Tracing:
  - Each ray is traced with `trace_ray(ray)` using the default `propagate_distance = DEFAULT_PROPAGATION_DISTANCE` (value in constants, not shown).
- Ray that misses the front surface:
  - Gets `hit=False` and `terminated=True`.
  - It is still propagated by that distance if the distance is > 0.
  - It is still included in the returned list. Nothing is filtered out.
- Ray that passes through:
  - Gets `hit=True`.
  - Its `path` gains the front-surface point and the back-surface point.
  - It is then propagated forward.
- Whether `Ray.__init__` puts the start point into `path` is defined in `openlens.ray`, which is not shown. Do not assert on the exact length of `path` or on `path[0]`.

## 5. Side effects
- The lens and the tracer's state are not mutated.
- Only the newly created rays change.
- No global state is touched.

## 6. Branches and edge cases

| Call | Observable result |
|---|---|
| `num_rays=0` | `[]` |
| `num_rays=-3` | `[]` |
| `num_rays=1`, any range | one ray, starting height 0. At `angle_deg=0` its `y` stays ≈ 0 and its angle stays ≈ 0 through a centred symmetric lens. |
| `num_rays=5`, range `None`, `D=25`, `fill=1` | heights `-12.5, -6.25, 0, 6.25, 12.5` |
| `fill=0.5` with `D=25` | heights span ±6.25 |
| `fill` together with an explicit range | `fill` is ignored |
| range `(-20, 20)` on a `D=25` lens | outer rays miss (`hit is False`, `terminated is True`) and are still returned |

## 7. Rules stated in comments/docstrings
- `fill` defaults to the full aperture so that rim spherical aberration is traced. Callers pass `0.95` explicitly for display fans.
- The fan start plane moves with the front vertex. The comment's example: before the fix, a 0-height 5° ray for a lens at `x_offset=50` arrived at y = 4.3744 instead of on axis.

## 8. Testing hints
Build a symmetric biconvex lens with explicit parameters, and read the index back instead of assuming it:
```python
from openlens.lens import Lens
from openlens.tracer_2d import LensRayTracer
lens = Lens(radius_of_curvature_1=50.0, radius_of_curvature_2=-50.0, thickness=5.0,
            diameter=25.0, refractive_index=1.5)
t = LensRayTracer(lens)            # t.D == 25.0; use t.n, not a hard-coded value
rays = t.trace_parallel_rays(num_rays=5, angle_deg=0.0)
```
Sign convention: `front_center = vertex + R1` and `back_center = back_vertex + R2`, so `R1 > 0` with `R2 < 0` is biconvex.

Checks that are robust on the current code:
- **Count and types:** `len(rays) == 5`, and every element is an `openlens.ray.Ray` instance.
- **Symmetry at angle 0:** `rays[i].y ≈ -rays[4-i].y` and `rays[i].angle ≈ -rays[4-i].angle`. The middle ray has `y ≈ 0` and `angle ≈ 0`. Use `pytest.approx(abs=1e-9)`.
- **Convergence:** the top ray (`i=4`, positive start height) ends with `angle < 0`. The bottom ray ends with `angle > 0`.
- **Front-surface heights at angle 0:** a ray stays horizontal until it hits the lens. So for every hit ray, some point in `ray.path` has `y == pytest.approx(expected_height)`, where `expected_height = -12.5 + 6.25*i`.
- **Offset invariance (strongest regression check):**
  - Compare `LensRayTracer(lens, x_offset=0)` and `LensRayTracer(lens, x_offset=50)` with the same arguments, including `angle_deg=5`.
  - The final `y` and `angle` of each ray pair must be equal, and the final `x` values must differ by exactly 50 (`approx(abs=1e-6)`).
  - This only passes because the fan is referenced to the front vertex.
- **Wavelength independence:**
  - Two fans that differ only in `wavelength_mm` (e.g. `0.0005` vs `0.0007`) give identical final `y` and `angle`.
  - Each ray's `wavelength_mm` equals the value passed. Assert with `approx`, because the Ray property may normalise it.
- **Single ray:** `num_rays=1, ray_height_range=(2, 4)` gives a ray whose final `y` matches the `num_rays=1` default-range ray. Both start at height 0.
- **`fill`:**
  - `fill=0.4` gives the same results as an explicit `ray_height_range=(-5, 5)` when D=25.
  - `fill=0.4` combined with `ray_height_range=(-10, 10)` gives the same results as the range alone.
- **Misses:** range `(-20, 20)` with `num_rays=3` gives `rays[0].hit is False`, `rays[2].hit is False`, `rays[1].hit is True`, and `len == 3`.

Pitfalls:
- Do not hard-code `RAY_START_OFFSET_MM`, `DEFAULT_NUM_RAYS` or `DEFAULT_PROPAGATION_DISTANCE`. Their values are not shown. Import them from `openlens.constants` if you need them.
- Do not assert exact final `x` values or exact path lengths. Use relative comparisons such as symmetry, offset differences and equality between two runs.

### openlens.tracer_2d.SystemRayTracer.trace_parallel_rays

# Notes: `SystemRayTracer.trace_parallel_rays(num_rays=DEFAULT_NUM_RAYS, angle_deg=0.0, wavelength_mm=WAVELENGTH_GREEN*NM_TO_MM, fill=1.0)`

## 1. Purpose
- Builds a collimated fan of 2D `Ray`s and traces each one through every element of `self.system`.
- Each ray goes through the elements in order, then the aperture stop, then the casing.
- Returns the list of traced rays.

## 2. Inputs
- `num_rays` (int): not validated.
  - It is used in `range(num_rays)`, so `0` or a negative value gives `[]` when the system has elements.
  - `1` is a special case: the single ray is at height 0.
  - `DEFAULT_NUM_RAYS` is defined in `openlens.constants`, which is not shown. Pass `num_rays` explicitly.
- `angle_deg` (float, degrees): converted with `math.radians`. Every ray starts with `angle = radians(angle_deg)`.
- `wavelength_mm` (float): passed only to the `Ray(..., wavelength_mm=...)` constructor.
  - **It does NOT change the glass index.** The index comes from the `wavelength_nm` given to `SystemRayTracer(system, wavelength_nm)`. If that is `None`, each lens's stored `refractive_index` is used.
- `fill` (float): not validated. `max_height = elements[0].lens.diameter / 2 * fill`.
  - `fill=0` puts every ray at height 0.
  - A negative `fill` reverses the order of the heights.
- Inputs it does not take: there is no `ray_height_range` parameter, unlike `LensRayTracer.trace_parallel_rays`.

## 3. Raises
- The function raises nothing itself.
- An error could only come from the `Lens`, `Ray` or `OpticalSystem` code, which is not shown. A normal `Lens` raises nothing here.

## 4. Returns and guarantees
- Empty system (`system.elements == []`): returns `[]` straight away, before the tracers are rebuilt.
- Otherwise: returns a new `list` of exactly `max(num_rays, 0)` new `Ray` objects, in order of increasing height when `fill > 0`.
- Ray `i` has `height = -h + 2h*i/(num_rays-1)`, where `h = D0/2*fill` and `D0` is the diameter of the first lens.
  - Example: with D0=25, fill=1 and 5 rays, the heights are -12.5, -6.25, 0, 6.25, 12.5.
- Every ray starts at `x = p0 - RAY_START_OFFSET_MM`, where `p0 = elements[0].position`.
  - Its start height is `y = height - RAY_START_OFFSET_MM * tan(angle)`.
  - So the straight-line extension of each ray passes through `(p0, height)`, the first element's vertex plane.
  - The value of `RAY_START_OFFSET_MM` lives in `constants` and is not shown.
- What happens to each ray depends on how it ends:
  - **Missed an element aperture:** `ray.hit=False`, `ray.terminated=True`, and it is not propagated further. Clipping uses the clear aperture: `CA1/2` at the front surface, `CA2/2` at the back.
  - **TIR, or exit through the side:** `terminated=True`, and the loop breaks.
  - **Blocked by the aperture stop:** this check runs after element `i` when `stop["gap_index"] == i` and the stop diameter is truthy.
    - If `|y at stop_x| > diameter/2`, the ray is terminated.
    - If the stop plane is ahead of the ray, the stop point is appended to `path`.
  - **Survived every element:** after the last element the ray gets `ray.propagate(RAY_EXIT_PROPAGATION_2D_MM)`. That value is in `constants` and is not shown.
  - **Casing absorption:** if `system.casing` is set, a path segment that enters the wall truncates `path` at the hit point. It also sets `x,y` to the hit point, `terminated=True` and `absorbed=True`.
    - The pre-first-element casing check (`_absorb_before_first_element`) is **not** called here. Only the finished path is checked.

## 5. Side effects
- The function calls `_sync_tracers()`, which rebuilds `self._tracers` from the current lens parameters and `element.position`.
  - So if you edit a lens between two calls, the second call picks up the edit.
- `system` and the lenses are not mutated.

## 6. Branches and edge cases
| Case | Input | Result |
|---|---|---|
| No elements | `OpticalSystem()` | `[]` |
| Zero rays | `num_rays=0` | `[]` |
| Single ray | `num_rays=1` | one ray at height 0 (start y = `-OFFSET*tan(angle)`) |
| Centered element | `decenter_y == 0` and `tilt_z == 0` | `LensRayTracer.trace_ray(ray, propagate_distance=0)` |
| Aligned element | `decenter_y != 0` or `tilt_z != 0` | traced in the local frame, and the path points are mapped back to world coordinates |
| Fan wider than CA | `clear_aperture_1 < diameter` | outer rays have `hit=False` and `terminated=True` |
| Stop | `set_aperture_stop(0, diameter=d)` on a 2-element system | rays above `d/2` at the stop are terminated |

## 7. Rules from comments and docstrings
- `fill` defaults to the full aperture, so rim spherical aberration is traced. Display fans pass 0.95 explicitly.
- A terminated flag is never cleared. Terminated rays are never propagated forward.
- The 2D trace honours only `decenter_y` and `tilt_z`. The other alignment parameters apply in 3D only.

## 8. Testing hints

  - The final `ray.angle` values should be equal.
  - The path points at the two lens surfaces should be equal.
  - Do not compare the final `x`/`y`: the exit propagation distances differ (`DEFAULT_PROPAGATION_DISTANCE` vs `RAY_EXIT_PROPAGATION_2D_MM`).
- **Heights are referenced to the first element's diameter, not the clear aperture.**
  - Example: `Lens(diameter=25, clear_aperture_1=10)` with `num_rays=5` and `fill=1`.

- **Index comes from the constructor, not from `wavelength_mm`.**
  - Changing `wavelength_mm` alone gives identical angles.
  - Changing `SystemRayTracer(s, wavelength_nm=...)` gives different angles.
- **Pitfalls:**
  - Do not assume `ray.path` contains the start point. That depends on the `Ray` class, which is not shown.
  - Do not hard-code `RAY_START_OFFSET_MM` or the exit distance.
  - An on-axis ray should stay at y≈0. Use `approx(0, abs=1e-9)`, not `==`.
