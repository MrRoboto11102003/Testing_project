    def plot_airy_disk(
        self,
        focal_length: float,
        aperture_diameter: float,
        save_path: Optional[str] = None,
    ):
        """
        Plot Airy disk intensity pattern

        Args:
            focal_length: Focal length in mm
            aperture_diameter: Aperture diameter in mm
            save_path: Optional path to save the plot
        """
        airy_r = self.airy_disk_radius(focal_length, aperture_diameter)

            color="r",
            linestyle="--",
            label=f"Airy disk radius = {airy_r:.2f} μm",
        )

        else:

    def plot_psf_2d(
        self,
        focal_length: float,
        aperture_diameter: float,
        save_path: Optional[str] = None,
    ):
        """
        Plot 2D point spread function

        Args:
            focal_length: Focal length in mm
            aperture_diameter: Aperture diameter in mm
            save_path: Optional path to save the plot
        """
        airy_r = self.airy_disk_radius(focal_length, aperture_diameter)
        size = 10 * airy_r
        if not MATPLOTLIB_AVAILABLE:
            logger.warning("plot_psf_2d unavailable: matplotlib is not installed. Skipping.")
            return

        psf = self.point_spread_function_2d(size, focal_length, aperture_diameter)

        fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))

        # 2D PSF
        extent = [-size / 2, size / 2, -size / 2, size / 2]
        im = ax1.imshow(psf, extent=extent, cmap="hot", origin="lower")
        ax1.set_xlabel("X (μm)")
        ax1.set_ylabel("Y (μm)")
        ax1.set_title("2D Point Spread Function")
        plt.colorbar(im, ax=ax1, label="Normalized Intensity")

        # Cross-section
        center = psf.shape[0] // 2
        profile = psf[center, :]
        x_coords = np.linspace(-size / 2, size / 2, len(profile))
        ax2.plot(x_coords, np.real(profile), "b-", linewidth=2)
        ax2.axvline(
            x=airy_r,
            color="r",
            linestyle="--",
            label=f"Airy disk radius = {airy_r:.2f} μm",
        )
        ax2.axvline(x=-airy_r, color="r", linestyle="--")
        ax2.set_xlabel("Position (μm)")
        ax2.set_ylabel("Normalized Intensity")
        ax2.set_title("PSF Cross-Section")
        ax2.grid(True, alpha=0.3)
        ax2.legend()

        plt.suptitle(
            f"Point Spread Function Analysis\n(f={focal_length}mm, "
            f"D={aperture_diameter}mm, λ={self.wavelength*1e9:.0f}nm)"
        )
        plt.tight_layout()

        if save_path:
            plt.savefig(save_path, dpi=300, bbox_inches="tight")
        else:
            plt.show()

        plt.close()

### openlens.diffraction.DiffractionCalculator.plot_airy_disk

# Notes: `DiffractionCalculator.plot_airy_disk(focal_length, aperture_diameter, save_path=None)`

## 1. Purpose
- Draws the normalized 1-D Airy intensity profile with matplotlib.
- Marks the Airy-disk radius and a 50 % line on the plot.
- Saves the figure to `save_path`, or calls `plt.show()` when no path is given.
- Always closes the figure and returns `None`.

## 2. Inputs
- `focal_length` (mm) and `aperture_diameter` (mm): plain numbers.
  - No validation or conversion is done.
  - They are inserted into the title exactly as given: `100` prints as `100`, `100.0` prints as `100.0`.
- `save_path`: optional `str` or path-like.
  - The check is truthiness, so `None` and `""` both go to `plt.show()`.
  - Any truthy value goes to `plt.savefig(save_path, dpi=300, bbox_inches="tight")`.
- Instance state used:
  - `self.wavelength_m` drives the numbers. The default is `550e-9`. `DiffractionCalculator(wavelength=633e-9)` also sets it through the kwargs alias.
  - `self.wavelength` (an alias of `wavelength_m`) is used for the title.

## 3. Raises
Order of operations: compute `airy_r`, then check `MATPLOTLIB_AVAILABLE`, then plot. So division errors happen even when matplotlib is missing.
- **`aperture_diameter=0`** raises `ZeroDivisionError("float division by zero")`.
  - It comes from `airy_disk_radius_um`, which computes `1.22*λ*f/D` with Python floats.
  - Example: `DiffractionCalculator().plot_airy_disk(100, 0)`.
- **`focal_length=0`** does not raise.
  - numpy produces NaN with a RuntimeWarning, so the plot is meaningless.
  - Avoid it in tests.
- Errors from `savefig` (for example a bad directory) propagate from matplotlib.

## 4. Returns and guarantees
- Always returns `None`.
- Computed values:
  - `airy_r = 1.22 * wavelength_m * focal_length / aperture_diameter * 1e6`, in µm. Example: λ = 550 nm, f = 100, D = 10 gives `6.71`.
  - `max_radius = 5 * airy_r`.
  - The data comes from `self.airy_pattern(max_radius, focal_length, aperture_diameter)` with the default 1000 points.
- Figure content (one Axes, `figsize=(10, 6)`):
  - `lines[0]`: the curve `plot(r, np.real(intensity), "b-", linewidth=2)`.
    - 1000 points; x runs from 0 to `5*airy_r`.
    - y is normalized, so its max is `1.0` and `y[0]` ≈ 1.0. It has no label.
  - `lines[1]`: `axvline(x=airy_r, color="r", linestyle="--", label=f"Airy disk radius = {airy_r:.2f} μm")`. Its xdata is `[airy_r, airy_r]`.
  - `lines[2]`: `axhline(y=0.5, color="g", linestyle=":", alpha=0.5)`. Its ydata is `[0.5, 0.5]`.
  - xlabel is `"Radius (μm)"` and ylabel is `"Normalized Intensity"` (µ here is U+03BC Greek mu, not the micro sign).
  - Title template: `f"Airy Diffraction Pattern\n(f={focal_length}mm, D={aperture_diameter}mm, λ={self.wavelength*1e9:.0f}nm)"`. Example: `"Airy Diffraction Pattern\n(f=100mm, D=10mm, λ=550nm)"`.
  - Grid is on with `alpha=0.3`.
  - The legend has exactly one entry: `"Airy disk radius = 6.71 μm"` for the example above.

## 5. Side effects
- Creates a new pyplot figure.
- Then calls `savefig` (writes a file at dpi 300) or `show`.
- Finally calls `plt.close()`, which closes the current (new) figure. The count from `plt.get_fignums()` is unchanged afterwards.
- No instance attributes are changed.

## 6. Branches
- **Matplotlib unavailable**:
  - Triggered with `monkeypatch.setattr(openlens.diffraction, "MATPLOTLIB_AVAILABLE", False)`.
  - Logs a WARNING on logger `"openlens.diffraction"` with the exact text: `"plot_airy_disk unavailable: matplotlib is not installed. Skipping."`
  - Returns `None` without calling `airy_pattern` or any `plt` function.
  - `airy_r` is still computed, so `aperture_diameter=0` still raises here.
- **`save_path` truthy**: `plt.savefig(save_path, dpi=300, bbox_inches="tight")`. `plt.show` is not called.
- **`save_path` is `None` or `""`**: `plt.show()`. `savefig` is not called.
- `plt.close()` runs on both plotting paths.

## 8. Testing hints
- Use the non-GUI backend: `import matplotlib; matplotlib.use("Agg")` before importing pyplot.
- File test:
  - Call `calc.plot_airy_disk(100, 10, save_path=str(tmp_path/"a.png"))`.
  - Assert the file exists and has size > 0, and the return value is `None`.
- Inspecting the figure: it is closed before return, so capture it inside a patched `savefig`.

- Use `pytest.approx` for numbers and exact strings for formatted labels.
  - The `:.2f` and `:.0f` formatting removes float noise: `550e-9*1e9` becomes `550`.
  - Other wavelengths: `633e-9` gives title `λ=633nm` and label `"Airy disk radius = 7.72 μm"` (f = 100, D = 10).
- Pitfalls:
  - Do not try to read the figure after the call returns; it is already closed.
  - The curve line has no label, so do not expect two legend entries.
  - `scipy.special.j1` or the numpy fallback may be used. The values are equal to roughly 1e-6, so use tolerances.

### openlens.diffraction.DiffractionCalculator.plot_encircled_energy

# Notes: `DiffractionCalculator.plot_encircled_energy(self, focal_length, aperture_diameter, save_path=None)`

## 1. Purpose
- Draws the analytic Airy encircled-energy curve (in %) with matplotlib.
- Marks the Airy radius and the 50% / 80% points.
- Then either saves the figure to `save_path` or calls `plt.show()`, and always closes it.
- Returns `None`.

## 2. Inputs
- `focal_length` (mm) and `aperture_diameter` (mm): plain numbers, not validated.
- They are passed unchanged to `self.encircled_energy(...)` and `self.airy_disk_radius(...)`.
- They appear verbatim in the title via `{focal_length}`. So `100` renders as `f=100mm` and `100.0` renders as `f=100.0mm`.
- `save_path`: optional. Its truthiness decides the branch:
  - Truthy: `plt.savefig(save_path, dpi=300, bbox_inches="tight")`.
  - `None` or `""`: `plt.show()`.
- Wavelength comes from `self.wavelength_m` (default `550e-9`). The `wavelength` property is an alias, and the title uses `self.wavelength*1e9`.

## 3. Raises
- **Check order:**
  1. `encircled_energy` is computed first, before the matplotlib check.
  2. Then the `MATPLOTLIB_AVAILABLE` check.
  3. Then `airy_disk_radius`.
- `aperture_diameter=0` (int or float) raises `ZeroDivisionError("float division by zero")`.
  - Source: `airy_disk_radius_um`, line `1.22*λ*f/D` with `D = 0/1000.0` (a Python float).
  - It is raised from inside `encircled_energy`, because `max_radius_um` defaults to 5× the Airy radius.
  - It is raised **even when matplotlib is unavailable**.
  - Example: `DiffractionCalculator().plot_encircled_energy(100, 0)`.
- `focal_length=0` does not raise in this module. Numpy array division gives NaN with a RuntimeWarning. Do not test this case.
- An unwritable or nonexistent directory in `save_path` makes matplotlib's `savefig` raise (behaviour lives in matplotlib, not here).

## 4. Returns and guarantees
- Always returns `None`, on both the plotting and the skip path.
- **Figure contents** (Axes = `plt.gca()` of the one figure, `figsize=(10, 6)`). `ax.get_lines()` holds 6 Line2D objects, in this order:
  1. Curve: x = `r` (μm, 100 points from `encircled_energy` default `num_points=100`), y = `encircled*100`, colour `"b"`, linewidth 2.
  2. `axvline(x=airy_r)`: colour `"r"`, linestyle `"--"`, label `f"Airy disk radius = {airy_r:.2f} μm"`.
  3. `axhline(y=50)`: colour `"g"`, linestyle `":"`, alpha 0.5.
  4. `axhline(y=80)`: colour `"orange"`, linestyle `":"`, alpha 0.5.
  5. Marker `"go"` at `(r[idx_50], 50)`, markersize 8, label `f"50% @ {r[idx_50]:.2f} μm"`.
  6. Orange `"o"` marker at `(r[idx_80], 80)`, label `f"80% @ {r[idx_80]:.2f} μm"`.
- `idx_50 = np.argmin(np.abs(encircled - 0.5))`, and `idx_80` likewise with 0.8. These use the fractions, not the percentages.
- Legend texts, in order: `["Airy disk radius = … μm", "50% @ … μm", "80% @ … μm"]`.
- Labels and title:
  - xlabel `"Radius (μm)"`.
  - ylabel `"Encircled Energy (%)"`.
  - Title `f"Encircled Energy Curve\n(f={focal_length}mm, D={aperture_diameter}mm, λ={self.wavelength*1e9:.0f}nm)"`.
- Grid is on (alpha 0.3) and `ylim == (0, 105)`.
- **Worked example:** default calculator, `f=100`, `D=10`.
  - `airy_r = 6.71` μm, so the label is `"Airy disk radius = 6.71 μm"`.
  - Title is `"Encircled Energy Curve\n(f=100mm, D=10mm, λ=550nm)"`.
  - The curve's x data runs from 0 to about 33.55 (= 5·6.71); y[0] = 0.0.

## 5. Side effects
- Creates one pyplot figure and closes it with `plt.close()` (the current figure).
- With a truthy `save_path`, writes that file.
- `self` is not mutated and there is no global state.
- On the skip path it logs a WARNING on logger `"openlens.diffraction"`, with the exact text `"plot_encircled_energy unavailable: matplotlib is not installed. Skipping."`.

- **`save_path` is `None` or `""`**: `show` is called and `savefig` is not.
- `focal_length=0`: `size` becomes 0, giving a degenerate extent. Avoid this case; matplotlib behaviour is uncertain.

## 7. Rules from comments/docstring
- Both inputs are in mm. The plot extent is 10× the Airy radius, i.e. ±5 Airy radii.
